## 1. 背景与口径

### 1.1 本轮范围

逐个手牌 ID 解释，不做批量改动：

1. **真人每个决策点**：局面（街 / 底牌 / 公共牌 / 底池 / 跟注额 / 对手数）、`equity` / `pot_odds` / `call_ev`、参考动作与参考分布、命中的 mistakes 及其判据来源、按参考打的定性走向。
2. **Bot（启发式）的决策依据**：复盘只覆盖真人座位（`build_review` 仅对 `human_seat` 调 `_analyze_decision`），因此 Bot 为何这么打需回到 `app/strategy/heuristic.py` 逐条对照阈值解释（价值下注 / 半诈唬 / 空气诈唬 / Chen 分档）。
3. 解释中发现的疑点按 §3 结构记录，由用户判断是否改代码。

### 1.2 解释时使用的当前口径（来自 `13` / `16` / `17 §5`）

- 参考动作 = 「启发式基线分布」经保守收窄后的**众数**；`DecisionReview.bot_distribution` 给出完整分布（按概率降序，权重和为 1）。
- 基线分布唯一来源是 `HeuristicStrategy.action_distribution`；只有「无人下注 + 胜率 < 0.25」的空气诈唬支是混合分布，其余分支为单一动作。
- 收窄规则：翻牌后面对下注 → 赔率无余量或无可继续牌力时把跟注质量转移到弃牌（小注例外：跟注额 ≤ 底池 1/3）；翻牌后无人下注 → 弱踢脚顶对把下注质量转移到过牌；翻牌前与加注 / 弃牌原样沿用基线。
- `_call_margin`：强听牌（`draw_outs ≥ 8` 且公共牌未发完）余量折半；被压制对子（一对且该对低于公共牌最高点数）不算可继续牌力；参考动作与 `bad_fold` **共用**该门槛。
- **实盘 Bot 行为未变**：`HeuristicStrategy.choose_action` 只是从分布采样。
- `bad_call` **仍**只看 `equity < pot_odds - 0.03`（翻牌前追加「跟注额 ≤ 一个大盲」豁免），未与跟注侧牌力门槛同步。

### 1.3 平台层现状（来自 `18`，影响「跑起来是什么行为」的判断）

- 不再有「目标手数」：`target_hands = 0` 表示不限手数，新对局永不 `finished`；`target_hands > 0` 只存在于旧数据。
- 进行中对局仅驻留内存，进程重启 / 热重载即丢失；历史手牌落库 `hands` 表（`history_json`），复盘在读取时用 `build_review` 重放。
- 同一 `session` 下会积累很多手牌，`inspect_hand.py` 不带参数即可快速取 ID。

### 1.4 核对工具

```bash
# 在 backend 目录下
uv run python tools/inspect_hand.py                # 列出最近 20 手（取 ID）
uv run python tools/inspect_hand.py <hand_id>      # 打印该手的复盘与判据内部状态
uv run python tools/inspect_hand.py --recent 50    # 列出最近 50 手
```

只读数据库、不改状态；重放直接复用 `analysis.hand_review`，不会与其漂移。

**本次疑问：为什么 Bot 河牌用（几乎）必输的牌下注 70**

- **牌型澄清**：`2d 4s` 在 `Ac Th Ad 6c 7d` 上并不是「高牌」——最佳牌型是**公共牌自己成的一对 `A`**，踢脚 `T 7 6` 全部来自公共牌，底牌 `2`/`4` 完全不参与。实测 `equity = 0.0020`（vs 2 随机），近似必输。
- **分支归属**：河牌 `draw_outs` 恒为 0（`len(board) == 5`），价值下注与半诈唬都不成立；`equity 0.0020 < _AIR_EQ 0.25` → 落入**空气诈唬混合支**：分布为 `[(bet, 0.10), (check, 0.90)]`。本手河牌 `choose_action` 采样命中了下注（`_BLUFF_FREQ = 0.10`），于是 `bet 70`。
- **不是「突然反常」而是同一支的第三次采样**：翻牌 `0.1164`、转牌 `0.0450`、河牌 `0.0020` **三街都落在空气支**，前两次分别命中 90% 的过牌、河牌这次命中 10% 的下注。`choose_action` 每次消耗一个独立随机数，所以「连续两次过牌后第三次下注」是正常分布行为。
- **设计意图**（`16 §3.1`）：这是策略里**唯一的混合分支**，用于平衡下注范围——若 Bot 只在有牌时下注，对手（真人）可以「见注就弃、见牌就躲」，Bot 的强牌就拿不到价值。10% 频率即为此设。
- **额度 70** 同样来自 `_bet_amount`（恒一池），与价值下注共用，不含「诈唬用小注」的考虑。
- **本手结果**：seat 3、seat 4 双双弃牌，Bot 不摊牌直接赢 70——这是一次成功的诈唬，并非亏损。

**疑点关注**：本手 Bot 行为与口径一致，无标记；空气诈唬支的频率 / 额度 / 边界敏感性记入 §3.3（观察，非缺陷）。

- **不是诈唬，是价值下注**。转牌走「无人下注」分支，第一个判据就是 `eq >= _VALUE_BET_EQ`——seat 4 的 `equity = 0.7542 ≥ 0.70`，返回确定性分布 `[(bet, 1.0)]`，与「空气诈唬」的 10% 混合支（§3.3）完全无关。
- **一对 9 为什么算「价值」**：`equity` 是「vs 随机底牌」的胜率，而**对手数已从 2 降到 1**。同一副底牌在翻牌（vs seat 0、seat 2 两人）只有 `0.6049` —— 当时不够 0.70，所以 seat 4 在翻牌只能过牌；seat 0 在翻牌弃牌后，转牌变成 vs 1 个随机对手 → `0.7542`，**因对手数减少而越过阈值**，同一手牌由「过牌」翻转为「下注一池」。
- **额度 210** 来自 `_bet_amount`（恒取当前底池），与牌力无关。
- **对照实证**：面对 seat 2 的真实底牌 `As 8c`（两对 `A`/`8`），`9c Kc` 在转牌的胜率只有 **0.0455**（枚举 44 张河牌）。也就是说这次「价值下注」的 0.75 完全来自 vs 随机口径，真实对抗中是彻底的落后牌——随后被加注到 630 并全下输光 370。
- **与 §3.3 的区别**：`bet 210` 是**确定性**的价值下注（`bet 100%`），不是随机诈唬；用户观感上「像诈唬」恰恰说明 vs 随机口径下的「价值牌」与真实牌力之间已出现可见落差。

**疑点关注**：本手真人三个决策点均无标记；「价值下注阈值同样只看 vs 随机胜率、且对对手数高度敏感」记入 §3.4（观察，非缺陷）。

### 3.1 实盘 Bot 在「翻后未击中 / 只成被压制的一对」时，跟随任何不超过一池的下注

**现象**：手牌 `49034be75ba140f6a20464228fd008f9` 的 seat 1（`Kc Kd`）在 `Ah 8d 7h` 上——`KK` 的一对**低于公共牌最高点数 `A`**，属被公共牌压制的对子，翻后三街没有击中任何新牌——面对 seat 3 的三发一池下注（120 / 360 / 1080）**全部跟注**，河牌面对 `pot_odds 0.5000` 仍跟 1080，本手净亏 1610。用户观察到的「翻前未弃牌的 Bot 在未击中牌时经常不理智地跟注、金额很大也跟」即此形态。

**机制**（回到 `strategy/heuristic.py::_postflop_distribution`，面对下注分支）：

```text
if eq >= _RAISE_EQ(0.90) and can_raise:  → raise
if eq >= _AIR_EQ(0.25) and eq >= pot_odds: → call
else: → fold
```

1. 判据里**只有「vs 随机底牌的摊牌胜率」与「底池赔率」两个量**，没有牌力质量（是否被公共牌压制 / 是否成手牌）、对手下注线长度、注额绝对大小等维度；
2. `equity()` 是「vs N 个随机底牌」的胜率，面对下注时被系统性高估（`13 §1`、`17 §3.5` 同一病根）。本手实测（40000 次采样）`KK` 三街为 `0.7388 / 0.7492 / 0.7878`；
3. 而 `_AIR_EQ` 下限 `0.25` 对「有一对的牌」形同虚设，真正生效的只有 `eq >= pot_odds`；
4. `_bet_amount` 恒为「一池」（`17 §3.4`），因此面对下注分支里 `pot_odds = to_call / (pot + to_call)` 的**上限约为 0.5**（一池下注恰为 0.5）。要让 `KK` 在这类面弃牌需 `pot_odds > 0.7878`，即下注 **≥ 约 3.7 倍底池**——在本策略的额度档位下**永远无法达到**；
5. 同一原因也使 `KK` 永远进不了 `_RAISE_EQ 0.90` 的加注分支：本手 `KK` 只能「一直跟、从不再加注」。

**对照（精确枚举，翻牌 `A 8 7`，底牌 `KK`）**：

| 对手实际底牌 | `KK` 胜率 |
|---|---|
| `8s 7c`（本手实际，两对） | **0.2545** |
| `Ah Th`（顶对） | **0.0444** |
| `As Ks`（顶对顶踢） | **0.0424** |
| `8c 8h`（三条） | **0.0798** |

即面对「在这里真的会连开三枪的牌」，`KK` 只有 4%~25%，而策略层用的是 **0.74~0.79**，高估约 50~70 个百分点；`pot_odds` 又只有 0.33~0.50，于是跟注判据必然成立。**这不是实现 bug，而是判据口径本身的取向**。

**分析**：

- 属**口径设计（策略层判据过宽）**，不是误报/漏报类问题；也**不是**「Bot 不看金额」——它看 `pot_odds`，但注额上限被夹在一池，`pot_odds` 天花板 0.5，低于「任何一对牌」在这类面的 vs 随机胜率，所以「金额很大」在本框架内约束不了它。
- 与复盘层的**方向性分裂**：`17 §5.2` 已把「一对且该对低于公共牌最高点数」（`_dominated_pair`）排除出「可继续牌力」，复盘面对该局面既不保留参考跟注、也不判 `bad_fold`。但该门槛位于 `analysis/hand_review.py`，**实盘 Bot 不读它**（`13` / `16 §8` 明确「只动复盘、实盘不变」）。结果同一局面：复盘认定「该牌力不可继续」，实盘 Bot 自己却一路跟到底。本手是该分裂最极端的一次暴露。
- 次要同源现象：翻前的「投机边缘牌」档（`_SPECULATIVE_CHEN 5`）同样**只看价格不看牌力**。本手 seat 3 的 `8s 7c`（Chen 5）面对 `40/80` 恰为「底池一半」，`_call_within` 恰好成立而跟注入场（若加注到 60 以上即弃）。这是「翻前未弃牌的 Bot」的来源之一；本例它翻后击中了，故未放大亏损。
- 与 `13 §6` 的已知取舍一致：`equity` 为 vs 随机口径时，任何「有一对但被压制」的牌都会越过跟注线；`17 §3.5` 记录的 `JJ` / `bad_fold` 误报是同一病根的复盘侧表现，本手是**实盘侧**表现。

**候选修正**（含取舍与代价）：

| 方案 | 内容 | 取舍 / 代价 |
|---|---|---|
| a | 把复盘层的「被压制对子」门槛下沉到策略层：面对下注时，成手牌恰为一对且低于公共牌最高点数 → 不保留跟注（可与强听牌例外共存） | 与复盘口径对齐，直接消掉本手形态；但**改变实盘 Bot 行为**，需回归 `08`~`10` 的调参结论（会弃掉「对手在诈唬时其实领先」的牌）、补齐用例并重跑批量对照；且触及本轮「默认不动 `strategy/`」的边界 |
| b | 策略层引入「对手下注线强度」或「按街收紧阈值」（如被跟注/被加注后降档） | 更贴近真实牌理；但等于引入范围/线强度建模，超出 `13` 起确立的「不引范围建模」边界，改动面最大 |
| c | 维持实盘不变，仅把该现象记为已知局限，在文档/前端说明「Bot 使用 vs 随机胜率，面对下注偏乐观」 | 零风险、不碰三层；但「教练标准严于对手打法」的割裂长期存在，用户实测时仍会反复遇到同一形态 |
| d | 只在复盘侧继续加保险（如把 `bad_call` 与跟注侧牌力门槛同步），实盘不动 | 只影响标记不影响对手行为，无法解决用户观察到的现象本身；且 `17 §3.7` 数据显示 `bad_call` 豁免会掩盖真报 |

**本轮决策（2026-09-16）：不改实盘，作为已知局限记录。** 理由：实盘收紧会改变 Bot 性格，需回归 `08`~`10` 的调参结论并重跑批量对照，与 `13` / `16 §8` 确立的「只动复盘、实盘不变」取舍冲突。若将来目标改为「更可信的陪练」，可走方案 (a) 的小改动路径——把 `_dominated_pair` 从 `analysis` 上移到 `strategy` 后由复盘反向复用（依赖方向合法，避免 `11 §3.1` 的判据漂移）。

### 3.2 观察（非缺陷）：半诈唬阈值「补牌数」的二值跳变

**现象**：手牌 `5aac83a888a646598bc3a4e239a1cedb` 转牌，seat 2（`2d 6d`）在 `3d Jd 7s 4h` 上以**同花听牌 9 张 + 顺子补牌 3 张 = 12 张**恰好越过 `_DRAW_STRONG_OUTS = 12`，得到确定性的 `bet 100%`（额度一池 70）。若同花补牌少一张（补牌 11），`equity 0.2650 > _AIR_EQ 0.25` 使它既不落空气分支、也不落半诈唬分支，结果为确定性的**过牌**。

**机制**（回到 `strategy/heuristic.py::_postflop_distribution`，无人下注分支）：

```text
if eq >= _VALUE_BET_EQ(0.70):                                   → bet（价值）
if outs >= _DRAW_STRONG_OUTS(12):                               → bet（半诈唬）
if eq < _AIR_EQ(0.25) and 0 < bluff_freq < 1:                   → 混合（bet bluff_freq / check 1-bluff_freq）
else:                                                           → check
```

三个下注理由是**按顺序短路**的确定性判断，补牌数只与阈值 `12` 作 `>=` 比较，没有过渡：`outs = 12` → 100% 下注，`outs = 11` → （在 `equity` 不低于 0.25 时）100% 过牌。这与 `16 §2` 的设计一致（只有空气支是混合分布），也与 `17 §2.1` 记录的 `Qh Ad`（12 补牌踩线）是同一形态。

**分析**：属**口径的边界敏感**，不是 bug，也不构成误报/漏报：

- 触发半诈唬的是「补牌数」这一单一维度，不看听牌质量（是否坚果、是否可能被更大同花压制）——本手成的是 `6` 高同花，若对手有更大的方块听牌则存在反向隐含赔率，这一维度在当前判据里不表达（与 `17 §3.2` 的「听牌质量」遗留同源）。
- 阈值两侧的行为是「下注 / 过牌」的二值跳变，用户观察 Bot 时容易感到「差不多的牌，一手突然下注、另一手完全不动」。
- 半诈唬与本手顺子补牌的加成来自 `draw_outs` 只统计「再发一张即成型」，因此**卡顺被公共牌补上后补牌一次性 +3**，是阈值跳变的常见触发路径。

**候选修正**（含取舍与代价，均为待讨论）：

| 方案 | 内容 | 取舍 / 代价 |
|---|---|---|
| a | 把本支改为混合分布（如 `outs == 12` 时以较低频率下注、`outs ≥ 13` 才确定性下注） | 行为更平滑、更接近真实打法；但会把 `16 §3.1` 的「唯一混合分支」扩成两处，需同步复盘分布展示与用例 |
| b | 在 `draw_outs` 之外补一层听牌质量（坚果 / 非坚果）再决定是否半诈唬 | 更贴近牌理；但新增判据维度，超出「不引范围建模」的当前边界 |
| c | 维持现状，仅在文档/前端说明「补牌数达阈值即下注，阈值附近会二值跳变」 | 零风险；但用户对阈值附近的观感困惑会继续存在 |

**本轮决策（2026-09-16）：维持现状**（方案 c，只记录并说明），不改判据。

### 3.3 观察（非缺陷）：空气诈唬支的频率与额度不分场景

**现象**：手牌 `9d294eadf9444ea9944b076a5242181b` 河牌，seat 1（`2d 4s`）在 `Ac Th Ad 6c 7d` 上 `equity = 0.0020`（底牌完全不参与成牌），仍以 10% 频率下注**满池 70**；同一手翻牌 / 转牌也落在同一支，只是分别命中了 90% 的过牌。

**机制**（`strategy/heuristic.py::_postflop_distribution` 无人下注分支 + `choose_action`）：

```text
if eq < _AIR_EQ(0.25) and 0 < bluff_freq(0.10) < 1:
    → [(bet, 0.10), (check, 0.90)]      # 唯一混合分布
choose_action: roll = rng.random(); 累积权重比较            # 每次决策独立采样
```

- 该支的判据只有 `equity < 0.25` 一条，**不看**公共牌纹理（本手是双 `A` 面，任何对手的 `A` 都成三条）、**不看**对手数（vs 1 与 vs 2 个对手同为 10%）、**不看**底牌自身的摊牌能力（`0.0020` 与 `0.24` 同等对待）；
- 下注额度走 `_bet_amount`，恒为一池，与价值下注 / 半诈唬共用（`17 §3.4`），因此诈唬风险敞口等同满池价值下注；
- 混合支的存在是 `16 §3.1` 的设计（平衡下注范围），本手也为 Bot 带来了实际收益（两个对手均弃牌，直接赢下 70）。

**分析**：属**口径的简化**，不是 bug、也不构成误报：策略层面没有「诈唬面纹理」「多对手降低诈唬频率」「诈唬用小注」这三个维度，因此用户在复盘时会看到「几乎必输的牌满池下注」这类形态，且它能出现在任意牌面。与 `17 §2.1`（`Qh Ad` 12 补牌踩线）同属「判据维度太少导致的观感跳跃」，但本条发生在空气支、且带随机性，观感上更像「Bot 抽风」。

**候选修正**（含取舍与代价，均为待讨论）：

| 方案 | 内容 | 取舍 / 代价 |
|---|---|---|
| a | 诈唬频率随对手数递减（如 1 人 10%、2 人 5%、3 人以上 0） | 更贴近真实打法（多人底池诈唬成功率低）；但引入「对手数 → 频率」映射，策略层新增参数，需重跑批量对局观察影响 |
| b | 空气诈唬改用较小额度（如半池）而非满池 | 降低失败成本、提高诈唬性价比；但会让 `_bet_amount` 从「单一池量」变成分档，`underbet` / `value_missed` 的判定面与 `16 §7` 的统计口径都要同步 |
| c | 加一层「诈唬面纹理」门槛（只在干燥 / 单挑时可诈唬） | 最贴近牌理；但等于引入牌面纹理建模，超出「不引范围建模」的当前边界，改动面最大 |
| d | 维持现状，在文档 / 前端说明「Bot 会以 10% 频率用任意空气下注」 | 零风险；但用户仍需自行把「偶尔的满池下注」理解为诈唬而非失误 |

**本轮决策（2026-09-16）：维持现状**（方案 d），不改诈唬频率与额度。

### 3.4 观察（非缺陷）：价值下注阈值同为 vs 随机口径，且对对手数高度敏感

**现象**：手牌 `4b3dc126bedb4272819692ae1054a1bf` 转牌，seat 4（`9c Kc`，一对 9 + K 踢脚）在 `9s Ac 4d 8s` 上无听牌，却下注**一池 210**（确定性 `bet 100%`，非随机诈唬）；随后被 seat 2 的两对加注到 630，全下输光。同一副底牌在**翻牌**（`9s Ac 4d`）时只选择过牌——唯一的差别是当时还有 2 个对手。

**机制**（`strategy/heuristic.py::_postflop_distribution` 无人下注分支）：

```text
if eq >= _VALUE_BET_EQ(0.70):  → bet（价值下注，权重 1.0）
```

- 价值下注的判据**只有** `equity ≥ 0.70`，不看牌力质量（一对 / 两对 / 听牌）、不看对手数、不看牌面结构；
- `equity` 是「vs N 个随机底牌」的胜率，`N` 由 `_num_opponents` 实时统计（已弃牌者被排除）。本轮实测：`9c Kc` 在 `9s Ac 4d` vs 2 随机 = **0.6049**（< 0.70 → 过牌），在 `9s Ac 4d 8s` vs 1 随机 = **0.7542**（≥ 0.70 → 下注）。**一张对手弃牌的动作，直接把同一手牌推过阈值**；
- 对照实证：面对 seat 2 的真实底牌 `As 8c`（两对），`9c Kc` 的转牌胜率只有 **0.0455**（枚举 44 张河牌）——「价值」完全来自 vs 随机口径。

**分析**：属**口径的简化/边界敏感**，不是误报或漏报：

- 与 §3.1 同一病根（`equity` 为 vs 随机），但**方向相反**：§3.1 是跟注侧「该弃不弃」，本条是下注侧「把中等对子当强牌下注一池」。两处共用同一个 `equity` 与同一套 `_VALUE_BET_EQ` / `_AIR_EQ` 阈值。
- 观感落差集中在**单挑**：在 1 个对手时，任何「有一对且踢脚不差」的牌 vs 随机胜率都容易达到 0.70~0.80，于是 Bot 会持续用中等牌力下注满池。用户看到「Bot 拿一对 9 开一池」自然第一反应是诈唬，实际是它眼中的价值下注。
- 阈值对对手数的敏感度大于对牌力的敏感度：本例两张底牌完全相同，仅对手数从 2 变 1，行为就从过牌变成满池下注。这一「行为跳变」的来源与 §3.2（补牌数踩线）同类，但驱动量是**对手数**。

**候选修正**（含取舍与代价，均为待讨论）：

| 方案 | 内容 | 取舍 / 代价 |
|---|---|---|
| a | 价值下注追加牌力质量门槛（如「一对且该对低于公共牌最高点数」不主动下注一池，与 `17 §5.2` 的 `_dominated_pair` 同向） | 与复盘口径对齐，能抑制「中等对子单挑满池」；但**改变实盘 Bot 行为**，需回归 `08`~`10` 的调参结论与批量对局统计 |
| b | 阈值随对手数上浮（如 2 人 0.70、3 人以上不降 / 1 人不降）或改为「按对手数归一」 | 缓解单挑激进；但 `equity` 已含对手数影响，叠加调整易造成双重收紧，需实验定标 |
| c | 价值下注额度按牌力分档（强牌一池、边缘牌半池） | 直接缓解「中等牌力满池」的风险敞口；但 `_bet_amount` 由单一池量变分档，`underbet` / 价值门槛统计（`16 §7`）需同步，改动面与 §3.3 方案 b 重叠 |
| d | 维持现状，文档 / 前端说明「Bot 的价值阈值取自 vs 随机胜率，单挑时中等对子会被当成价值牌」 | 零风险；但「像诈唬的价值下注」会持续出现，用户需自行分辨 |

**本轮决策（2026-09-16）：维持现状**（方案 d），与 §3.1 同一决策（不改实盘）。

### 4.1 决策

**本轮不改任何代码**（`poker/` / `strategy/` / `analysis/` 均未改动，仅新增本文档）。四条现象全部按「维持现状 + 记录」收尾：
