# 12 M5 复盘质量调优（针对 bad case）

> 本文档记录在 M5 复盘引擎（见 `11-m5-review-engine.md`）之上，针对本地真实对局暴露的 bad case 所做的一轮轻量调优，作为 `11` 之后的实现快照。
>
> **文档权威性**：遵循 `03-execution-plan.md` 第 8 节约定，本文档是 `11` 之后的「实现快照」，两者冲突时以本文档为准。

---

## 1. 背景与目标

M5 复盘已能确定性重放并标记错误，但在本地库的 159 手真实对局（354 个真人决策点）上跑全量后发现两类问题：

1. **重放本身会算错、甚至报错**——底池 / 跟注额与实际不符，16/159 手直接抛错；
2. **错误判据误报偏多**——`bad_fold` 命中 21 次，其中近半与参考 Bot 结论相反。

本轮只做「保持简单、不引重活」的修复：不引对手范围建模、不引入 CFR、不做反事实动作树模拟，优先修复误报 / 漏报最明显、出现频率最高的 bad case。

---

## 2. 诊断

### 2.1 重放正确性（最高频、影响面最大）

| 根因 | 表现 |
|---|---|
| 各玩家起始筹码被压成同一个值（取循环最后一个玩家的 `starting_stack` 给所有人） | 一手开始时各人筹码本就不同，重放时加注越界，**16/159 手抛错**（接口 500） |
| 加注额语义错位：历史记录的是本次加注增量，引擎要求的是加注后总额 | 重放状态漂移，**143 手中 5 手的决策点底池 / 跟注额被算错**（最大偏差 100+） |

修复后：**155/159 手可重放**；剩余 4 手为 2026-09-09（`8311670` 之前）的旧格式历史（免费过牌却弃牌、翻牌前「下注」语义），当前引擎已无法重放。

### 2.2 误报分布（修复重放后）

| code | 命中 | 主要问题 |
|---|---|---|
| `bad_fold` | 21 | 最吵：10/21 处参考 Bot 也弃牌；翻牌前用 `vs 随机`胜率判误弃失真（K4o 胜率 0.535 被判误弃，Bot 却弃牌） |
| `bad_call` | 43 | 大体真实；约 8 处跟注 EV 约等于 0（-2~0）被标 `error`，偏严 |
| `value_missed` | 12 | 9/12 是胜率 0.73~0.80 的薄价值过牌，阈值偏低 |
| `slowplay` | 3 | 均为强牌面对半池只跟，判定合理，未调整 |
| `underbet` | 4 | 合理（`info` 级），未调整 |
| `over_aggressive` / `air_bluff` | 0 | 本库未触发 |

---

## 3. 改动

| 文件 | 改动 |
|---|---|
| `app/analysis/hand_review.py` | 重放时按 `players[*].starting_stack` 逐人还原筹码；新增 `_replay_action` 把加注「增量」换算为「加注后总额」（展示仍用历史原值）；`bad_fold` 容差改为随注码放大并加翻牌前胜率下限；`bad_call` 加容差；`value_missed` 阈值提高 |
| `tests/test_review.py` | 新增 6 个用例：重放逐人筹码、加注增量换算，以及误弃 / 价值丢失 / 跟注容差的判据边界 |

阈值一览（常量集中于 `hand_review.py` 顶部）：

| 项 | 旧值 | 新值 |
|---|---|---|
| 误弃容差基准 | `0.10` | `0.15`（再叠加 `0.10 × 跟注占底池比例`） |
| 翻牌前误弃胜率下限 | 无 | `0.55` |
| 跟注不足容差 | 无 | `0.03` |
| 价值丢失胜率阈值 | `0.70` | `0.80` |

---

## 4. 与 `11` 的偏差

| 点 | `11` 原表述 | 本轮落地 |
|---|---|---|
| 重放筹码 | 未提及 | 按各玩家起始筹码逐人还原 |
| 重放加注额 | 未提及 | 由「增量」换算为「加注后总额」 |
| `bad_fold` 容差 | 固定 `+0.10` | 随注码放大，翻牌前另加胜率下限 |
| `bad_call` 判据 | `equity < pot_odds` | `equity < pot_odds - 0.03` |
| `value_missed` 阈值 | `0.70`（与策略层一致） | `0.80`（与策略层解耦） |

---

## 5. 效果

同一批 159 手对局，错误标记总数 **83 → 49**：

| code | 调整前 | 调整后 |
|---|---|---|
| `bad_fold` | 21 | 4 |
| `bad_call` | 43 | 35 |
| `value_missed` | 12 | 3 |
| `slowplay` | 3 | 3 |
| `underbet` | 4 | 4 |

保留下来的多为高置信错误（如「胜率 0.59 面对半池却弃牌」），阅读干扰明显下降。

---

## 6. 遗留与后续

- **仍为「vs 随机」而非「vs 对手范围」**：判据仍基于同一信息边界，未做范围建模。
- **旧格式历史无法重放**：4 手 2026-09-09 的对局会在复盘接口抛错（当前返回 5xx）。是否做「优雅降级 / 兼容旧语义」留待后续。
- **未调整的规则**：`slowplay` / `underbet` / `over_aggressive` / `air_bluff` 本轮未动；`slowplay` 尚未考虑「面对超注时不加注也合理」的情形。
- **多街重复标记**：同一手在转牌与河牌各记一次价值丢失，属两次独立决策，暂未合并。
