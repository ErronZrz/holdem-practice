> 本文档记录 M4 验收后、体验过程中发现的 Bot 策略问题——弃牌率偏高，作为下一轮策略调优的交接依据。

## 1. 观察现象

体验中发现 Bot 翻牌前弃牌率偏高，不少本可入池的边缘牌也被弃掉，例如：

- 小对子 `55 / 66 / 77` 面对下注直接弃牌，缺少 set mining（击中暗三条）的价值。
- 同花连张如 `T9s` 翻牌前能入池（MEDIUM），但翻牌后未击中公共牌即被判定为 WEAK，面对下注直接弃牌，缺少对听牌 / 潜在价值牌的考量。

---

## 2. 根因分析（`app/strategy/heuristic.py`）

翻牌前用 Chen 公式打分后按阈值分三档（`_STRONG_CHEN=12`、`_MEDIUM_CHEN=8`）：

| 档位 | Chen 阈值 | 动作倾向（`_select`） |
|---|---|---|
| STRONG | ≥ 12 | 能下注就下注、能加注就加注，否则过牌/跟注 |
| MEDIUM | ≥ 8 | 能过牌就过牌，否则跟注 |
| WEAK | < 8 | **能过牌就过牌，否则弃牌** |

具体表现：

- 小对子 Chen 分：`55=5`、`66=6`、`77=7`（对子公式 `max(5, ceil(high_value*2))`）→ 全部落入 WEAK，面对任何下注直接弃牌；`88` 起才进入 MEDIUM。
- 连接/同花牌如 `T8s`（Chen=7）、`J9s` 等 < 8 → WEAK，翻牌前面对下注弃牌；`T9s`/`98s` 恰好 = 8 进入 MEDIUM。
- WEAK 分支是「非弃即过」的确定性逻辑，没有「赔率合适时跟注」的弹性。
- 翻牌后高牌（WEAK）同样直接弃牌，未区分「纯空气」与「有听牌潜力（两头顺 / 同花听牌）」。

---

## 3. 改善方向（候选，待下一轮细化）

1. **阈值 / 分档调整**：把小对子、同花连张的翻牌前档位提高（如 `55~77` 提到 MEDIUM，用于 set mining）。
2. **赔率敏感跟注**：面对小注（跟注金额相对底池 / 有效筹码较小）时，边缘牌允许跟注。
3. **翻牌后听牌识别**：把两头顺、同花听牌等「有潜力」的牌从 WEAK 中分离，避免过早弃牌。
4. **位置感知**：按位置调整起手牌范围（`02` D7 原定初期不做，属长期增强）。
5. **混合 / 诈唬**：引入少量随机化，避免完全确定性被 exploit（`05` 文档已知取舍）。
