# 15 复盘参考动作的待办与逐手核对疑点

> 本文档承接 `13-m5-conservative-reference.md`，记录逐手核对过程中暴露的口径问题、现象与初步分析，以及已定的待办。
>
> **文档权威性**：遵循 `03-execution-plan.md` 第 8 节约定。本文档是「待办与疑点记录」，**不改变任何既有实现**；与 `13` 冲突时以 `13` 为准（待办落地后再另立实现快照）。

---

## 1. 背景

本轮以「逐手核对」的方式复核了 3 手真实对局，逐决策点打印局面、`equity` / `pot_odds` / `call_ev`、参考动作，以及参考判据的内部状态（成手牌 / 补牌数 / 赔率余量）。结论分两类：

- **判定为「系统判对」**：`ffbed98cdeef42df96e3f76c98bb2345`（河牌用底对抓半池下注，参考弃牌合理），未产生待办；
- **判定为「疑点」**：两处口径问题，见 §3。

归纳出的病根有两条：

1. **参考动作在「无人下注」分支沿用启发式的随机诈唬**，同一局面在固定 seed 下表现为一个「固定结果」，实为一枚硬币，不具可解释性；
2. **判据不对称**：跟注侧（`bad_fold` / 保守参考）在 `13` 中已引入「赔率余量 + 牌力质量」门槛，而**翻牌前跟注**（`bad_call`）与**价值下注**（`value_missed` / 参考价值下注）仍只看单一胜率阈值。

---

## 2. 待办：参考动作改为概率分布（下一轮展开）

**现状**：`reference_strategy = "heuristic-conservative"` 给出的是**单一确定动作**。其中「无人下注 + 胜率低于空气阈值」这一支由 `HeuristicStrategy(seed=0, bluff_freq=0.10)` 的随机数决定，复盘里表现为「同一局面永远给出同一个随机结果」。

**决定**：**保留随机诈唬**，但把参考动作从「单一动作」升级为**动作概率分布**，例如：

| 动作 | 概率 |
|---|---|
| 跟注 | 50% |
| 弃牌 | 40% |
| 加注 | 10% |

让用户看到的是「策略分布」而不是一枚硬币的落地结果。

**影响面（待评估）**：

| 层 | 需改动 |
|---|---|
| 接口模型 | `DecisionReview.bot_action`（单动作）需扩展为分布字段（保持向后兼容或新增字段） |
| 参考实现 | `_conservative_action` 的收窄逻辑需从「改判动作」改为「对分布加权」 |
| 标注 | `reference_strategy` 的取值与文案 |
| 前端 | 复盘区展示分布 |
| 测试 | `tests/test_review.py`、`tests/test_games_api.py` 相关断言 |

**状态**：已由 `16-m5-reference-distribution-and-gates.md` §3 落地（分布唯一事实源、众数参考动作、概率质量再分配）。

## 3. 本轮核对暴露的疑点（现象 + 分析）

> **后续**：本节三处疑点已由 `16-m5-reference-distribution-and-gates.md` 处理——§3.1 → 参考动作概率分布；§3.2 → 翻牌前 limp 豁免；§3.3 → 弱踢脚顶对门槛。

### 3.1 参考动作的随机诈唬

**现象**：手牌 `7a88f7d65abd4fdfaf457b68237bc32b` 河牌，真人先行动、无人下注。底牌 `2s Ad`（A 高、`_is_made_hand = False`、补牌 0），公共牌 `5h Qs Kh Kd Jh`，底池 150、`equity = 0.1710`，**参考动作 = 满池 `bet 150`**。

**机制**：

- 无人下注（`call_amount = 0`）时 `_conservative_action` 直接返回基线动作，保守收窄不介入；
- 启发式无人下注分支有三条下注理由：价值下注（胜率 ≥ `0.70`）、半诈唬（补牌 ≥ `12`）、**空气诈唬（胜率 < `0.25` 且随机命中 `bluff_freq = 0.10`）**；
- 河牌公共牌 5 张，补牌记 0；`0.1710 < 0.70` 且 `< 0.25` → 只剩空气诈唬分支，本次随机恰好命中 → 下注；
- 额度 = 一个底池 = 150。

**验证**：把 `bluff_freq` 置 0 后重放同一手，该决策点由 `bet 150` 变为 `check`，确认来源就是空气诈唬。

**分析**：参考动作因此**带上了随机性**，且固定 seed 使其表现为「同一局面永远同一个随机结果」。面对 2 个对手做满池诈唬本身也不合理（需两人同时弃牌）。**处理方式**：不单独改判据，统一由 §2 的概率分布改造吸收。

### 3.2 翻牌前 `bad_call` 对「廉价看牌」的误报

**现象**：手牌 `0aac1aedbb6545578cd2b9ba9e021ba0` 翻牌前，真人 `6h As` 跟注 20。底池 30（跟注额恰好一个大盲）、`equity = 0.2750`（vs 3 人随机）、`pot_odds = 0.4000`、`call_ev = -6`；**参考动作 = 弃牌**，并命中 `bad_call`（error）。

**机制**：

- 启发式翻牌前走 Chen 分档：`A6o` 得 5 分，落在投机档下限 `_SPECULATIVE_CHEN = 5`；投机档规则为「跟注额不超过半个底池」，`20 × 2 = 40 > 30` 不满足 → 弃牌；
- 注意跟注额 20 恰好等于一个大盲，属 **limp（补齐盲注）**，但 `call_amount > 0` 使启发式按「面对下注」处理；
- `bad_call` 判据为 `equity < pot_odds - 0.03`，`0.2750 < 0.37` → 命中。

**分析**：翻牌前的 `equity` 是「vs 随机 + 直接摊牌」，未计入翻牌后可弃牌的**期权价值**、**隐含赔率**与**位置**，用作跟注的 EV 代理会失真；而弃牌侧在 `12` 中专门加了 `_FOLD_MIN_EQ_PREFLOP = 0.55` 来防这类失真，跟注侧却只有 `0.03` 容差，**二者不对称**（`13` §6 已记录 `bad_call` 未同步）。因此本处 `bad_call` 属**误报**；参考弃牌本身属「偏紧但规则自洽」，不是硬错。

**候选修正（待定）**：翻牌前 `bad_call` 使用更大的容差；或对「跟注额 ≤ 一个大盲」（limp / 补齐盲注）的跟注豁免。

### 3.3 价值下注侧缺少牌力质量门槛

**现象**：同一手河牌，真人 `6h As` 在 `Qs Tc Ad 2h 8s` 上构成**顶对 + 弱踢脚（踢脚 6）**，底池 630、`equity = 0.8465`（vs 1 人随机）；真人过牌，**参考动作 = 满池 `bet 630`**，并命中 `value_missed`（warning）。

**机制**：

- 无人下注 → `_conservative_action` 不介入；
- 启发式：`0.8465 ≥ _VALUE_BET_EQ (0.70)` → 价值下注，额度取一个底池 = 630；
- `value_missed` 判据为「过牌且 `equity >= _VALUE_BET_EQ (0.80)`」，`0.8465` 越过 → 命中。

**牌面与牌力核对**：

| 维度 | 情况 |
|---|---|
| 同花 | 不可能（公共牌仅 `Qs 8s` 两张黑桃，对手最多凑到 4 张） |
| 顺子 | 存在：`KJ` 翻牌即成 Broadway；`J9` 河牌成顺（`Q J T 9 8`） |
| 两对 / 三条 | 组合很多：`QT` `Q8` `T8` `A8` `A2` `AQ` `AT`、`88` 等 |
| 踢脚 | 顶对但踢脚为 `6`（最差档），对手拿剩余两张 A 之一配大踢脚即可压过 |
| 位置 | 翻后顺序为 BB → 真人 → 对手，**真人在对手之前行动** |
| 对手表现 | 连跟翻牌 80（底池 70）与转牌 200（底池 230）两条街 |

**分析**：`equity` 为「vs 随机」，对「连跟两条街的范围」严重高估，因此 `value_missed` 属**误报（判据过宽）**，把边缘薄价值决策标成了 warning；参考 `bet 630` 从教练标准看过于武断，但并非硬错——从「对手实际范围」看反而可能收到价值（对手是启发式 bot，本手用 `8h Jh` 的 J 高 + 卡顺跟了两条街）。

**候选修正（待定）**：为「价值下注」引入与 `bad_fold` 对称的**牌力质量门槛**，并让参考动作与 `value_missed` 共用同一门槛，保持二者自洽。可判定的候选定义：

> 顶对时，若另一张底牌（踢脚）低于公共牌中第二高的点数，视为**弱踢脚顶对**，不做满池价值下注。

按该定义：本手 `6 < Q` → 判弱 → 过牌；而 `AK` 在 `Q T A` 上 `K > Q` → 仍下注。
