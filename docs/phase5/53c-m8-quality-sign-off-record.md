## 4. 反向读数（随结论一并列入细化清单）

1. **净筹码不占优**：旧启发式 arm 在 4 个主种子块中的 3 个高于新 Bot。块内均值（新 对 旧）：`1215` −0.5 对 +94.0；`20260918` +62.2 对 +107.5；`3311` +25.2 对 +77.3；`7926` +2.1 对 −19.6。总计新 +47007 对旧 +136878。这不是强度证据（机械探针不是 best response、单格仅 8–16 手、四个固定种子块不出具置信区间），但**方向不利于**新 Bot。
2. **翻前过紧**：新 Bot 三风格 VPIP 0.045 / 0.088 / 0.080，旧启发式 arm 0.243（三个风格标签下相同，属配对控制）；PFR 分别 0.016 / 0.013 / 0.000 对 0.017。新 Bot 进池率明显更低。
3. **人格区分不均**：风格间 JS 距离均值 紧密–松凶 0.193、紧密–跟注 0.174、松凶–跟注仅 0.069——松凶型与跟注型在多数节点上几乎重合。
4. **共享公共大牌上过度被动**：面对下注且自身牌力等于公共五张牌时，百万单位平均质量为 紧密型 弃 959,100 / 跟 40,900、松凶型 弃 826,596 / 跟 173,404、跟注型 弃 828,106 / 跟 171,894，**三档均不主动下注或加注**。
5. **最差对手族**：随机策略（紧密）、旧启发式（松凶）、固定施压探针（跟注型）。此项**不可当结论**使用（单格 8–16 手，量级由单手全下主导）。

上述 1、2、3、5 属「记录在案、不作为已证弱点」；第 4 条是唯一被单列为必须签收项的具体、可检验的疑似弱点。
