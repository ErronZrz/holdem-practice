## 8. 实施期暴露的缺陷（如实记账）

首次运行补算时**立即中止、未写任何报告**：`docs/54b` 的测试侧适配把对照回放的口径参数改成必填，但补算模块的同一个调用点未同步，抛出 `TypeError`。补算入口在回放前中止，`stage-b-recheck/` 只留下一个空目录。

`docs/54b` 报告的三项常规检查（`ruff` / `910 passed` / 前端构建）**全部通过却没有覆盖到这条路径**——因为补算的对照回放只在显式 opt-in 时才执行，默认套件只覆盖它的拒绝分支。

处置：同步该调用点、并新增一条**真正走回放路径**的回归（用单节点清单跑一次阶段 A 与补算，断言回放收到回执身份对应的口径、且身份不一致时拒绝）。修复后补算一次通过（§5.5），全量回归为 `911 passed, 3 skipped`。

该缺陷与修复**均在测试侧**，不触及被测策略实现，因此第二版清单的 `code_identity`（指向策略实现提交）**无需重取**。
