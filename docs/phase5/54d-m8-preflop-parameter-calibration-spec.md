## 3. 支配翻前进池率的量（结构分析）

翻前是否进池取决于「评分 S 是否越过跟注/价值阈值」：

- `S = clip(base + position + looseness + mode_offset - 35*(contenders-1), 0, 1000)`（翻前 `texture=0`、`draw=0`）
- `跟注阈值 Tc = 310 + floor(450*price/1000) + 25*r + depth`，翻前深筹码 `depth = +25`
- 进池 ⇔ `S > Tc - 160` 或 `S > Tv - 120`（后者需 `S > 480 + 25*r`，翻前极少发生）

因此在底池仅含盲注时，价格项在 `price≈400` 下贡献约 **+180**，深筹码再 **+25**，使 `Tc - 160 ≈ 355`——**单是价格项与深筹码项就把门槛抬到多数起手牌之上**；多人桌上每多一名对手再减 35 分，进一步压低 `S`。这两处（价格项、每对手惩罚）是主控量。

## 4. 只读算术筛查（估计，不是测量）

方法：枚举 169 个起手牌类（按 6/4/12 组合权重）、2–9 人（按 `N/44` 加权）、全部相对位置、三种手模式（80/10/10）与一组假定的翻前面对动作混合（未被抬高 / 跛入 / 被加注 / 被再加注），按上述公式判断是否进池。

**保真度核对（必须先看）**：在当前参数（价格权重 450、每对手惩罚 35、基数 310）下，筛查给出 `0.0743 / 0.1205 / 0.1015`（紧密 / 松凶 / 跟注），而**实测为 `0.045 / 0.088 / 0.080`**（`docs/54c` §5.5）。即筛查**系统性高估约 30–40%**，且在被判定为「过松」的设置下会饱和到 0.6 以上（明显失真）。

**结论：该筛查只能用于判断方向与主控量，不能用于定值。** 任何参数取值都必须由授权运行实测确认。

## 5. 筛查暴露的三项结构性结论

1. **只调阈值不足以达标**：把价格权重与人数惩罚降到能抬起紧密型的水平，会同时把三档整体推向上限之外（上表最后两行）；必须在「抬起下限」与「不顶到上限」之间同时约束。
2. **现有风格参数无法满足「两两差 ≥ 0.05」**：翻前进池只由 `S` 与阈值比较决定，而 `S` 中唯一的风格量是 `looseness = 紧密 −35 / 松凶 +35 / 跟注 +10`。松凶必然比跟注更松——**跟注型不可能成为进池率最高的一档**，而目标带要求任意两档相差 ≥0.05，现状下「松凶–跟注」这一对必然违背（实测两者相差仅 −0.008，与 R3 的 JS 距离 0.069 同源）。因此 M2 必须改变风格在**翻前**的作用方式，而不是只调全局阈值。
3. **翻前基础分存在连张/缺张倒置**（疑似缺陷，需单列）：公式取 `gap = 高低点差 − 1`，再接 `{1:35, 2:20, 3:5}`，于是**连张（gap=0）不加分、单缺张（gap=1）反而加 35**。只读核对：`KQo=429 < KJo=454`、`98s=287 < 97s=312`。这会直接改变进池手牌集合。

## 6. 拟修改项（候选项，未裁定）

### M2-1 翻前价格项与深筹码项口径

为翻前单独确定价格项权重与 `depth` 是否施加（当前二者把门槛抬到基础分之上）。边界：不改 `_preflop_base` 的公式形态，不动后翻后的价格口径，不动 `heuristic.py`。

### M2-2 风格的翻前专属偏移与排序

为每种风格引入**仅作用于翻前**的评分偏移（新参数，不动全局 `looseness`，以免连带改变已校准的翻后行为），并明确排序：**跟注型进池最松、松凶次之、紧密最紧**；而松凶继续以**主动率/PFR**（而非进池率）区别于跟注型。这是同时满足「两两差 ≥0.05」与人格语义的唯一可行方向。

### M2-3 连张/缺张倒置的处置

两种立场需用户择一：**(a) 保持不动**（它是已冻结公式的一部分，改动会影响非 M2 的节点）；**(b) 在本批一并修正**（把加分改成按真实点差，使连张 ≥ 单缺张）。建议 **(a) 暂不动**：它不影响目标带的可达性，混入本批会让「标定结果」与「公式修正」互相掩盖。

## 7. 标定与验收流程

- **M2a（实现与回归）**：按 M2-1 / M2-2 改动，注册累积版新身份 `mixed-local@3`（首版 + M1 + M1b + M2），配套针对性回归（翻前门槛、风格排序、非翻前节点逐位不变）。**不实跑。**
- **M2b（标定运行，需另行授权）**：一次授权运行给出三档实测 VPIP（同一 4,224 手设计、同一四个主种子、不新增种子），逐项对照目标带。
- **迭代性质必须披露**：若未达标需调参重跑，**每次重跑都是开发证据**，按 `docs/53` §13.2 **不得**被表述为独立质量验证；达标之后若需要质量结论，仍须另立预注册设计。
- **成本披露**：进池率上升会让更多牌局进入翻后，对抗批次耗时上升；冻结节点的成本矩阵读数不受影响。每次标定运行预计与 `docs/54c` 同量级（阶段 B 123.6s + 补算 68.3s）。

## 8. 回归风险清单

1. 非翻前节点：M2 只应改动翻前；`shared-board` 等翻后节点的分布必须逐位不变（由回归锁定）。
2. 风格语义：`calling` 的 PFR 应继续贴近 0，`aggressive` 的 PFR/主动率应继续最高——不得为了 VPIP 间隔把三档压成同一种打法。
3. 信息边界与随机隔离：不得读取对手底牌，不得引入新的随机维度。
4. 决策延迟：新增参数不得引入按人数或筹码展开的循环；`DECISION_BUDGET_MS=100` 与 50/80ms 指导值不变。
5. 旧身份与证据：`mixed-local@1` / `@2` 的分布、摘要与已落盘回执零改动。
6. `docs/37` §3.1 五项（参考实现、保守判据、`equity` 实现、采样数、固定种子）零改动。
