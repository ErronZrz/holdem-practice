# 59 当前工作成果诊断与后续工作边界

> 日期：2026-09-23。
>
> 本文是对现有代码、已归档文档和已落盘验证记录的综合诊断，供后续策略研发、验证设计和产品决策参考。它不改写任何历史签收结论，不构成代码实施、样本冻结、外部评测运行或默认策略切换的授权。

## 1. 定位与结论

当前平台已经具备可进行多人数对局的规则引擎、基础 Web 对局、复盘能力，以及一个可运行的本地规则型混合 Bot。当前工作的主要瓶颈不是“能否让 Bot 行动”，而是如何证明它在目标产品定义下具有足够的对局质量。

本诊断的结论如下：

1. `mixed-local@6` 的机制与本机运行成本已有支持，但质量未获支持；默认策略继续保持 `heuristic@1`。
2. 当前的质量失败不是单纯由样本波动、工程遗漏或某一个阈值造成；策略结构存在值得修复的信号。
3. 当前 L4 的统计对象和“一刀切”通过条件又比产品目标严格得多，不能把它直接等同于长期对局强度或玩家体验。
4. 完整 CFR 不是当前完整 Bot 路线的必经前置；Kuhn CFR 与受限多人 MCCFR 工具链不应被外推为真实多人无限注德州的均衡或不可剥削证明。
5. 后续最有价值的工作不是只换一批样本重跑，而是先形成可归因、可回归的反例驱动改造规格，再决定是否创建新策略身份和独立验证战役。

本文与 [`phase6/57k-m8-third-verification-criteria-judgment-and-signoff-record.md`](phase6/57k-m8-third-verification-criteria-judgment-and-signoff-record.md) 的正式签收结论一致；后者仍是 `mixed-local@6` 当前质量判定的依据。

## 2. 已取得的有效成果

### 2.1 牌局与策略运行基础

现有系统具备按 2–9 人设计的牌局规则、合法动作、短码、边池、摊牌与筹码守恒等基础能力。策略层与牌局规则边界清晰，混合 Bot 使用行动者视角投影和公开摘要，不应读取其他座位暗牌。

`mixed-local` 的运行机制具备以下正向属性：

- 牌堆与 Bot 随机流从同一主键分域派生；
- 不同 Bot 座位、不同手号和不同事件号使用分离的派生流；
- 每个座位固定一种基础风格，并有每手级别的受控模式变化；
- 策略输出是合法动作和有限尺度上的离散分布，概率单位以整数表示；
- 现有本机验证中，规则、信息边界、重放和大样本延迟都有已落盘读数。

这些是“可运行、可追溯、避免完全确定性动作模式”的基础，不应被低估。

### 2.2 CFR 工具链的正确定位

[`phase2/25-m7-kuhn-cfr-toolchain.md`](phase2/25-m7-kuhn-cfr-toolchain.md) 证明了小型两人零和 Kuhn 博弈中 CFR、平均策略、精确 best response 与 NashConv 的工程链路。`phase3/` 的多人 Candidate A 则验证了受限抽象下的训练、导出、探针和资源控制链路。

这些成果可用于：

- 小型抽象博弈的教学与回归；
- 离线策略校准；
- 发现明显的动作失衡；
- 验证训练、工件和加载流程。

它们不能用于：

- 声称当前线上 Bot 是 CFR lookup；
- 声称真实多人无限注德州近似均衡；
- 声称已得到 exploitability、NashConv 或不可剥削上界；
- 替代完整 Bot 的行为质量验证。

## 3. 当前失败的证据与解释边界

### 3.1 L1 与 L2 通过的是必要条件，不是策略质量

第三次独立验证的 L1 记录了无违规、无截断、摘要一致、随机可重放和信息边界契约测试通过。L2 在 2–9 人、80,000 次端到端决策样本中没有超过 100ms 的读数，p95、p99 均低于指导值。

这些结果仅支持当前评测环境和指定路径上的正确性与成本：

- 不等同于生产并发、冷启动、长期运行或不同机器上的容量保证；
- 不等同于策略强度、风格质量或抗针对能力；
- 阶段 B 补算的峰值 RSS 已接近 1GiB 包络，且原因未归因，后续运行仍需单独监控。

### 3.2 L3 的关键失败是策略结构信号

在预先指定的翻牌面对下注机会域，tight、calling、aggressive 三档的主动率为 3.46%、5.12%、7.97%，两两差距均低于要求的 10 个百分点。因此，三种人格在这个高价值机会域中仍共同偏向被动。

这不是“随机流不够随机”的问题，而是策略分布的设计问题：规则评分、价值阈值、非价值进攻质量、候选过滤和风格参数共同决定了该局面下主动动作的概率。

同时应避免误读其他 L3 成绩：

- 动作混合覆盖、类型熵和 JS 距离有达标读数，但不自动说明难以被针对；
- 16 个种子块上的直接分布逐位相同，使“跨 seed 方向稳定”成为结构性必然，不能作为额外的独立稳定性证据；
- 10 个百分点的风格差要求是历史冻结门槛。它可以作为强诊断信号，但不应被偷换成唯一的产品可用性定义。

### 3.3 L4 的失败既不能忽视，也不能过度外推

L4 的绑定标准为：相对 `heuristic@1`，每个人数取最差对手族，其配对收益差 95% 区间下界必须不低于 `−5 BB/100`。第三次验证在 2–9 人均未满足。

[`phase6/57m-m8-l4-negative-difference-read-only-diagnostic-record.md`](phase6/57m-m8-l4-negative-difference-read-only-diagnostic-record.md) 给出了两个必须同时接受的事实：

1. **不能忽视的策略信号**：tight 风格在全部 8 个人数上为负；无人下注的手占总负差约 70%；强牌桶以较小样本贡献了较大的负差。它们提示紧手风格在无人下注、价值兑现或主动选择方面可能存在系统性问题。
2. **不能过度外推的统计限制**：配对单位是单手，`bb_per_100` 由单手净筹码换算；约三分之二配对差为零，极端底池造成很高方差，最差 3 个 seed 块贡献大部分负差。因此，L4 不是传统长期样本意义的胜率估计，也不是对玩家体验的直接测量。

所以，L4 的正确含义是：

> 在这套固定、严格的独立评测设计下，当前新策略不能证明自己相对旧启发式在所有人数和最差探针族上不劣化。

它不等同于“新策略毫无价值”，也不等同于“旧启发式是更强的真实扑克策略”。但在未设计新的有效质量框架前，它足以阻止默认策略切换。

### 3.4 L5 不能被表述为不可剥削性验收

当前 L5 是有限探针和分桶诊断，不运行 best response，也没有数值通过线。它可以帮助发现已知漏洞、观察针对性风险和定位可疑桶；它不能给出 exploitability、NashConv、best response 上界或“不可剥削”的结论。

从此以后，产品与技术文档应使用“未观察到某类已定义探针风险”这类边界表述，而不是“不可剥削”或“近似 GTO”。

## 4. 造成长期反复不达标的主要盲区

### 4.1 目标、机制与验收指标未完全对齐

产品优先级是：三维不可预测性优先，其次是可控运行成本，最后是尽量减少可剥削性，且允许人格具有适度弱点。

当前策略机制是固定规则评分加受控随机混合；当前 L4 却要求新策略在每个人数和最差对手族上几乎不允许弱于旧策略。这更接近严格支配检验，而不是“有清晰人格、足够挑战且不易陷入固定模式”的产品检验。

若不显式区分以下目标，研发会持续在互相冲突的方向上调参：

- 动作随机性：同一局面不总是同一动作；
- 行为不可预测性：对手不易从历史行动推断条件化策略；
- 策略强度：长期对局结果不显著劣于可信基线；
- 抗针对性：已定义的攻击性策略不能稳定获得不可接受收益；
- 人格可感知性：玩家能在合理样本内察觉三种风格的区别。

### 4.2 随机混合不等于战略不可预测

由 HMAC 派生的随机流和按事件隔离的抽样，能够减少随机消费相互干扰；但若动作概率仍由固定阈值决定，长期观察者仍可能学习其条件化行为边界。

另外，显式 seed 适合测试和重放；当调用方可以选择并知晓 seed 时，牌堆与 Bot 行为可被复现。面向对抗性生产局时，服务端应独占随机根密钥，显式 seed 应仅限开发或受控调试场景。

### 4.3 先验证、后归因，导致迭代信息密度不足

v6–v8 的冻结纪律、失败保留和口径披露是正确的；问题不在审计流程，而在策略改造前缺少足够细的因果假设。

继续在综合样本上重跑，只能再次告诉我们“当前分布不满足当前门槛”。更高信息密度的顺序应是：

1. 用固定反例集定位具体局面与行为；
2. 提出能解释失败机制的改动；
3. 明确该改动可能伤害哪些已达标指标；
4. 为每条风险补充针对性回归；
5. 仅在此后创建新策略身份、重新标定和独立验证。

### 4.4 将单一旧策略视为全局质量基线

`heuristic@1` 是当前默认策略和重要对照，但不是经证明的真实扑克强度上界。以它作为唯一全局不劣化基线，会把“所有新人格都在每一个角落不弱于旧策略”与“允许人格有适度取舍”的目标混在一起。

未来若设计新的质量框架，应至少分开评估：

- 策略池整体相对基线池的长期表现；
- 每种人格的角色契约与明显失衡；
- 已定义攻击探针的长期收益；
- 玩家可感知的风格差异与重复感。

任何新框架只适用于新的策略身份与新的验证战役，不能追溯改写 v6–v8 的历史判定。

## 5. 后续工作的固定护栏

### 5.1 必须继续遵守的边界

- 默认策略继续为 `heuristic@1`，直到新的策略身份获得新的质量签收。
- 不把开发标定、单次 benchmark 或可重放测试表述为独立质量通过。
- 不把有限探针表述为 best response、exploitability 或不可剥削证明。
- 不以改门槛、换分母、删样本、换 seed 或事后选择节点的方式处理已冻结战役的失败。
- 不重写历史策略身份、历史工件或已签收结论。
- 不让 LLM 参与实时动作合法性与牌局规则判断。
- 不把 CFR 的小博弈结论外推到真实多人无限注德州。

### 5.2 应优先补齐的诊断能力

下一轮策略研发前，应先构建只读或开发期使用的反例与分层评测能力。它至少要覆盖：

- 翻牌面对下注时，不同牌力、听牌、SPR、位置和下注尺度下的分布；
- 无人下注时，不同牌力、人数、位置和底池规模下的下注/过牌选择；
- strong 桶的价值下注、慢打和弃牌行为；
- tight 风格在 2–9 人中的翻前入池、翻后主动与摊牌表现；
- 三种人格在相同可行动局面中的动作与尺度差异；
- 对手动作线变化时，策略分布是否产生合理且可解释的变化。

这些工具应只读取行动者可见信息，不能成为线上策略读取隐藏信息的通道。

### 5.3 新身份改造规格的最低要求

若后续选择新策略身份，必须先产出一份独立的反例驱动改造规格。每一项候选改动必须写明：

1. 暴露问题的局面类型与可复现反例；
2. 现有规则为何会产生该行为；
3. 拟改动的策略机制，而非仅列出希望跨过的指标阈值；
4. 预期改善的行为和可能恶化的行为；
5. 对应的针对性回归与不变量；
6. 是否涉及随机性、信息边界、合法性、成本或策略身份语义的变化。

不应直接根据“域二差距不足 10pp”或“L4 下界低于 −5”反向调常量。阈值是验证结果，不是设计因果。

## 6. 推荐推进顺序

### 阶段 A：反例驱动诊断

不修改默认策略、不运行独立验证。建立能复现和解释关键局面的开发期诊断，并形成问题清单。此阶段的产出是证据与假设，而不是质量结论。

### 阶段 B：改造规格与针对性回归

选择少量有因果依据的问题，完成新身份改造规格。先补回归，再实施策略变更，保持 `@1`–`@6` 的历史含义不变。

### 阶段 C：新身份标定

对新身份进行开发性标定，检查规则合法性、信息边界、可重放、成本、分布和风格差异。标定不替代独立质量签收。

### 阶段 D：重新预注册的独立验证

仅在新身份和针对性回归稳定后，冻结新节点、新种子、判据和工件口径，运行独立验证。应将新框架中“产品质量”“强度风险”和“抗针对诊断”的结论分别报告。

## 7. 当前不建议做的事情

- 仅更换样本集后直接运行第四次独立验证。该路线可以检验结论稳定性，但不能改变已知的翻牌面对下注分布结构，预期仍不足以支持质量。
- 在没有反例规格时直接创建 `mixed-local@7` 并调节规则常量。
- 为让 L4 通过而回溯修改历史判据，或把 L4 的统计限制当作忽略策略失败信号的理由。
- 为追求“不可剥削”而直接上完整真实德州 CFR。其状态空间、多人常和博弈语义、训练成本和产品收益均不支持把它作为当前阻断项。
- 把 `mixed-local` 的随机抽样、风格熵或低延迟表述为对抗性安全或扑克理论强度认证。

## 8. 状态摘要

| 主题 | 当前可支持的结论 |
| --- | --- |
| 对局规则 | 可运行的多人牌局引擎与合法动作链已具备。 |
| 完整 Bot | 已具备本地规则型混合 Bot，存在固定风格和受控混合。 |
| 不可预测性 | 有动作混合和随机流隔离基础；关键机会域的人格差异不足，且不能宣称战略上难以针对。 |
| 运行成本 | 当前本机评测的决策成本读数良好；部署容量与补算内存余量仍需谨慎。 |
| 不劣化 | 当前独立验证不支持相对 `heuristic@1` 的不劣化。 |
| 不可剥削性 | 未证明；有限探针只能形成风险诊断。 |
| CFR | 小型/受限抽象工具链可用，不是当前线上完整 Bot 的质量证明。 |
| 默认策略 | 保持 `heuristic@1`。 |
| 下一有效产出 | 反例驱动改造规格，而不是直接调参或只换样本重跑。 |
