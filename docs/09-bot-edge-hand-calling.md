## 2. 实现细节

### 2.1 翻牌前：从「三档」改为「六类」处理

沿用 Chen 公式打分，但不再简单映射到强/中/弱三档，而是按分数与牌型结构分六类处理：

| 类别 | 判定 | 动作 |
|---|---|---|
| 强牌 | Chen ≥ 12 | 能下注/加注就下注/加注，否则过牌/跟注 |
| 中牌 | Chen ≥ 8 | 免费过牌；面对 ≤ 3/2 底池的注跟注，超出则弃牌 |
| A 大踢脚高牌 | 含 A 且另一张 ≥ T（如 ATo） | 与中牌同等：面对 ≤ 3/2 底池的注跟注，超出则弃牌 |
| 小对子 | 两张同点（且 Chen < 8） | 免费过牌；面对下注时按隐含赔率决定：跟注额 ≤ 剩余筹码 1/15 才跟（博暗三条），否则弃牌 |
| 投机边缘牌 | Chen ≥ 5 且非对子 | 免费过牌；面对 ≤ 1/2 底池的小注跟注，超出则弃牌 |
| 纯垃圾牌 | 其余 | 免费过牌，否则弃牌 |

关键变化：

- 小对子 `22~77`（Chen 5~7）不再落入「见注就弃」，而是按隐含赔率博暗三条。
- 同花/连张边缘牌（如 `T8s`）面对小注可便宜入池。
- A 大踢脚高牌（`ATo` 等，Chen 公式仅打 6 分）被单独提升到中牌待遇，不再面对常规加注直接弃牌。
- 中牌不再是「无条件跟注」，面对超底池巨注会弃牌（原来 MEDIUM 会一直跟）。

### 2.2 翻牌后：区分「底牌击中」与「公共牌白送」

先用 `evaluate(底牌 + 公共牌)` 得 `HandRank` 分档；关键在区分牌力是「底牌真正击中」还是「公共牌白送」——例如翻牌 `AAA` 时所有玩家都保底三条，此时底牌若只是散牌（如 `K8`）胜率并不高，只有底牌成对（成葫芦）才算强。此外，高牌（无对子）时进一步统计补牌数（outs）以体现听牌价值：

| 类别 | 判定 | 动作 |
|---|---|---|
| 葫芦及以上 | 葫芦/四条/同花顺 | 下注/加注，否则过牌/跟注 |
| 底牌三条 | 三条且公共牌无三张同点（set / trip） | 无人下注时主动下注；面对下注跟注（不主动加注） |
| 公共牌三条 | 三条且公共牌已三张同点（底牌只是踢脚） | 无人下注时下注；面对 ≤ 3/2 底池的注跟注，超出弃牌 |
| 顺子/同花 | 顺子、同花 | 无人下注时主动下注；面对下注跟注（不主动加注） |
| 顶对/两对 | 两对；或对子点数 ≥ 公共牌最大点数 | 无人下注时主动价值下注；面对 ≤ 3/2 底池的注跟注，超出则弃牌 |
| 中/底对 | 一对且对子点数 < 公共牌最大点数 | 免费过牌（控池）；面对 ≤ 3/2 底池的注跟注，超出则弃牌 |
| 强听牌 | 高牌且 outs ≥ 12（组合听） | 主动半诈唬下注；否则跟注/过牌 |
| 常规听牌 | outs ≥ 8（同花听/两头顺） | 免费过牌；面对 ≤ 3/4 底池的注跟注，超出则弃牌 |
| 弱听牌 | outs ≥ 4（卡顺） | 免费过牌；面对 ≤ 1/4 底池的注跟注，超出则弃牌 |
| 纯空气 | 其余 | 免费过牌，否则弃牌 |

- 底牌三条与公共牌三条的区分用 `_board_has_trips` 判断：公共牌是否已有三张同点；只有底牌参与的三条（set / trip）才按强牌对待。
- 听牌识别仅在翻牌/转牌进行（河牌已无补牌），河牌高牌直接按纯空气处理。
- outs 用枚举剩余 47 张补牌、逐一 `evaluate` 的方式统计，天然覆盖同花听（4 张同花时约 9 outs）、顺子听及组合听，无需单独实现各类听牌判定。

## 3. 与 05 文档的偏差

| 点 | `05-m2-basic-bot.md` 表述 | 实际落地（本文档） |
|---|---|---|
| 牌力分档 | 统一三档 `Strength`（WEAK/MEDIUM/STRONG） | 删除 `Strength` 枚举，翻牌前按「强/中/A 大踢脚/小对子/投机/垃圾」、翻牌后按「葫芦+/底牌三条/公共牌三条/顺子同花/顶对两对/中底对/听牌/空气」分类处理 |
| MEDIUM 动作 | 面对下注无条件跟注 | 改为赔率敏感：面对超底池巨注弃牌；顶对/两对改为主动价值下注 |
| WEAK 动作 | 面对下注直接弃牌 | 高牌时先识别听牌，有潜力则按赔率跟注/半诈唬；纯空气才弃 |
| 内部函数 | `_preflop_strength` / `_postflop_strength` / `_select` | 重构为 `_preflop_action` / `_postflop_action` / `_aggressive` / `_strong_value_action` / `_value_action`，并新增 `_call_within` / `_set_mine_within` / `_draw_outs` / `_board_has_trips` 辅助 |

## 4. 与 08 文档的偏差（候选方向落实情况）

`08 §3` 提出的五个候选方向，本次落实如下：

| 方向 | 落实情况 |
|---|---|
| 1. 阈值/分档调整 | 已实现：小对子、同花连张、A 大踢脚高牌不再落入「见注就弃」 |

## 6. 已知取舍

- 仍为**确定性策略**：未引入随机化混合，弱听牌/投机牌的跟注阈值是人工拍定的启发式，非 GTO；后续 CFR（M7/M8）或混入随机可增强。
- 位置感知未做：前位/后位使用同一范围，属已知可预测性，后续可注入位置维度。
- 听牌 outs 采用枚举补牌 + 逐张评估，逻辑简单通用但每次决策点有常数级评估开销；实测压力运行无性能问题。
