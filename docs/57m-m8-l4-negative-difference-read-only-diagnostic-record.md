以下只陈述「证据指向什么」，供用户回答「是否值得新开身份重做」，**不构成**对任何判据的修改建议：

1. **L4 的配对单元是单手**，逐对 `bb_per_100` 为单手提纯（标准差 `7,217.41`，极值达 `±80,000`）。因此 L4 的块均值与区间由极少数大额底池主导。
2. **三分之二的配对逐手同结果**（`65.73%`），净值仅为绝对值之和的 `15.7%`。
3. **负差高度集中在块级**：最差 3 / 16 块贡献 `78.68%`；但**任何单块退出都不足以**把下界抬回 `-5` 以上（最好情形仍为 `-447.48`）。
4. **不存在单一主导格**：最大单格仅占 `6.42%`，前 12 格合计 `46.40%`。
5. **符号不一致是普遍现象**：人数（`N=6`、`N=9` 为正）、风格（`calling` 为正）、对手族（`heuristic@1` 近零、其余为负）、以及 7 / 8 个族的人数切片均出现翻转；唯一无翻转的切片是 **`tight` 风格在 8 个人数上全负**。
6. **桶层面的负差集中在「无面对下注」的手上**（`67.41%` 的对数、`70.06%` 的负差），而非「对下注的应对」；`strong` 牌力档小样本（`5.57%` 对数）贡献 `30.14%`。
7. **族集在 `N ≥ 6` 上实际只有 7 种行为**（§5.9），因此「8 族」上的任何聚合读数在 `N ≥ 6` 上并非 8 个独立行为。

**证据面的净判断**：负差**没有**落到少数可指向、可修复的机制格子上；它同时表现为「块级集中 + 格级分散 + 符号普遍翻转 + 大额底池主导」。因此**在既有冻结集合上无法**识别出单一可修因；同时，本诊断也**不能**回答「换新身份后 L4 会变好」——`@6` 与任何新身份的 L4 表现仍在样本外。

**不得**由本节推出「L4 判据有误」「应改判据」或「已证明是噪声」：本文件不重算判据、不重设区间、不重选估计块，判定与签收以 `docs/57k` 为准，**未被触碰**。
