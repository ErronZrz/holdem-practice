## 6. X1：L4 区间的唯一方法（逐字，产生读数前锁定）

**主口径**：把 8 个种子块推广为 `S` 个种子块（`S = 16`），在**最差族**上取块均值序列，构造双侧 95% 的 t 区间：

```text
区间 = 块均值 ± t(0.975, S-1) × 块标准差 / sqrt(S)
判定 = 区间下界 ≥ -5 BB/100
S = 16 时 t(0.975, 15) = 2.131
```

**强制并列报告**（不得省略）：块均值、块标准差、块极值（min / max）、逐人数分解。

**保守处置（已确认）**：若两口径结论不一致（t 区间下界 ≥ `−5` 而块极值下界 < `−5`），判为**未满足**。理由：避免在读数之后争论应当采用哪个口径。

**必须一并声明**：块数虽由 8 增至 16，仍属**小固定种子集**，`interval_status=not-estimated-small-fixed-seed-set` 的口径**不变**；即使达标也**不得**表述为稳健达标（`docs/55` §10.4.2 第 5 条）。

5. **探针重叠（`docs/55h` §6）使名义族多样性低于 8**，本次**不修**（§4.6），故 L5 的探针池有效性仍受此限制。
