### 5.2 `P2-A`：主动分支尺度（`A-2`）

| 项 | 明细 |
|---|---|
| 新增字段 | `active_scale_percent: int = 1`——主动分支的尺度倍率；**默认 `1` 等价于现状**，故 `@1`–`@5` 的分布**逐位不变** |
| 分派位置 | `build_distribution` 中主动权重倍率的构造处（现为 `aggression_scale = Fraction(aggression_percent × 模式百分, 100)`，位于 `mixed_policy.py` 约 `271–273` 行） |
| 新口径 | `aggression_scale = Fraction(aggression_percent × 模式百分 × active_scale_percent, 100)` |
| `@6` 取值 | `10` |
| 为什么不是 `100` | `100` 会让主动项与被动项**完全同量级**，面对下注的主动份额可能从不足 `1%` 跳到数十个百分点，属一次过大的跳变；`10` 只缩小一个数量级 |

### 5.3 `P2-C`：人数惩罚带上限（`C-1`）

| 项 | 明细 |
|---|---|
| 新增字段 | `contender_penalty_cap: int = 0`——人数惩罚上限；**`0` 表示不设上限**，等价于现状 |
| 分派位置 | `_score` 中 `contender_penalty = per_opponent × (contenders − 1)` 之后（`mixed_policy.py` 约 `316` 行）；**必须放在「共享牌面锁定则惩罚清零」之后**，保持该分支的优先级不变 |
| 新口径 | `contender_penalty = min(cap, contender_penalty)`（当 `cap > 0`） |
| `@6` 取值 | `70`（等价于最多只扣两名对手的量：`contenders − 1 ≤ 2` 时**与 `@5` 完全相同**） |

5. **新身份需完整标定**，标定本身**不是**新的独立验证；
6. **开发证据 ≠ 独立验证**：`R-*` 与任何固定对照只属开发证据；独立验证仍须按 §5.6 第 3–5 步冻结全新清单与种子后单独授权运行；
