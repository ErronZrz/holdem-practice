### 5.1 必须一并读的标签语义警示

`focus_strength_bucket` 由「**焦点自身底牌 + 手牌结束时的公共牌**」评估而来，**公共牌本身即可抬档**（例如公共牌成花时全桌同为该档）。因此：

- **不得**把 `medium` / `strong` 读作「焦点独占的强牌」；
- **不得**据此说「Bot 拿着强牌还输」；
- 该标签是**派生档位**，不是牌面、不是对手范围，也不是 EV。
