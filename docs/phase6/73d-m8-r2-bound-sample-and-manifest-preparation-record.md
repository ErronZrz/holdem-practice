## 2. 域 C：R2 的解析统一上界与样本量

### 2.1 上界推导

`73b` §4.4.1 给出每个 `N` 的片段统计量上界：

```text
M_N = 2 · (N − 1) · S · 100 / BB
    = 20,000 · (N − 1) BB/100
```

对 R2，不以任何实测离散度推导方差。对任意预注册的非负且和为 `1` 的块内片段权重，块级量 `X_j` 都是位于 `[-M_N, M_N]` 的凸组合。因此：

```text
Var(X_j) ≤ (max(X_j) − min(X_j))² / 4 = M_N²
V_j ≤ V_max,N := M_N²
```

该界等价于 `73b` §4.4.2 中「只能取保守协方差界时，R2 退化为 `M²`」的情形。它与候选身份读数、具体 seed 和未来清单独立，并覆盖全部未来块；但不构成对逐块 `V_j`、片段间协方差或 `V_max` 的冻结证明。

| `N` | `M_N`（BB/100） | `V_max,N = M_N²` |
|---|---:|---:|
| 2 | 20,000 | 400,000,000 |
| 3 | 40,000 | 1,600,000,000 |
| 4 | 60,000 | 3,600,000,000 |
| 5 | 80,000 | 6,400,000,000 |
| 6 | 100,000 | 10,000,000,000 |
| 7 | 120,000 | 14,400,000,000 |
| 8 | 140,000 | 19,600,000,000 |
| 9 | 160,000 | 25,600,000,000 |

### 2.2 逐项水平与 R2 块数

```text
α_C′ = 0.05 / 16 = 0.003125 = 1/320
β_C′ = 0.20 / 16 = 0.0125 = 1/80

max{(1−α_C′)/α_C′, (1−β_C′)/β_C′}
= max{319, 79}
= 319
```

代入 `73b` 的 R2 解算式：

```text
B_N ≥ (4 · V_max,N / m²) · 319
    = 12.76 · V_max,N
```

按钮位必须等权轮换，因此准备块数取 `B_N^button = N · ceil(B_N / N)`：

| `N` | 功效下限 `B_N` | 按钮均衡准备块数 `B_N^button` | 额外块数 | 每个按钮位块数 |
|---|---:|---:|---:|---:|
| 2 | 5,104,000,000 | 5,104,000,000 | 0 | 2,552,000,000 |
| 3 | 20,416,000,000 | 20,416,000,002 | 2 | 6,805,333,334 |
| 4 | 45,936,000,000 | 45,936,000,000 | 0 | 11,484,000,000 |
| 5 | 81,664,000,000 | 81,664,000,000 | 0 | 16,332,800,000 |
| 6 | 127,600,000,000 | 127,600,000,002 | 2 | 21,266,666,667 |
| 7 | 183,744,000,000 | 183,744,000,006 | 6 | 26,249,142,858 |
| 8 | 250,096,000,000 | 250,096,000,000 | 0 | 31,262,000,000 |
| 9 | 326,656,000,000 | 326,656,000,008 | 8 | 36,295,111,112 |
| 合计 | 1,041,216,000,000 | 1,041,216,000,018 | 18 | — |

**R2 结论**：在当前可得的纯解析界下，`V_max,N = M_N²` 是唯一可记录的统一上界，R2 明确退化为不优于 R1 的保守量级。该结论不是候选身份表现读数，也不授权以经验方差替换该界。

## 3. 域 A / 域 B：解析样本量

```text

    = 8 · max{ln(40), ln(10)} / 0.15²
    = 1,311.601583684955...
```

因此每个有向主判情境需要：

ln(1/α_B′) = ln(240) = 5.480638923342...

| 主判量 | 解析下限 | 向上取整块数 |
|---|---|---:|
