## 5. L4 不劣化（D4，**逐字照抄**）

- **判据**：相对 `heuristic@1` 的**最差族配对收益差 95% 区间下界 ≥ `−5 BB/100`**；
- **配对设计**：同牌堆派生流、同位置、同起始深度；**不得**把新动作接到旧历史后缀算反事实 EV；
- **最差族**：逐人数**各自**取最差族（`docs/55g` §7 先例）；
- **双向报告**：最大正偏离与最小负偏离**都须报告**，不得只报有利一侧；
- **数值性质**：`−5 BB/100` 是 `docs/20` §6.2 明确标注为**未拍板**的对手风险预算，**不是**教学 / GTO 标准；本裁定把它纳入**仅限本次**的绑定判据，**不使它成为通用门槛**。

## 6. L5 抗针对（D3，**逐字照抄**）

- 形态 = **扩充探针族** + **针对性诊断**；**不做**局部 best response，也不做任何 BR 构造；
- 对手族集沿用 `--family-set=iqv` 的既有 `8` 族：**不得**增删、重定义或替换（`docs/55h` §6 与 `docs/56i` §8 的探针重叠发现**均在产生读数之后**，据此增删即「按表现挑选族」）；
- 针对性诊断口径：比较探针在**前 20 手**与**更长样本**后的增益，按**尺度 / 牌力 / 街道**分桶**分别报告**；
- **结论边界**：不做 BR ⇒ 只能表述为「**本次样本集与本次探针池下未观察到 X**」；**不得**表述为「不可剥削」，**不得**作为 exploitability / NashConv / best response 上界；`shared-board` 的读数**只能**表述为「**读数存在、可利用性未检验**」。

## 7. 机会分母与两个机会域（**逐字照抄**）

### 7.1 机会分母（`docs/55a` §7.2）

| 指标 | 分母定义 |
|---|---|
| 实质动作混合覆盖率 | **非强制节点**：至少两个合法动作可选的决策节点；另按**翻前 / 面对下注 / 免费行动**分域报告 |
| 平均类型熵 | 固定估值 seed 下的策略内分布（**不得**靠降低 MC 样本制造抖动） |
| 额度多样性 | 条件于已选 `BET`/`RAISE`，**同额合并**后的可区分锚点 |
| 风格可分度 | **预先指定的两个机会域**（见 7.2） |
| 风格稳定性 | 同 session 配置 / 身份连续；换按钮 / rebuy 不重抽 |
| 成本 | 逐人数各自统计，**不把合并均值当各人数通过** |

### 7.2 两个机会域（`docs/55a` §7.5）

| 域 | 定义 |
|---|---|
| **域一（翻前）** | **翻前未开池节点**上的**进池概率**（`call` / `bet` / `raise` 合计） |
| **域二（翻牌面对下注）** | **翻牌面对下注**节点上的**主动概率**（`bet` / `raise`） |

判定读数：同一局面、同一估值 seed 下不同风格的条件分布之差；**至少两档**在两个域上各 ≥10 个百分点。

**本轮的具体归属**取自判定模块的实现（口径来源见 §9），**不另写**：域一 = `unopened-open` 类节点；域二 = `flop-draw` 类节点。本轮**不改**任一取值的定义来源。

## 10. 绑定与处置（**逐字照抄** `docs/55` §10.4）

1. **判据在冻结样本上的判定结果直接决定本次质量签收结论**；绑定范围**仅限本次独立验证**；
2. 签收时**不得**新增判据、**不得**修改判据、**不得**删除失败样本、**不得**按结果换 seed、**不得**按结果更换机会分母；
3. 判定结构：观测数 `<2` 明确失败；同一判定内 seed 唯一；同一判定内人数一致，**逐人数各自独立判定**，**禁止跨人数归因**；
4. **未满足的前置（如实记账）**：「用更多 seed 估计判定反转频率」本次**未做**。因此即使判据全部满足，结论也只能表述为「**本次独立验证下判据满足**」，**不得**表述为稳健达标、质量已证明或不可剥削；
5. **判据未满足时的对称处置**：结论为「**质量未获支持**」，默认策略**保持 `heuristic@1`**；此时**不得**改判据、不得重跑同一集合、不得把同一集合反复调参后称为独立验证；若需再试，须**新开身份或新样本集并重新预注册**，且运行需单独授权；
6. 判定的误差项必须如实标注：判据**不是** best response、**不是** NashConv、**不是** exploitability。
