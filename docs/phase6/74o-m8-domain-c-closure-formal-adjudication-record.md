- **时点**：在该对象**首次被 ② 或 ③ 使用之前**完成锁定；不得先使用、后锁定。
- **锁定内容**：对每个对象写定——版本；适用范围；取值或规则；来源（规则推导、块模板或设计裁定，不得来自任何身份读数、实测离散度、成本读数或历史机械量）；可执行判据。
