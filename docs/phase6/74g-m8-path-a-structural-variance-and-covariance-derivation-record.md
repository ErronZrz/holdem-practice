## 2. 本次推导新增的只读核验事实（实现侧）

为使前提表述准确，本轮执行了以下**只读**核验（未改任何文件）：

1. `backend/app/poker/engine.py`：引擎持有**单个** `random.Random` 与**单个** `Deck`，`__init__` 时以 `seed` 初始化一次；`_begin_hand()` **不**重新播种。因此一个会话内各手的牌堆抽取来自**同一条推进中的随机流**，不是「每手一次独立抽取」。
2. 同文件：庄位每手顺时针轮转（会话内按手号确定，是手号的确定函数，不是随机依赖）。
3. `backend/app/strategy/mixed_strategy.py`：座位子策略不持有跨手推进的可变随机状态；行动随机量按 `(手号, 事件数)` 派生、手模式按 `(座位键, 手号)` 派生，二者都是纯函数。
4. `backend/app/strategy/mixed_context.py`：策略输入契约只含本手的公开摘要，不含跨手特征。

上述事实的用途只有两处：判定两条前提的**构造来源是否已具备**，以及为失效处置指明回退点。它们**不**是质量读数，**不**构成任何质量证据。

## 3. 记号与目标

```text
块 j 的块级量      X_j        （域 C：配对会话上的片段加权平均；
                              域 A / 域 B：层内节点取值的加权平均）
块级方差           V_j := Var(X_j)
统一上界           V_max      对全部未来块成立、且对指定权重类一致成立的上界
朴素界             (max(X_j) − min(X_j))² / 4 ，在 |X_j| ≤ M 时恰为 M²
退化判据           V_max < M² 必须严格成立；否则如实报告退化，不得称路线满足
```

概率空间（本次采用的口径）：以**块的外生随机源**为随机源——域 C 为会话的牌堆派生流种子与两臂各座位的派生流种子；域 A / 域 B 为外生节点种子 `σ_j` 及其层内抽样所用的随机量。块级量与块级方差都定义在该随机源之上；块与块之间的随机源相互独立（`74f` §3 已登记的块间独立构造）。

## 4. 域 C 的推导

### 4.1 对象

```text
每手配对差        d_h = m_h − b_h                （两臂在同一 deal、同一座位指派下的净筹码差）
每手规范化值      e_h := 100 · d_h / BB          （与片段口径一致的 BB/100 单位）
片段 f 的统计量   Δ_f = (1 / K_f) · Σ_{h ∈ f} e_h
块级量            X_j = Σ_f w_f · Δ_f ，  w_f ≥ 0 ， Σ_f w_f = 1
```

### 4.2 前提 C-1（每手有界，可由规则推出）

```text
|e_h| ≤ E ，  E := 100 · D / BB
D := 单手内配对差的最大筹码移动量
```

- **构造来源**：引擎规则给出的单手上限（筹码与盲注结构决定）＋ 判定单元口径「每手两侧全员重置为 `S`、手内不补码」。
- **可执行判据**：由规则推导 `D`（其为 `N`、`S`、`BB` 的确定函数），**不依赖任何读数**；推导式一旦修订必须同步重算。
- 与既有登记的关系：`73d` §2.1 登记的 `M_N` 与 `E` 在数值上是同一个量（单手取值界）。本记录不改变 `73d` 的登记，也不新冻结任何取值。

### 4.3 前提 C-2（块内手间去相关）——**本前提未建立**

要求：在一个块内，各手的牌堆抽取与两臂决策随机量互不相关（在块随机源的条件空间内按独立抽取处理）。

- **构造来源（当前状态）**：§2 只读核验显示——策略侧已具备每手 / 每事件派生的纯函数随机量（满足手间无状态），但**引擎侧不满足**：会话内各手共用一条推进中的随机流，因此同一会话内各手是**同一随机源的确定函数**，不能由「不同手号」推出独立。
- **两条可选实现路径（须先裁定其一）**：
  - **C-2a 强化形式（设计层）**：把「每手一抽」实现为「块种子 ＋ 手号 → 摘要 → 每手种子」，使每手的牌堆随机源是 `(块种子, 手号)` 的纯函数、且不含跨手推进状态。可执行判据：每手播种点的静态检查（无跨手推进的 RNG 状态、随机源只为 `(块种子, 手号, …)` 的函数）。
  - **C-2b 弱化形式（保留现状）**：接受「单条推进流近似独立抽取」这一**建模理想化**，并在预注册中写明。该形式不可由读数核验，其失效风险必须登记。
- **可执行判据**：见 `74f` §4.1 第 5 条要求的三条静态检查（无跨手保留的随机状态；每手随机量由纯函数派生；跨手状态被口径禁止）。核验不读任何身份输出。
- **失效处置**：C-2 不成立（存在跨手相关或跨手状态）⇒ 本节界**不成立**，回退到 §8 的 `M²` 并报告退化。
- **不使用条件零均值**：每手配对差的条件均值可以是常数 `μ ≠ 0`（这正是被估计的效应），这不影响对**方差**的界。本推导**不依赖**、也**不**使用 `74f` §4.2.2 所述的条件零均值结构。

### 4.4 协方差处置（分列）

```text
片段内（与 73b §4.4.2 的有限样本协方差和同形）：
  Var(Δ_f) = (1 / K_f²) · [ K_f·γ_0 + 2 · Σ_{ℓ=1..K_f−1} (K_f − ℓ)·γ_ℓ ] ，  γ_ℓ := Cov(e_h, e_{h+ℓ})
  由 C-2：  γ_ℓ = 0   (ℓ ≥ 1)
  由 C-1 与 Popoviciu：  γ_0 = Var(e_h) ≤ (max − min)² / 4 ≤ E²
  ⇒ Var(Δ_f) ≤ E² / K_f

片段间：
  Cov(Δ_f, Δ_f') = 0   （由 C-2；不得以「同一派生流」或「座位轮换」为理由）

块内：
  Var(X_j) = Σ_f w_f² · Var(Δ_f) ≤ E² · Σ_f w_f² / K_f

逐块上界（与模板对应）：
  V_j ≤ E² · Σ_f w_f² / K_f
```

**登记**：本节「协方差项为零」的**唯一**来源是 C-2。若 C-2 不成立，则必须改为对 `γ_ℓ`（`ℓ ≥ 1`）与片段间协方差给出非退化界，否则即为 §8 的退化情形。

### 4.5 统一上界与适用权重类

```text
对任意非负且和为 1 的权重：
  Σ_f w_f² / K_f ≤ (1 / min_f K_f) · Σ_f w_f² ≤ 1 / K_min ，  K_min := min_f K_f
⇒ V_max^C := E² / K_min ，且 V_j ≤ V_max^C
```

- **适用权重类**：**全部非负且和为 `1` 的权重**（`K_f` 由块模板冻结）。因此本式**不需要**权重先于推导固定（`74f` §4.2.3 的「明确适用类」要求在此以更强的形式满足）。
- **非退化性**：`V_max^C / M² = 1 / K_min`。只要 `K_min ≥ 2`，即**严格小于** `M²`。等权、等长片段的特例为 `V_max^C / M² = 1 / H`（`H` 为块内总手数）。
- **本记录不代入任何数值**，也不据此做样本量算术或包络估算。

## 5. 域 A / 域 B 的推导

### 5.1 对象

```text
层 ℓ 的节点取值   y ∈ [a_ℓ, b_ℓ]        （域 A：节点级 0/1 差 ⇒ [−1, 1]；
                                          域 B：节点级有界量 ⇒ 由枚举取值域给出界）
块 j 的层内均值   ȳ_{j,ℓ} = (1 / n_ℓ) · Σ_{i ∈ S_{j,ℓ}} y_i
块级量            X_j = Σ_ℓ v_ℓ · ȳ_{j,ℓ} ，  v_ℓ ≥ 0 ， Σ_ℓ v_ℓ = 1
```

层内取样数 `n_ℓ` 与层定义由块模板给出；本记录只要求「存在界 `[a_ℓ, b_ℓ]`」，**不**新冻结任何枚举或界值。

### 5.2 前提 AB-1（层内**无放回均匀抽样**）——**本前提未建立**

要求：每层 ℓ 的 `n_ℓ` 个节点是该层合格总体（规模 `M_ℓ`）的一个**均匀无放回**样本。

- **构造来源**：**设计选择**——把 `σ_j → S_{j,ℓ}` 的映射实现为「以 `σ_j` 为随机源的均匀无放回抽样」。该实现与 `73b` §5.7 的「确定性索引映射 ＋ 逐层取前 `n_ℓ` 个」**相容**，但后者**不保证**其所诱导的 `n_ℓ` 子集分布是均匀的。
- **明确登记**：`74f` §4.2.1 已写死「不得由 `σ_j` 的存在推出层内节点独立」；本记录进一步写死：**AB-1 不成立时，本节的 `1/n` 量级收紧不成立**，A1 保持未建立。
- **可执行判据**：在 `σ_j` 的取值空间与该层合格总体的**有限枚举范围内**，逐点验证「每个合格 `n_ℓ` 子集被抽到的次数相同」。该核验只读模板与枚举，不读任何身份输出。
- **失效处置**：AB-1 不成立（例如映射为固定偏移的系统抽样）⇒ 本节界不成立，回退到 §8 的 `M²` 并报告退化，或另行给出该映射下的界。

### 5.3 层内界（无放回均匀抽样 + 有界取值）

```text
Var(ȳ_{j,ℓ}) = (σ_ℓ² / n_ℓ) · ((M_ℓ − n_ℓ) / (M_ℓ − 1)) ，σ_ℓ² 为该层总体的（除以 M_ℓ 的）方差
Popoviciu：        σ_ℓ² ≤ (b_ℓ − a_ℓ)² / 4
⇒ Var(ȳ_{j,ℓ}) ≤ ((M_ℓ − n_ℓ) / (M_ℓ − 1)) · (b_ℓ − a_ℓ)² / (4 n_ℓ)
               ≤ (b_ℓ − a_ℓ)² / (4 n_ℓ)
```

**该界不使用任何手间 / 节点间的独立性理想化**：它只由「无放回均匀抽样」这一设计事实与「取值有界」这一规则事实给出；「负相关」不是被假设的性质，而是该抽样设计下方差恒等式的后果。

### 5.4 层间与块内协方差处置（显式）

```text
Var(X_j) = Σ_ℓ v_ℓ² · Var(ȳ_{j,ℓ}) + 2 · Σ_{ℓ < ℓ'} v_ℓ · v_{ℓ'} · Cov(ȳ_{j,ℓ}, ȳ_{j,ℓ'})
```

- **前提 AB-2（层间驱动独立，未建立）**：各层的抽样由相互独立的随机量驱动 ⇒ 层间协方差为 `0`。
- **否则**必须给出层间协方差界。可用的**无条件**保守界为
  `Cov(ȳ_ℓ, ȳ_{ℓ'}) ≤ (b_ℓ − a_ℓ)·(b_{ℓ'} − a_{ℓ'}) / 4`，代回后所得界与 `M²` 同阶，即**退化**。
- **写死**：因此层间协方差**必须**以非退化方式处置（例如由 AB-2 给出 `0`，或给出该层的显式独立驱动构造）；否则本路径退化为 §8。

### 5.5 统一上界与适用权重类

```text
在 AB-1 与 AB-2 下：
  V_j ≤ Σ_ℓ v_ℓ² · (b_ℓ − a_ℓ)² / (4 n_ℓ)
对任意非负且和为 1 的权重：
  Σ_ℓ v_ℓ² · (b_ℓ − a_ℓ)² / (4 n_ℓ) ≤ max_ℓ [ (b_ℓ − a_ℓ)² / (4 n_ℓ) ] · Σ_ℓ v_ℓ²
                                    ≤ max_ℓ [ (b_ℓ − a_ℓ)² / (4 n_ℓ) ]
⇒ V_max^{AB} := max_ℓ [ (b_ℓ − a_ℓ)² / (4 n_ℓ) ]
```

- **适用权重类**：**全部非负且和为 `1` 的层权重**（`n_ℓ` 与层定义由模板冻结）。
- **非退化性**：记 `R_ℓ := b_ℓ − a_ℓ`、`R_max := max_ℓ R_ℓ`、朴素界 `R_max² / 4`。由 `R_ℓ² / (4 n_ℓ) ≤ R_max² / (4 n_ℓ)` 得 `V_max^{AB} ≤ R_max² / (4 · min_ℓ n_ℓ)`，故收紧倍数**不小于 `min_ℓ n_ℓ`**；当各层取样数均 ≥ `2` 时严格小于朴素界。准确倍数取决于各层取值界与取样数的相对大小。
- **本记录不代入任何数值。**

## 9. 候选读数无关性与与 seed 无关性（声明）

- **输入清单（穷尽）**：引擎规则给出的单手上限；判定单元的重置口径；块模板的 `K_f` / `n_ℓ` / 层定义 / 片段划分；各层取值界 `(a_ℓ, b_ℓ)` 的来源；权重类定义。**不含**任何身份读数、实测离散度、成本读数或历史机械量。
- **与 seed 无关**：`V_max^C` 与 `V_max^{AB}` 的表达只含模板量、取值界与规则推出的常量，不含任何具体种子值或未来块依赖项 ⇒ 对全部未来块成立（这即「统一上界」的含义）。
- **与身份无关**：推导全程未引用任何策略输出、对局结果或身份记录；前提 C-2 的实现侧检查只读代码结构，不读输出。
- **与路径 A1 / A2 的关系**：本推导**不**使用 A2 的条件零均值；A1 的「层内节点独立」**未被使用**——本节用的是**无放回均匀抽样**这一更弱且可核验的结构，且该结构**尚未建立**（AB-1）。
