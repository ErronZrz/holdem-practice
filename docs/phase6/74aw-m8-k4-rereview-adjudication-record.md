## 3. e 的证据

审查方只读核验编排器与两臂同手夹具。`74as` §8.2 列了五条缺口。下表只对照原文与本轮所见，不把五条写成都已补上。

| `74as` §8.2 | 原文要点 | 本轮所见 |
|---|---|---|
| 1 | 没有夹具在同一手分别推进基线臂和被测臂 | `test_two_arms_share_seeds_before_the_fork_and_differ_after` 在同一手分别推进了两臂 |
| 2 | 没有夹具核对两臂非被测座位使用同一组六字段键和同一个整数 | 该夹具断言：分叉前，同座位、同序号、公开投影相同的决策，整数相同，且该集合非空 |
| 3 | 没有夹具在第一次决策之后，用一个未列入表的新 `sigma_public` 再查一次，并断言 `KappaMaterialMiss` | 该夹具对分叉后的键做了查表，并断言 `KappaMaterialMiss`。这次查的用途是 `non_probed`。版本 3 里该用途由主值派生，不依赖闭合集 |
| 4 | `test_listed_key_injects_baseline_seed_once` 只覆盖基线臂的一个非被测决策，不能代表分叉后的第二条投影 | 该旧夹具仍然只覆盖基线臂的一个非被测决策。新夹具记录的是分叉之后的派生整数，不是那一次查表 |
| 5 | `test_missing_key_stops_without_constructing_strategy` 只覆盖基线臂的空表，不覆盖被测臂 | 未补。现有测试仍只覆盖基线臂 |

编排器在给出主值时收集决策记录。这不是 `74as` §8.2 的缺口，它写在 `74av` §8。下表是本轮读到的夹具行为。

| 核对 | 结果 |
|---|---|
| 给出主值 | `play_hand` 把每次派生决策追加到内存列表并返回。每条是用途、六字段键、整数 |
| 没有主值 | 不收集，不写文件，不把查表结果记成派生记录 |
| 被测臂的被测座位 | 仍只查被测材料，不进入派生决策列表 |
| 夹具场面 | 同一副固定牌、同一固定主值。不调用随机源。材料表里只有被测材料 |
| 分叉 | 基线臂先走完。被测臂在被测座位上取一个与基线不同、且能让本手继续的动作，公开投影因此分叉 |
| 全程 | 两臂都走完整手，没有出现「键未登记」 |
| 分叉之前 | 同座位、同序号、公开投影相同的决策，整数相同。该集合非空 |
| 分叉之后 | 同座位、同序号、公开投影不同的决策，整数不同。该集合非空 |
| 查表 | 分叉后的键拿去查表失败。通过靠的是派生，不是预先登记 |
| 用途 | 基线臂的被测座位记为 `arm_b`。被测臂没有被测座位的派生记录 |
| 接通 | 两臂记录合并去重后，决策记录核验通过。改一条整数、改一条座位、重复一条键，各自失败 |

这是 2 人、单手、一个分叉场景的非实际夹具。它证明机制成立。它不是对实际 campaign 规模的断言。决策记录是否覆盖对局里的每一次派生注入，仍由 ⑦ 的对局日志在包外逐条对账。该对账没有发生。
