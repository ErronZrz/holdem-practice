**阶段 B 估算（方法披露）**

- 观测工件：按阶段 A 实测的 `1,315 B/手` 外推 `33,792` 手 ≈ **`42.4 MiB`**（**粗外推**）；
- 主报告：以 v6 阶段 B 的 `5.18 MB` 为底，加 `18,000` 行明细（≈`9.99 MB`）≈ **`15.2 MB`**（粗估）；
- 两者合计 ≈ **`55–57 MiB`**，**在 ≤100 MiB 输出包络内，但余量明显小于此前基于 4 族样本的估算**（该早期估算的 `29.27 MiB` 是在 `first-batch` 4 族下测的速率，**不适用于** 8 族口径——此处如实更正）；
- wall：以 v6 阶段 B 的 `283.146 s` 为参照，对抗手数由 `16,896` 增至 `33,792`，粗估 **`480–650 s`（8–11 分钟）**，**远低于 ≤1800 s 包络**；
- 峰值 RSS：**无可靠外推依据**（阶段 A 已 `+77%` 且**未归因**），必须在运行中**实测监控**。

**估算的已知薄弱处**：`docs/54h` 已有「估算偏差 41%」的先例；本次估算混用了两个版本的数据点。**估算不是读数**，不得作为成本验收；实际体积或耗时触及包络时**停止并如实报告**，不自行扩容。
