## 3. 问题界定（为什么必须解决）

### 3.1 三轮判定的共同结构

| 轮次 | 判定回执 | 计算方式 | 回执明文 |
|---|---|---|---|
| v6 | `docs/55g` | 现有字段 + **内联确定性计算** | 「其中**不含任何计算代码**」 |
| v7 | `docs/56h` | 同上 | 「其中**不含计算代码**」 |
| v8 | `docs/57k` | 同上 | 「其中**不含计算代码**」 |

⇒ 判定读数依赖**会话内的临时代码**，无法从工件独立复算。

### 3.2 实测影响面（7 组口径）

| 组 | 口径 | v7 公布值能否复现 |
|---|---|---|
| 1 | 实质动作混合覆盖率（含三分域与节点聚合） | **能**（`39.82%` / `56.38%` / `30.69%` / `0.00%` / `50.40%` 逐位一致） |
| 2 | 平均类型熵 | **能**（`0.3181` / `0.4221` / `0.3838`） |
| 3 | 额度锚点与金额条件熵 | **能**（`237/237`；`1.3999` 与分风格三值） |
| 4 | 两个机会域的风格可分度 | **不能**（公布 `20.22/33.91/13.69` 与 `0.35/0.03/0.38` pp；本实现 `30.71/54.92/24.22` 与 `0.62/0.25/0.37` pp） |
| 5 | 风格稳定性 | 列为可复现（同上：符号一致性，本实现同向） |
| 6 | 不劣化（逐人数 `8` 行） | **能**（均值 / t95 下界 / 块极值**逐行一致**） |
| 7 | 逐族收益与针对性诊断 | 逐族收益与**短/长段能**（`8` 行逐行一致）；**分桶计数不能**（公布有面对 `1,345`；本实现 `5,366`） |

**结论**：`7` 组中 **5 组可逐位复现**、**2 组不可复现**；不可复现的落点**恰是冻结文本对实现层保持沉默之处**。

### 3.3 根因

**口径的「定义层」已冻结，「实现层」从未落盘**。例如冻结文本只说「进池概率 = `call/bet/raise` 合计」，未钉死单元（逐行 / 逐节点 / 逐风格池化）、加权（units 池化 / 行均 / 节点均）、取值来源；只说「尺度 = 面对额度 ÷ 街起始底池」，未钉死取哪一臂、取哪次面对事件、额度语义。判定脚本跑完即弃 ⇒ 读数**不可独立复核**。

## 4. 本轮交付

| 文件 | 职责 |
|---|---|
| `backend/tests/mixed_bot_judgment.py` | 只读判定器：把读数口径实现为纯函数；**默认拒绝**；**不写出任何文件**；不用随机、不联网、不产生对局 |
| `backend/tests/test_mixed_bot_judgment.py` | `22` 个用例：合成用例锁口径，黄金样本锁复现性 |

**运行形态**：

```text
$ uv run python -m tests.mixed_bot_judgment <清单> <阶段回执> <观测工件> \
    --allow-judgment [--recheck=<标签>=<路径> ...]
```

- **默认拒绝**：不传 `--allow-judgment` 即抛错，不读取任何工件；实测输出「判定器默认拒绝：必须显式传入允许开关；写好的入口本身不构成运行许可」。
- **不落盘**：判定载荷只打印到标准输出，**不写任何文件、不进入证据目录**；因此**不新增任何 artifact schema**。
- **诚实失败**：工件缺少逐节点分布时（例如 v6 的旧粒度）显式抛错，**不回退**到类别或风格均值；缺一臂的配对同样抛错。

## 5. 写死的实现层钉子（`11` 条，逐条列示）

| # | 钉子 |
|---|---|
| 1 | 估值单元取清单种子序的第一个主种子块；短段排序同样用清单序，不用数值大小 |
| 2 | 实质动作混合 = 次高份额 ≥`10%`；分域按类别自然分区；节点读数先合并 units 再套同一规则 |
| 3 | 类型熵 = 逐风格分布熵的算术均值；金额条件熵 = 存在额度分布的行的均值 |
| 4 | 额度锚点 = 同额合并后份额 ≥`15%` 的档数；达到两档记为满足 |
| 5 | 机会域概率 = 先按节点合并手模式 units，再按节点等权平均；进池取 `call/bet/raise`，主动取 `bet/raise` |
| 6 | 风格可分度 = 三个配对中至少两对在两域上各 ≥`10` 个百分点 |
| 7 | 风格间距离直读工件字段，不在判定器内重算 |
| 8 | 稳定性 = 同一配对同一域的差值在全部种子块上符号一致（含恒为零） |
| 9 | 不劣化 = 逐人数各自取最差族；块均值双侧 t 区间（`S=16`，`t=2.131`），块极值口径并列，二者不一致判未满足 |
| 10 | 针对性诊断的短段 = 每（对手族 × 风格）按清单种子序/人数/轮换排序的前 `20` 对 |
| 11 | 针对性诊断的面对事件 = 被测一方首次面对对手下注或加注；额度 ÷ 街起始底池（翻前 `1.5` 个大盲）分三档 |

判定器同时输出 `pins` 字段，使口径随载荷一起呈现，避免「读数与口径分离」。

## 7. 两组不可复现读数的处置（不得混淆）

判定器把两组数字**并列**钉为常量（`IRREPRODUCIBLE_REFERENCE`）：

| 组 | 上一轮公布 | 本实现的钉死读数 |
|---|---|---|
| 机会域差值（pp） | 域一 `20.22 / 33.91 / 13.69`；域二 `0.35 / 0.03 / 0.38` | 域一 `30.71 / 54.92 / 24.22`；域二 `0.62 / 0.25 / 0.37` |
| 针对性诊断的有面对配对 | 短 `42` / 长 `1,303`（合计 `1,345`） | 短 `175` / 长 `5,191`（合计 `5,366`） |

**必须一并声明的四点**：

1. 两组**只能并列**呈现，**不得**互相替代；**不得**把钉死后的读数说成「找回了原口径」。
2. `docs/56h` 与 `docs/57k` 中的公布值**原样有效**，本文件**不是**对它们的改写；本文件不重算、不覆盖、不重发它们的结论。
3. 上一轮的机会域判定方向**不受影响**：域二在两种口径下都远小于 `10` 个百分点（本实现 `4.51/1.66/2.85` pp；公布 `0.35/0.03/0.38` pp）。
4. 本轮的**分桶读数只在本轮钉死口径下可比**；与上一轮的分桶数字**不可比较**。
