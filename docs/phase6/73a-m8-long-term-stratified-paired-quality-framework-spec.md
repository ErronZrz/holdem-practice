## 1. 目的、适用范围与迁移纪律

### 1.1 目的

为**未来的新战役**定义一套质量框架，使下列问题各有**独立**的报告与**明确**的阻断语义：

1. 产品体验层：人格是否**可感知**、行为是否**不可预测**；
2. 风险层：相对已声明基线的**强度风险**是否可接受；
3. 已定义探针风险：在**已声明探针池**下是否观察到新的可利用信号；
4. 成本层：运行成本是否在已声明包络内。

**关键设计约束**：强度风险**必须**落在**可阻断**的判据上（§4）——本框架**不是**把旧判据降为报告层，而是**替换统计形态**。

### 1.2 适用范围（迁移纪律，硬边界）

| 项 | 规则 |
|---|---|
| 生效范围 | **仅**适用于本框架冻结之后**新开的根编号战役**（新身份、新清单、新种子、新预注册） |
| 存量 | `-v10` 与 v1–`-v9` 的判据、门槛、机会分母、估值块、区间方法**一律不动**；四份既有签收与 `docs/phase6/58m` **一律不动** |
| `docs/phase6/58f` | 其取值**全部保留**，只是**不再作为**未来战役的判据来源；对 `-v10` 的判定仍以 `58f` 为准 |
| 不取消阻断 | **不得**以「L4 已降层」为由宣称任何质量支持；本框架要求**先**定义替代性强度门（§4），**再**谈是否解除任何停滞 |
| 默认策略 | 在新框架下的新身份取得质量签收**之前**，默认策略**保持 `heuristic@1`** |
| 反作弊 | 「先冻结再运行」「候选域不得自证」「熵不得注水」「不得按读数挑选配方/字段/探针族」四条**原样沿用** |

### 1.3 阈值与常量的存放位置（对本文件的硬约束）

本文件只定义**结构、协议与禁止项**。以下数值**不得**出现在本文件中，**必须**在预注册（§10 的 `73b`）中于**任何运行之前**固定：

- 强度门的风险预算与其区间/聚类参数；
- 每（主判层格子）的最小对局片段数、块数、停止条件；
- 基线池的成员清单与版本；
- 成本包络的判定值（若需要，另行裁定）。

并且：**同一框架内全部身份共用同一组数值**；**禁止**按任何候选身份的读数反推或逐身份调整（§4.4）。

## 2. 术语与非目标

| 术语 | 含义 |
|---|---|
| **对局片段** | 预先定义的一段连续对局（其长度、起始条件、切分规则在预注册中固定），是**不可再分**的统计单元 |
| **块** | 一组共享同一随机源（同牌堆派生流 / 同种子推导）的对局片段集合；块是最小的**重抽样单元** |
| **主判** | 具备**阻断**语义的判定 |
| **次判** | 必须报告、**不阻断**的判定；不得用次判替代主判结论 |
| **诊断** | 只解释现象，**不得**作为任何判定输入 |
| **基线池** | 预先冻结的一组比较基线及其配对规则（§7） |

**非目标（明确不做）**：

1. 不做 best response、不做 NashConv / exploitability 上界；
2. 不做完整多人 GTO；
3. 不把「随机」当「强」，也不把「不可预测」当「已证明强度」；
4. 不以有限探针的未观察结果**包装**为不可剥削性证明（§3.4）。

## 3. 产品目标分层（五个报告域）

五个域**分别报告**，**不得**用一个域的读数替代另一个域的结论。映射关系（仅为可追溯，不构成对旧判据的改写）：

| 域 | 回答的产品问题 | 承接来源（术语沿用） | 阻断 |
|---|---|---|---|
| **A 人格可感知性** | 玩家能否**察觉**不同风格/人格的差异 | 旧 L3 第 4 / 4b / 5 项 | **主判**（§3.1） |
| **B 行为不可预测性** | 行动混合是否**不退化**为单档 | 旧 L3 第 1 / 2 / 3 项 | **主判**（§3.2） |
| **C 强度风险** | 相对基线池是否有**不可接受**的劣势 | 旧 L4 的**替代品**（新形态） | **主判**（§4） |
| **D 已定义探针风险** | 在**已声明探针池**下是否观察到**新的**可利用信号 | 旧 L5 | **次判**（§3.4，不阻断） |
| **E 运行成本** | `wall` / 峰值 RSS / 输出是否在包络内 | 旧 L1 机制项 + L2 | **主判**（§3.5，必要条件） |

### 3.1 域 A：人格可感知性（主判）

- **要回答的问题**：在**预先指定**的产品可感知情境上，不同人格/风格的条件分布差异是否达到**可感知**水平；
- **必须报告**：逐情境的分布、差异的**点估计与区间**、样本量；差异方向的一致性；
- **禁止**：以「未说明的跨维度最差值」充当可感知性结论；以单一全局均值掩盖情境级失败；
- **判定结构**：情境与最低可感知水平在预注册中固定（§6.1 的「主判层」），**不得**在读数后增删情境。

### 3.2 域 B：行为不可预测性（主判）

- **要回答的问题**：实质动作混合是否**不退化**（不塌缩成单档），且额度分布是否**多档可区分**；
- **必须报告**：整体与**预先声明的分域**（沿用「翻前 / 面对下注 / 免费行动」三分域口径）、类型分布熵、额度锚点与条件熵；
- **禁止**：以降低估计样本量制造抖动；以「门槛偏严」为由在读数后放宽；剔除结构性恒等条目后再报（须**照实计入并单列**）。

### 3.3 域 C：强度风险（主判，替代性强度门）

见 §4（独立成节，因其为本框架的核心替换项）。

### 3.4 域 D：已定义探针风险（次判，不阻断）

- **形态**：**扩充探针池** + **针对性诊断**；不做局部 best response；
- **探针池**：在预注册中**冻结**（成员、版本、比较口径）；一经冻结，**不得**按读数增删、重定义或替换；
- **结论边界（强约束）**：结论**只能**表述为「**本次样本集与本次探针池下未观察到 X**」；**不得**表述为「不可剥削」，**不得**作为任何上界；
- **必须并列声明**：探针池的有限性、探针不是最优反应、探针重叠导致的**伪独立**风险；
- **禁止**：把「未观察到」写成「不存在」；把探针命中率上升/下降包装成强度改善/恶化。

### 3.5 域 E：运行成本（主判，必要条件）

- **必须报告双口径**：整个调用的最大常驻集（判定口径）与模块自记峰值（**下界**），两者**并列**；
- **必须报告**：`wall`、输出字节数、单进程/不并行状态；
- **包络**：判定上界在授权时单独声明（沿用既有 `wall` / 峰值 RSS / 输出三项的表述形态）；**触及任一上界即停止并如实报告，不自行扩容**；
- **禁止**：只报一种 RSS 口径；把成本达标当质量证据。

## 4. 替代性强度门（域 C）

### 4.1 为什么不能只把旧 L4 降层

旧 L4 的形态是：**单手配对**的 `BB/100` 差 → 逐人数**各自取最差族** → 块均值 t 区间下界与块极值两口径 → 低于风险预算即判未满足。

其已披露的形态特征（**描述性现象**，取自 `docs/phase6/57m` §4.2、`58n` §4.2 / §5.1 / §5.2，**不用于反推任何阈值**）：

- 判定单元是单手，单对读数离散度达数千 `BB/100` 量级；
- 最差族是**极值型**统计，受极少数大额底池影响；
- 单块退出敏感性显示结论对块的选择**不敏感**（去掉最差若干块仍不改变方向）。

⇒ 该形态**能暴露风险**，但**不能稳定代表长期强度或产品体验**。因此本框架**必须**更换统计形态，而**不是**仅更换是否阻断。

**同时**：**不得**据此把旧 L4 说成「判据有误」或「噪声」；对 `-v10` 的判定与签收以 `docs/phase6/58l` / `58m` 为准，**未被触碰**。

### 4.2 门的形态（三段式）

| 段 | 内容 | 是否阻断 |
|---|---|---|
| **主判** | 在**预先声明的聚合层**上，相对**基线池**的配对劣势的**区间**判定 | **是** |
| **次判** | 分层（人数 / 对手族 / 风格-座位 / 街道等）的分解读数 | 否，但**必须**报告，且**不得**被省略 |
| **诊断** | 分布、集中度、桶级现象 | 否，**不得**作为判定输入 |

### 4.3 决策规则形态（在预注册中固定，本文件只定形态）

1. **聚合量**：以**对局片段**的对内配对差为基础，先按块聚合，再按**预先声明的权重**跨块合并；**禁止**直接把单手底池当作长期 `BB/100`；
2. **方向与判定**：判定用**区间下界**（或等价的单侧检验）而非点估计；区间的构造方法、聚类层级与自由度在预注册中固定；
3. **多重比较**：主判层内若含多个格子，必须**预先声明**合并方式（并集 / 交集 / 加权）与多重比较处置；**禁止**事后挑选最有利或最不利的格子；
4. **两口径并列**：若同时报告「区间口径」与「极值口径」，**任一口径不一致即判未满足**（保守处置原样沿用）；
5. **样本不足即不可判定**：任一主判格子的有效样本低于预注册下限 ⇒ 该格子**降级为诊断**，且**整体不得**给出「满足」结论。

### 4.4 数值校准协议（**本文件不给出任何数值**）

风险预算与其统计参数**必须**满足：

1. **先于任何读数固定**：在 `73b` 预注册中写定，之后**不得**修改、不得放宽、不得按结果更换；
2. **不来自候选身份读数**：**禁止**以任何候选身份（含 `mixed-local@8`）的实测读数反推该数值；`-v10` 的读数**只能**用于**描述现象**，**不得**用于确定判定值；
3. **来源须显式声明**：该数值必须注明其性质（例如「产品风险预算」），并明文声明其**不是**教学标准、**不是** GTO 基准、**不是**强度上界；
4. **框架内同值**：同一框架下的**全部**身份与战役使用**同一组**数值；**禁止**逐身份调整；
5. **可被拒绝**：若无法给出满足上述四条的依据，则该数值**不得**被写入预注册，相应战役**不得开始运行**。

### 4.5 阻断语义与失败处置

- 主判未满足 ⇒ 结论**只能**表述为「**本框架下强度风险未获支持**」；
- 默认策略**保持** `heuristic@1`；
- **不得**改判据、**不得**重跑同一集合、**不得**把同一集合反复调参后称为独立验证；若需再试，**须新开根编号战役并重新预注册**；
- 主判满足 ⇒ 结论**只能**表述为「**本次独立验证下主判满足**」；**不得**表述为稳健达标、质量已证明或不可剥削（「用更多 seed 估计判定反转频率」这类前置若未做，必须一并记账）。

## 5. 判定单位与方差处理

### 5.1 判定单位（**取代单手提纯**）

1. **基本单元 = 对局片段**：片段长度与切分规则在预注册中固定；同一片段内的对局**不可再分**为独立样本；
2. **配对结构**：每个片段形成**配对**（同一牌堆派生流、同一位置、同一起始深度），配对差是该片段的对内统计量；
3. **块 = 重抽样单元**：所有区间与显著性**必须**在块层聚类（§5.5）；
4. **禁止**：把单手净筹码按固定倍数等同于长期 `BB/100`；把同一片段内的多手当作独立观测。

### 5.2 方差来源清单（必须在预注册中逐项声明处置）

牌堆/公共牌结构、位置与按钮轮换、风格与人格、对手族、人数、起始深度、截断与动作上限、时长/手数上限。

对每一来源必须声明：**是**作为分层维度、**是**作为配对变量、**还是**作为被随机化的因子；**不得**留白。

### 5.3 配对与反事实纪律

- 配对**必须**建立在同牌堆派生流、同位置、同起始深度上；
- **禁止**把新动作接到旧历史后缀上算反事实 EV；
- **禁止**用不同牌堆的样本拼出「改善」。

### 5.4 区间与聚类方法

- 区间**必须**反映块级重抽样（块层聚类稳健区间或等价方法）；
- **必须并列**：点估计、区间、块级离散度、块极值、逐（主判）格子分解；
- **禁止**只报合并均值；**禁止**用合并均值代替逐格子结论。

### 5.5 功效、最小有效样本与停止条件

1. **先算后跑**：预注册必须给出**方差模型**（来源与量级依据）、**最小可检测效应**、以及在给定功效水平下的**最小有效样本**（每主判格子的对局片段数 × 块数）；
2. **算不出就不跑**：若无法给出上述计算，该战役**不得**开始运行；
3. **停止条件必须先声明**：包含正常终止与异常终止（错误、截断率越界、成本触及上界、样本不足）；**禁止**「跑到好看为止」，**禁止**事后延长或截断样本；
4. **不得**以小固定种子集作为强结论的依据；若块数受限，必须在结论中**明示**其为「小固定集合」，且**不得**表述为稳健。

## 6. 分层与聚合规则

### 6.1 三层划分（必须在预注册中逐维声明）

| 维度 | 典型取值 | 必须声明为 |
|---|---|---|
| 人数 | 2–9 | 主判层 / 次判层 / 诊断层 |
| 对手族 | 已冻结族集 | 主判层 / 次判层 / 诊断层 |
| 风格 / 座位 | 人格与位置 | 主判层 / 次判层 / 诊断层 |
| 起始深度 | 短码 / 标准 / 深码 | 主判层 / 次判层 / 诊断层 |
| 街道 | 翻前 / 翻牌 / 转牌 / 河牌 | 主判层 / 次判层 / 诊断层 |

**硬约束**：

1. 每一维度**必须**被显式归类，**不得**留白；
2. **禁止**用**未说明的跨维度最差值**替代产品结论（这正是旧形态的主要缺口）；
3. 次判层的失败**必须**完整报告，但**不阻断**；**不得**因次判失败而改写主判结论；
4. 主判层的**合并规则**（加权方式、多重比较处置）必须在预注册中固定。

### 6.2 聚合纪律

- 先**声明**权重，再聚合；**禁止**事后选权重；
- 聚合前后**样本量必须可追溯**；
- 若某格子样本低于下限 ⇒ 降级为诊断（§4.3 第 5 条），并**如实记账**。

## 7. 基线池

### 7.1 `heuristic@1` 的角色

1. **默认策略**：在新框架下未取得质量签收之前，生产默认**保持** `heuristic@1`；
2. **迁移基线**：作为**比较基线之一**沿用（保证与既有轮次的可追溯对话）；
3. **明确不是**：`heuristic@1` **不是**真实强度上界、**不是**教学正确性基准、**不是**「可接受强度」的定义者。任何「优于 `heuristic@1`」**不得**被表述为强度已获证明。

### 7.2 辅助基线的准入（**需要时**）

- **允许**引入**冻结、版本化**的辅助基线（例如固定随机基线、固定规则基线与已冻结的机械探针族集），但必须：
  1. 在预注册中**列出成员与版本**；
  2. 与主判**同权**或按预注册声明的权重参与；
  3. **一经冻结不得按结果增删、重定义或替换**；
- **禁止**：把「打败某个弱基线」当作强度证据；把基线池的扩大当作放宽或收紧判定值的手段。

### 7.3 比较口径

- 比较**必须**是**配对**的（§5.3），并报告**双向**偏离（最大正偏离与最大负偏离**都须报告**，不得只报有利一侧）；
- 跨基线池的**聚合**方式必须在预注册中声明；
- **禁止**按结果更换基线或更换比较口径。

## 8. 成本与包络的关系

- 新框架若要求更大的样本规模，**可能**需要更大的运行规模；**包络不得自行扩容**；
- 若预注册计算显示所需规模会触及既有包络，则**必须**先单独裁定包络（或缩减规模并**如实**把该缩减写入预注册的局限）；
- 成本达标**不是**质量证据（域 E 为必要条件）。
