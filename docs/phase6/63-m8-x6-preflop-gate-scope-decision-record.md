## 2. 裁定依据（只读核对，**不是读数、不是新证据**）

1. `docs/phase6/62` §5 的更正：翻前多人桌零主动的成因为**翻前准入门**（`A-ii`），**不是**对手数表；`docs/phase6/61` §7 的原归因**已被更正**，本文引用更正后的归因。
2. `docs/phase6/57k` §7 第 4 项要求**两个预先指定机会域各 ≥2 档 ≥10 个百分点**；现状域一 `2/3` 对、域二 `0/3` 对。故 **`A-ii` 对 L3 第 4 项没有上行**——它只作用于翻前，而该判据当前失败在翻后的域二。
3. 代码内只读核对（`backend/tests/mixed_bot_judgment.py`）：域一 = `unopened-open` 节点的**进池**概率（`call` / `bet` / `raise`）；域二 = `flop-draw` 节点的**主动**概率（`bet` / `raise`）。`unopened-open` 属域一，即 `A-ii` 的作用面与**已满足**的那一半重合。
4. `docs/phase6/62` §8 列出的变体风险：`A-ii-1` 会令 `unopened-open N=2`（焦点 `position = -40`）与 `facing-reraise N=2` 的非价值质量由 `0` 变为 `12`，直接改变单挑行为。

⇒ 在本轮证据水平下，`A-ii` 的**潜在收益只在 L4**（L4 负差主体在翻前），而**风险落在域一那半个已满足项**上；`docs/phase6/61` 的证据只到「翻前多人桌未面对下注主动率为 `0.00%`–`4.55%`」，**不足以论证**「提高 `tight` 翻前进攻是正确方向」，按 `docs/53` §13.2 需先有专门的反例与分层评测。
