
### 3.3 保持 L-2 v1（写死）

- 基线构造接口保持 `registry-seed`，基线不依赖公开摘要，座位集合口径保持 L-2 已写的渲染。

- 被测标识字符串仍以 L-2 v1 为准。该字符串所指名的身份**尚未**创建；本文件不把它登记进注册表，也不把它选为基线。

## 4. 对 K2-P-i 的条件确认（写定）

`74ai` 已采用 K2-P-i。`74ai` §5 要求：所选成员必须支持逐决策新建实例并按 κ 注入材料，否则该 K-2 裁定失效。本裁定确认 `heuristic@1` **在下列条件下**与 K2-P-i 兼容，从而**不**触发该失效。

### 4.1 未来实现必须满足的供给

```text
每一次决策，包外新建一个 heuristic@1 实例，
并向该实例注入与完整 κ 对应的整数 seed。
κ = (seat, hand_ordinal, event_index, σ_public)，
定义与 EncodeK2PublicV1 以 74ai §4.2 为准，本裁定不替换该编码。
两臂在相同 κ 上注入相同的 seed；σ_public 字节不同则不得复用该 seed。
```

| 项 | 裁定 |
|---|---|
| **实例** | 每次决策新建。手内不得沿用同一实例把它的随机源推进到下一次决策，并声称仍满足 K-2 |
| **注入参数** | 仅该次实例的整数 `seed`，经受控注册表 `registry-seed`／`create_strategy` 传入。`seed` 是 `M(κ)` 的像 |
| **禁止空种子** | 不得传入 `None`。空值会离开预注册整数材料 |
| **`samples`、`bluff_freq`** | **仍为实例化口径**。经注册表构造时取类默认值（`_SAMPLES = 500`、`_BLUFF_FREQ = 0.10`）。二者**不是** `M(κ)` 的组成部分，不随 κ 改变 |
| **`strategy/`** | 本条件**不**修改 `HeuristicStrategy` 的随机消费。以改策略源码来注入 κ 的路线仍是已不采用的 K2-P-iii |

### 4.2 本条件尚未实现

- 现行 `74r` L-3 v1 仍以手级整数 seed 供给 `heuristic@1`。该文本**继续有效**至另行授权的新后缀修订，但**不**满足 §4.1。
- 只读构造事实：该类在一次实例寿命内会推进随机源（翻牌后胜率估计与混合分支上的动作采样共用该源）。因此「每手一个 seed、手内同一实例」**不能**代替 §4.1。
- 固定映射的用途标签、键字段、整数域与字节编码由后续 L-3 修订写定。本裁定**不**生成任何 seed，**不**冻结摘要。
- 条件确认**不**等于 C-2′ 已建立，也**不**等于 ③ 已经按本条件重验。
