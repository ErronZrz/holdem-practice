## 4. 三处偏差的如实更正

### 4.1 `app/**` 文件数为 `3`，不是 `2`

`docs/57b` §5.1 写「只动 `2` 个 `app/` 文件」。**实际为 `3` 个**：除规则层与策略入口外，注册新身份还**必须**改受控注册表 `backend/app/strategy/registry.py`。该文件**不在永久禁改清单内**（`docs/57a` §3 表），故不构成范围扩大；但规格的文件数**低估**，如实更正。

### 4.2 共 `8` 处负例字面量必须上移

注册 `@6` 之后，四个测试文件里把 `"mixed-local@6"` 当作**未注册身份**的负例全部失效（共 `8` 处）：

| 文件 | 处数 | 处置 |
|---|---|---|
| `backend/tests/test_mixed_bot_benchmark.py` | `3` | 上移到 `mixed-local@7`，并补一条说明「版本号逐版上移」的注释 |
| `backend/tests/test_mixed_shared_board.py` | `5` | 同上（其中 `4` 处集中在一个测试内，改为单个局部变量） |
| `backend/tests/test_strategy_registry.py` | `2` | 同上（该文件原本已有「逐版上移」的注释，沿用其惯例） |

**这不是**放宽任何断言：被修改的只是「哪个版本号尚未注册」这一**字面量**，「未注册身份必须显式失败」的性质一字未改。

### 4.3 `R-d` / `R-e` 的表述更正（**不是**放宽标准）

| 项 | `docs/57b` §5.5 原文 | 为何不可用 | 更正后 |
|---|---|---|---|
| `R-d` | 断言 `@6` 的主动单位 **≥ `@5` 的 `10` 倍** | **数学上不可达**：单位是归一化量。主动权重放大 `k` 倍时份额满足 `sₖ = k·s₁ / (1 + (k−1)·s₁) < k·s₁`，故 `k = 10` 时比值恒小于 `10` | 改为断言**解析关系式** `s₁₀ = 10·s₁ / (1 + 9·s₁)`（容差 `2×10⁻⁵`；实测最大误差 `3.89 / 10⁶`）；并把开关还原后与 `@5` 的**逐位一致**作为独立断言 |
| `R-e` | 直接比较 `@6` 与 `@5` 的两份分布 | **未隔离另一项改动**：尺度变化会混入结论；且在额外对手 `≥ 3` 的两侧，两份分布都可能因「全弃牌」而**假通过** | 改为**单开关隔离**：比较 `@6` 与 `@6(contender_penalty_cap=0)`，其余字段完全相同 |

**两处更正都没有放宽标准**：`R-d` 由「不可达的不等式」换成「更精确的等式」；`R-e` 由「会假通过的粗比较」换成「更严格的隔离比较」。**两项根因均未被否定**（§5.4、§5.5）。
