## 3. 章程 §4.2 第一项：方差依据

**章程要求的原文要点**：不得再退化为保守解析界 `V_max = M²`；任何新的方差或判据依据须另行建立。

### 3.1 已登记的事实

`73d` §2.1 对任意预注册块内权重（非负且和为 `1`）的块级量 `X_j`（支撑位于 `[-M_N, M_N]`）得到：

```text
Var(X_j) ≤ (max(X_j) − min(X_j))² / 4 = M_N²
V_j ≤ V_max,N := M_N²
```

`73e` 已据此终止「以该路径闭合 `73b` 冻结项」的尝试，并登记该路径不能作为可冻结路线。

### 3.2 本授权内建立的部分：该退化的**必然性**

下列命题是标准结论，本轮将其登记为对「为什么该路径必然退化」的说明（它是对既有事实的解释，不是新的质量或性能主张）：

```text
命题：设 X 为实值随机变量且 |X| ≤ M（M > 0）。则仅由「支撑有界」可得
      Var(X) ≤ (max − min)² / 4 ≤ M²；
      且该上界是紧的：两点分布 P(X = −M) = P(X = +M) = 1/2 时 Var(X) = M²。
```

推论：

1. `V_max,N = M_N²` 不是「保守得过分」，而是**该信息集（有界支撑、分布无关）下的紧界**；不存在分布无关的推证能给出更小的一致上界。
2. 因此「不得退化为 `M²`」这一要求**不可能**由「有界支撑 + 分布无关」的解析路径满足；它等价于要求**新增支持信息以外的结构**。这是信息集层面的结论，与实现、工程优化或常数调整无关。
3. 由配对设计的额外结构（例如通过座位轮换的对称性在预注册层面确立配对差为零均值）在单侧偏差界上至多带来**常数级**收紧，不改变所需块数的量级；该构造本身也尚未建立。

### 3.3 未建立的部分与待裁定的决策框架

**本授权内不能闭合。** 但以下澄清先写死：本记录**不**把可新增的信息枚举为封闭集合，也**不**主张存在唯一的「上游」路径。这里至少涉及三个**不同层级**的决定——方差 / 协方差依据（本项）、判据路线（章程 §3 第 2 项）、资源与包络（本项第四项与阈值冻结）——三者不得混为一谈。

**允许的证据来源类型（不构成封闭集合；未列出的来源须另行登记，不得因未列入而被排除）**：

| 类型 | 内容 | 须同时满足的条件 |
|---|---|---|
| A. 候选读数独立的结构性解析方差 / 协方差界 | 由已冻结的块模板、重置口径、配对构造、相关结构或其它确定性约束，推导出**小于 `M²`** 的逐块 `V_j` 与片段间协方差处置 | 须在**冻结前**给出逐块 `V_j`、片段间协方差的处置方式、与 seed 及任何候选读数的**独立性**、以及该界的推导前提与适用条件；退化到 `M²` 即视为本项未满足，不得声称已满足 |
| B. 显式分布模型 | 预注册一个手级结果的参数化模型，并据此给出方差上界 | 参数**不得**来自候选身份读数（既有禁令保持）；须裁定模型形式、参数来源与其可辩护性，以及模型失配的风险处置 |
| C. 非候选标定运行的读数 | 由一次专门授权的标定取得的读数 | **辅助证据，不是独立的方差来源**：在没有独立的桥接模型或结构性上界时，**不得**用其读数界定被测身份的方差；`73b` §4.4.1(b) 的禁令保持 |

**不属于本层级的决定**：

- **变更判据形态或统计单元**（如以手为单位的序贯 / 自适应判定、配对符号或分位数型判据；或改为对**确定量**即固定有限清单的精确平均作判定——后者不再需要 Hoeffding / Cantelli 型推断）属**判据路线**决定，触及章程 §3 第 2 项，须由单独裁定择定；它不是方差 / 协方差依据的来源。

**因此，本项未建立的内容是**：一个新的、非退化的方差 / 协方差依据本身。它须由上述允许来源中至少一条路径在**冻结前**给出（类型 A 是可分析的结构性路径之一），并同时在决策框架层面裁定「哪一类证据被允许作为依据、其适用条件由谁在何时核验」。

## 4. 章程 §4.2 第二项：块数可达性

**章程要求的原文要点**：清单预注册块数相对各解出块数的可达性须另行建立，不得以解析块数替代可达性。

### 4.1 本授权内建立的部分：可达性的判据与认证协议

定义（建立）：

1. 对每个分域 `g`，「可达」指：清单在冻结前对**该分域的每个外生层**都能实际枚举出不少于解出块数 `B_g` 的块，且每个块都能按其预注册规则生成合格节点集。
2. 认证方式只能是**构造性枚举**：按预注册的层与配额规则实际生成节点并逐层取满；配额取不满即该块**不合格**（不得以补齐、放宽或反复生成的方式使其合格）。
3. 认证须逐项核对：按钮位等权、配对臂对称性、外生层配额取满、全偏移量配额、块与种子的对应关系。
4. **解析块数不得替代可达性**：由公式得到的 `B_g` 只是需求下界，不构成可达性依据；枚举上限与层谓词未生成时，可达性**未证**。

### 4.2 未建立的部分与所需裁定

**事实未建立**：可达性依赖清单层（节点枚举、层集合、层谓词、枚举上限、偏移量空间与全偏移量验证）的实际生成。这些对象本轮**未生成**，且属清单层工作。

所需裁定：授权清单层的节点枚举与配额试算（**不**冻结 seed、**不**运行验证），以判定「预注册块数需求」是否可达。在该裁定之前，可达性保持未证。

## 5. 章程 §4.2 第三项：块间独立性

**章程要求的原文要点**：须具备构造性依据与预注册核验判据，且不得把核验结果表述为独立性的证明。

### 5.1 本授权内建立的部分：构造性依据的形态与核验判据

**构造性依据（形态，采纳 `73b` §5.7 已写定的方向）**：

1. 块级随机性**只**来自块的外生种子 `σ_j`；块内节点集是 `σ_j` 与预注册规则共同决定的**确定函数**（纯映射）。
2. `σ_j` **独立同分布**于预注册的均匀分布，由**身份无关**的外部随机源在清单冻结前**一次性**给出并落盘。
3. 因此块间独立由「外生种子独立抽取 + 确定性映射」构造性给出，**不**由「种子不同」「读数不相关」或「块不相交」声称。

**预注册核验判据（可执行，且不构成证明）**：

| # | 判据 |
|---|---|
| (i) | 种子来源与分布**在生成之前**预注册；生成后落盘；**禁止**按结果重新生成、增删或替换 |
| (ii) | 每个块的节点集与 `σ_j` 的对应关系可机械重放（同一 `σ_j` 与同一规则必得同一节点集） |
| (iii) | 种子生成路径不引用任何身份标识、基线随机流或对局结果 |
| (iv) | 块之间不共享被测身份的随机流；各块的派生流互不可推 |
| (v) | 块的划分是身份无关的纯函数（给定清单与规则，块集合唯一） |

**明确禁止**：把上述核验的通过表述为独立性的**证明**；不得以「来自不同种子」本身作为独立性依据（章程 §4.2 已写死的边界保持）。

### 5.2 未建立的部分与所需裁定

**实例未建立**：依据与判据的**形态**已建立，但其**实例**依赖 `σ_j` 的实际生成、层与节点规则的实际冻结（清单层工作）。所需裁定：授权清单层的种子生成（`σ_j` 一次生成并落盘），并在其后按上表逐项执行预注册核验——核验结果只能作为记录，不得表述为独立性证明。

## 6. 章程 §4.2 第四项：包络可行性

**章程要求的原文要点**：既有包络取值为单进程、无并行、`wall ≤ 1,800 s`、整调用最大 RSS `≤ 1.5 GiB`、输出 `≤ 100 MiB`；其可行性在 `73` 内未获支持，`74` 不得继承为已满足，也不得在未获授权时通过运行性能测试来取得支持。

### 6.1 本授权内建立的部分：取证要求与允许的推证形态

**允许**的取得方式（二选一）：

1. 由**冻结的块模板、每单位机械工作量上界与清单规模**推出的**解析上界**（须写明每项输入来源与该上界成立的条件）；
2. 在获得单独授权后的一次**专门包络测量运行**（测量对象、口径与记录方式须在同一裁定中预注册）。

**不允许**的方式（登记，保持既有边界）：

1. 以既有历史读数或历史外推主张包络已获支持：`73d` §5.1 的机械吞吐下界与 §5.2 的「未获支持」结论**原样保持**，只是一种**描述性**记录，不构成可行性依据；`74` **不得**将其继承为已满足。
2. 在未获授权时通过运行性能测试取得支持。
3. 改变包络数值（单进程、无并行、`wall ≤ 1,800 s`、整调用最大 RSS `≤ 1.5 GiB`、输出 `≤ 100 MiB`）。

### 6.2 未建立的部分与所需裁定

**未获支持，且本授权内不能闭合**：解析上界所需的每单位机械工作量与清单规模都依赖未冻结的实现与清单；测量则需要运行授权。所需裁定（二选一）：授权给出每单位机械工作量上界的**解析输入**（随附其成立条件），或授权一次**预注册的包络测量运行**。
