## 8. 更正与披露（`docs/phase6/62` **原样保留**，更正一律记在此处）

### 8.1 `docs/phase6/62` §7.1 的三档水平未能复现

按该节自称的口径（第四套冻结节点、`normal` 手模式、逐节点）重算，得到的第六版水平与 §7.1 表格**不一致**：

| 节点 | §7.1 表格「现状 t / c / a」（%） | 本次同口径重算（%） |
|---|---|---|
| `n2` | `12.48 / 13.72 / 24.96` | `16.22 / 22.17 / 35.51` |
| `n3` | `5.94 / 7.39 / 12.87` | `7.61 / 12.53 / 18.55` |
| `n4` | `2.96 / 3.70 / 6.65` | `3.78 / 6.29 / 9.74` |
| `n5`–`n9` | 全 `0` | 全 `0`（一致） |

已排查并排除的口径：另外三套冻结节点（四套的 `N=2` 行分别为 `17.98/19.74/37.94`、`16.29/22.06/35.63`、`15.21/24.19/33.46`，均与 §7.1 不符）、把人数当对手数、分母不计弃牌、两者的组合。**未能复现，成因未定位**，如实并列，不作为结论。

**判断口径**：本次重算在第六版上**逐位复现**了 v8 已公布读数（§7.1），因此以本记录 §7.1 的口径为准；`docs/phase6/62` §7.1 的表格**只能作为方向性推演**看待，其数值水平不可引用。

**对结论的影响**：§7.1 的结论方向（「`A-i` 单独不应被期待使域二达标」）**不变**——按本记录 §7.1，第七版仍只有一对达到 `10` 个百分点，域二不满足「至少两对」。但其**余量被低估**：`t-a` 一对会跨过 `10` 个百分点。

### 8.2 `docs/phase6/62` §4.3 的「差异最小化」只对**对手数分量**成立

§4.3 写「`c = 1`（`12`）与 `c = 2`（`6`）**与现状完全相同**」。按同一节的公式，位置分量与听牌分量是**叠加**在对手数分量之上的，因此：

- `c = 1`：对手数分量已达基数，合成后仍封顶为 `12` ⇒ 确实与现状相同；
- `c ≥ 2`：只要位置分量或听牌分量为正，合成结果就**大于**对手数分量 ⇒ 与现状**不同**（实测 `contenders = 2` 处由 `6` 变为 `8` 或 `10`，`contenders = 3` 处由 `3` 变为 `5`–`7`）。

即：**实际覆盖面比 §4.3 的小结更宽**（`25` 个节点而非 `20` 个）。本次**未因此调整任何取值**——公式是规格的正文，实施按公式执行。

### 8.3 「由零转正」不等于「分布变化」

`20` 个由零转正的节点中有 `5` 个（`one-side-all-in` 的 `N ≥ 5`）分布**不变**：其主动候选落在危险尺度保护内。`docs/phase6/62` §6 的「`20` 节点」是**依据口径**的计数，**不等于**行为变化面的计数（`25`）。

### 8.4 `docs/phase6/62` §11 的文件清单缺一项

新增身份还需在 `backend/app/strategy/registry.py` 注册版本化标识（`mixed-local@7`，版本 `7`），否则该身份无法通过注册表构造。§11 的四个落点中未列出该文件。这是**清单遗漏**，不是范围扩大：注册表是既有身份的既定入口。

### 8.5 既有断言的必要维护

`8` 处既有断言把 `mixed-local@7` 当作「尚未注册的版本号」；本次把它后移为 `mixed-local@8`（断言性质不变），另有 `1` 处身份元组断言随新增身份上移一版。这不改变任何既有身份的含义、摘要或分布。
