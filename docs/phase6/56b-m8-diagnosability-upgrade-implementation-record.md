## 4. 关键实现决定（逐条披露）

1. **版本分派而非无条件升版**：只有清单声明 `mixed-validation.v2` 时才产出逐节点明细。因此**旧清单的报告不多出字段**，v1–v6 回执的可比性由这一点维持（有回归钉住）。
2. **逐节点明细致 L3 第 5 项可判定**：实现层面的行为矩阵原本**只取清单的首个种子**，因此「不同 seed 仍体现倾向」在旧粒度下结构性无读数。新增的逐节点明细**按每个种子块各算一次**（`125 × 3 × 3 × 16 = 18,000` 行）。
3. **字段闭集**：观测只记**公开落子**与**派生标签**，不含底牌、公共牌、牌堆；三条模型的字段集合已由回归逐字钉死，新增字段必须先改断言。
4. **底池口径**：引擎的 `pot` 为整手累计投入，结算时不清零，故「落子后覆盖本街读数」即该街结束时的底池；落子所属的街在应用动作**之前**取。
5. **牌力档**：只用**焦点座位自己的底牌 + 公开公共牌**计算，落盘的是 `weak/medium/strong` 标签；公共牌不足三张时为 `None`（不猜测）。
6. **对手族集不动**：`docs/55h` §6 的探针重叠发生在产生读数之后，据此增删族集即「按表现挑选族」，故族集沿用既有 `iqv` 的 8 族。

## 7. 新引入的口径空白（**X2，必须在冻结清单之前裁定**）

新增的逐节点明细是**数据超集**：它对**每个**种子块各产一行。但 `docs/55` §7.2 的判据中：

- 第 1 项（覆盖率）、第 3 项（额度多样性）、第 4 项（风格可分度）按定义是**固定估值种子下的分布**读数；
- 第 2 项（类型熵）原文亦写明「固定估值 seed」；
- 第 5 项（稳定性）**才**需要跨种子块比较。

**因此有一个尚未在预注册中指定的口径**：第 1 / 2 / 3 / 4 项应当取**哪一个种子块**的行（或如何跨块汇总）。

**裁定（已定）**：用户答复原文

> 「A.」

指向的选项原文：

> 「A. 授权提交 `docs/56b`，并裁定 X2 取「第 1 个种子块」」

| 编号 | 裁定结果 |
|---|---|
| **X2** | 第 1 / 2 / 3 / 4 项的「固定估值种子块」= **清单中的第 1 个主种子块**（即 `MIXED_IQV2_MAIN_SEEDS[0]` = `2518403890`） |

**由本裁定直接推出的四条后果**：

1. 该口径与既有单种子聚合口径一致，因此改造**只增加可判定性、不改变读数含义**；
2. 第 5 项（稳定性）**仍**按**全部 16 个种子块**比较倾向方向，**不**使用单一估值块；
3. 逐节点明细的**其余种子块行只**用于第 5 项与离散度报告，**不得**用于第 1 / 2 / 3 / 4 项的判定；
4. 该口径在**任何新读数产生之前**锁定；产生读数后**不得**改换估值块（改换即属「看到结果后更换分母」类的行为）。

**本篇不做任何判定**：X2 只是口径，不产生任何判据结论，也不改变 `docs/55g` 的既有签收。
