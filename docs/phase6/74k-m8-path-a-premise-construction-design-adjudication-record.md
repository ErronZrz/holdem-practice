## 3. 外部随机源：有限接受，作为预注册随机化协议的设计公理

### 3.1 准确表述（照录）

> 在本次预注册随机化协议中，指定外部随机源的每次有效抽取被**建模为**相互独立、在指定有限集合上均匀的原始随机变量；该公理仅用于构造本次随机设计，不是对操作系统、物理熵或真实世界独立性的证明。

以下以「**随机化公理**」指称该表述。

### 3.2 地位与限制

1. 随机化公理可作为 A 路径的**随机化构造前提**；它**不是**候选身份读数，也**不是**经验方差模型。
2. **不得**表述为「操作系统密码学随机源已被证明真正独立均匀」。
3. 后续预注册**必须固定**：
   - 唯一来源接口与环境范围；
   - 每次抽取的用途标签、索引与有限输出域；
   - 无偏拒绝采样规则与拒绝后的继续规则；
   - 一次性生成、完整落盘，禁止重试、替换或按结果筛选；
   - 生成过程的可审计记录。
4. 后续核验**只能**检查来源、调用顺序、完整性、无重复生成与映射规则；**不能**证明实际独立性或均匀性。
5. 若未来不接受随机化公理：C-2′、AB-1′ 与可选 AB-2z 均失去本裁定下的构造来源；须另寻 A 类来源，或重新申请 B 类模型路线。

### 3.3 保留的排除

`74j` §5.2 对下列来源的排除**保持有效**：由共同块种子经摘要 / PRF 派生各手材料（R-c，非 A 类，属 B 类候选）；单条推进流；PRF「近似独立」。

## 4. 接受的设计方向

### 4.1 域 C（对应 `74j` §4）

接受：

- **D-a**：两臂使用同一份显式注入的完整发牌材料；
- 两臂相同的庄位、被测座位与其他座位安排；
- 每手、每臂新建引擎，全员从相同 `S` 开始；手内不补码；
- 记录单位 `d_h = m_h − b_h`，`e_h = 100 · d_h / BB`；
- 在「无抽水、无外部转移、每座初始筹码为 `S`」口径下：`m_h, b_h ∈ [−S, (N−1)·S]`，`|d_h| ≤ N·S`。

裁定登记：该上界比 `73b`（历史引用）的 `2(N−1)S` 更紧，且不依赖身份读数；平分底池、边池与整数余筹不突破全局筹码守恒范围，但**仍须在 ③ 中按规则核验**。

### 4.2 C-2′ 的构造组合（对应 `74j` §5–§6）

接受 **R-a ＋ S-a ＋ P-a**：

- **R-a**：每手 `Z_h` 逐手、逐用途从外部随机化协议取得原始材料；
- **S-a**：每手、每臂新建引擎并使用注入发牌；
- **P-a**：每手、每臂、每座位新建策略实例，以该手、该座位对应材料构造其随机输入。

裁定登记：现有代码事实只支持「该方案可避免当前会话级推进状态」，**不**代表已实现。仅当后续实现满足全部条件时，该组合才可作为下式的构造来源：

```text
e_h = g_h(Z_h) ，  Z_h ⊥ Z_{h'} (h ≠ h')   ⇒   Cov(e_h, e_{h'}) = 0
```

### 4.3 域 A / 域 B（对应 `74j` §7–§8）

接受：

1. **P1 静态互斥层**：`P_ℓ = {n : I_ℓ(n) 且对全部 ℓ' < ℓ 有 ¬I_{ℓ'}(n)}`。层谓词与优先序**只能**依赖节点的外生字段、已冻结标签与合法动作集；**不得**读取策略输出、观测分布、候选读数或结果。
2. **精确均匀无放回抽样**：每层以无偏拒绝采样取得均匀整数，再经组合数系统双射到 `n_ℓ` 元子集；实现与核验完成后可支撑 AB-1′。
3. **AB-2z 可选**：分层随机材料独立可作额外收紧来源；不采用时，`74i` 的通用协方差界在 AB-0 与 AB-1′ 成立时仍可使用。
4. **W-b** 作为待冻结的默认候选：在 P1 静态互斥总体下，`v_ℓ = M_ℓ / Σ_{ℓ'} M_{ℓ'}` 对应并集总体上的等节点权重平均。
5. 域 C 手数权重 `w_f = K_f / Σ_{f'} K_{f'}` 作为待冻结的默认候选；此时 `Σ_f w_f² / K_f = 1 / H`。
