## 4. 域 A／域 B：节点级量型裁定（AB-0 仍无定义）

### 4.1 域 A：采用 A-1

在**未来冻结**的决策节点 `n` 上，节点级量采用**直接观测概率质量差**：

```text
y_A(n) := q_c(i, n) − q_c(i′, n)
```

其中：

- `q_c` 为 `74b` 契约规定的**概率单位**下的边缘或条件质量（经约定查询模式与分域归一后）；**不是**动作采样得到的 `{0,1}` 指示量，**不是**样本频率或身份评估输出。
- `(i, i′)` 为**未来须冻结**的候选动作（或候选集合元素）对；本裁定**不**指定具体对、**不**登记节点清单。

**支持界（条件性，须 AB-0 链路写定后才可引用）**：若在所选查询模式下 `q_c(i,n), q_c(i′,n) ∈ [0,1]`，则 `y_A(n) ∈ [−1, 1]`，对应层内 `R_ℓ = 2`（`74i` §3.4、`74k` §6 对 `74j` §8.1 的更正口径）。

**仍待未来锁定（精确对象）**：域 A 节点注册表；每个节点上的合法动作枚举与**唯一**采用的 `(i, i′)`；`q_c` 所依查询模式（边缘／条件、分域键）；据此推出的逐层 `[a_ℓ, b_ℓ]` 与 `R_ℓ`。**在以上对象未锁定前，AB-0 无定义**，不得宣称支持界已成立。

### 4.2 域 B：采用 B-1 的单一已命名桶概率质量差

在**未来冻结**的决策节点 `n` 上，域 B 节点级量采用**单一已命名金额桶**上的概率质量差（两身份、同一桶、同一节点）：

```text
y_B(n; b*) := q_x(b*, n) − q_y(b*, n)
```

其中：

- `b*` 为**未来须冻结**的桶名称（或规范序中的唯一标量桶标签）；本裁定**只**采用「单桶差」这一标量形式，**不**采用多桶向量范数分量或未标量化的联合差（`74z` B-3 类）。
- `q_x`, `q_y` 为契约下两比较身份在节点 `n`、桶 `b*` 上的概率单位质量（`74b` 金额／概率分链；域 B 分域中**尚未冻结**的部分须在未来规格层补齐）。

**支持界（条件性）**：在桶枚举与概率单位写定后，单桶差界由定义域推出（典型情形 `y_B ∈ [−1, 1]`，从而 `R_ℓ = 2`）；**须**与 `M_AB(v) = (Σ_ℓ v_ℓ R_ℓ)² / 4` 所用 `R_ℓ` 一致（`74h` §6.3）。

**仍待未来锁定（精确对象）**：金额分区与**完整**桶集合；每个域 B 节点上采用的**唯一** `b*`；两比较身份在规格层的命名与查询键；`74c`／实现链未闭合部分。**在桶名与分域未锁定前，AB-0 无定义**；`74d` 契约一致性**不**补建该缺失。

### 4.3 与 `74y` 的关系

若节点外生字段或 `q_c`／`q_x` 查询键含物理座位或相对庄位标签，层谓词与节点键的冻结须与 `HandPlan`／`schedule` 及已生效 `seat_rotation` **一并**审查（`74y` §4.1）。本裁定**不**因 `seat_rotation` 生效而默认任何 A/B 节点或桶已登记。

## 5. 层总体：采用 P1 静态互斥层

采用 **`74k` §4.3-1 / `74j` §7.1 / `74z` §6.1 的 P1 路径**：

1. **未来冻结**层优先序 `≺` 与层谓词 `I_ℓ(n)`；谓词**只能**依赖节点外生字段、已冻结标签与合法动作集枚举，**不得**读取策略输出、分布观测运行结果、候选身份读数或块结果（`74k` §4.3、`74z` §5.1）。
2. 主判层集合 **`L*`**：**未来冻结**；本裁定**不**给出层清单。
3. 对每个 `ℓ ∈ L*`（在 `L*` 写定后）：

```text
P_ℓ := { n : I_ℓ(n) ∧ ∀ ℓ′ ≺ ℓ, ¬I_{ℓ′}(n) }
M_ℓ := |P_ℓ|
```

4. 层内样本量 **`n_ℓ`**：**未来冻结**（须满足 `1 ≤ n_ℓ ≤ M_ℓ`；抽样层 `n_ℓ ≥ 2` 为后续非退化讨论的常见条件，**本裁定不**写死向量）。
5. 记 `L_s := { ℓ ∈ L* : n_ℓ < M_ℓ }`，`L_e := { ℓ ∈ L* : n_ℓ = M_ℓ }`，`c_ℓ := (M_ℓ − n_ℓ) / (M_ℓ − 1)`（`ℓ ∈ L_s`）——为**模板量**，在 `P_ℓ`、`n_ℓ` 锁定后方可计算。

**仍待未来锁定（精确对象）**：`I_ℓ` 的逐层定义；层优先序；`L*`；`P_ℓ`、`M_ℓ`、`n_ℓ` 的完整向量；`P_ℓ` 上节点**规范序**（供 §6 双射使用）。**在以上未锁定前，AB-1′ 无定义**；变更优先序或谓词须重算全部 `P_ℓ`、`M_ℓ`，已存在的 ② 文本（若将来发生）**失效**。

**不采用**：P2 联合抽样、P3 去重／补足为当前战役层总体路线（`74z` §6.1）。

## 6. 抽样构造：采用 S-1（AB-1′ 的来源型，仍未建立）

在 **P1** 与 **`74k` 随机化公理**前提下，将来构造 AB-1′ 时，采用 **`74z` §7.1 的 S-1**：

2. 按 **`P_ℓ` 的冻结规范序**，用组合数系统建立 `u_{j,ℓ}` 与 `n_ℓ` 元子集 `S_{j,ℓ}` 的**双射**。
3. 边缘分布：在 `P_ℓ` 上均匀无放回 `n_ℓ` ⇒ 满足 **AB-1′** 陈述（`74i`／`74h` 块级抽样假设）。

本裁定**不**预注册具体来源接口、落盘格式或层材料键；`74k` §7.1 基线成员随机材料（K-2）**不在**本文件裁定。**AB-1′ 仍未建立**——仅锁定「将来若建立，须沿 S-1 型构造」。

## 7. 层权重：采用 W-b 公式方向（W-1 仍未建立）

v_ℓ := M_ℓ / Σ_{ℓ′ ∈ L*} M_{ℓ′}

## 8. 块级上界：采用通用 `V_max^{AB}(v)`；暂不采用 AB-2z

### 8.1 采用的候选（`74i` §5.3 通用界）

在**将来** AB-0、AB-1′、W-1 **均成立**，且审查方在锁定或 ② 文本中**选用**本候选时，块级上界采用：

```text
V_max^{AB}(v) := ( Σ_{ℓ ∈ L_s} v_ℓ · √c_ℓ · R_ℓ / (2 √n_ℓ) )²
M_AB(v)² := ( Σ_ℓ v_ℓ · R_ℓ )² / 4
```

**本裁定含义**：在 A/B 前置设计面，**唯一**采纳的上界**路线**为上述通用 `V_max^{AB}(v)`；**不**并行保留「默认解算选用收紧界」的战役立场。

**条件性非退化**（`74i` §5.4）：`M_AB(v) > 0` 且 `n_s := min_{ℓ∈L_s} n_ℓ ≥ 2` ⇒ `V_max^{AB}(v) ≤ M_AB(v)² / n_s < M_AB(v)²`。**当前无已锁定 `v` 与层向量，不作解算主张**。

### 8.2 与 AB-0／AB-1′ 的依赖

- 未锁定 `R_ℓ`、`n_ℓ`、`M_ℓ`、`v` 时，上式**无运行意义**；不得用 campaign 读数或样本量事后填入。
- AB-1′ 未建立时，只能走 `74i` §3.4 退化或「支持界缺失」分支；**不得**声称已具备非退化比较上界。

### 8.3 暂不采用 AB-2z 与 `V_max^{AB,0}(v)`

本战役阶段对域 A/B **明确不采用**下列收紧路径作为设计前提或默认上界：

```text
AB-2z：∀ ℓ ≠ ℓ′，Cov(ȳ_{j,ℓ}, ȳ_{j,ℓ'}) = 0
V_max^{AB,0}(v) := Σ_{ℓ ∈ L_s} v_ℓ² · c_ℓ · R_ℓ² / (4 n_ℓ)
```

登记：

- **不**把独立层材料生成当作当前必建义务；**不**为选用 `V_max^{AB,0}` 预留默认立场。
- 若未来审查方单独裁定采纳 AB-2z，须**新授权新文档**；**不得**由本文件隐式启用。
- 在 AB-2z 未建立时误用 `V_max^{AB,0}` 可能导致上界非保守（`74z` §9.3 失效传播照录）。
