## 4. 本模块的实现层钉子（先于读数固定）

1. 配对键与两臂名沿用判定器口径；配对不完整即显式失败。
2. **面对状态** = 焦点座位在手内是否首次面对对手的下注或加注；**面对时街道取该事件的街**。
3. **未面对下注时街道取焦点座位手内最后一次动作所在的街**；整手未行动单列（`no-action`），不用其它街代替。
4. 牌力档直读工件字段 `focus_strength_bucket`；缺失或非字符串时单列（`None`）。
5. **行为构成只统计焦点座位的动作**（焦点座位 = 轮换号 % 人数）；主动占比 = `bet` 与 `raise` 占全部已登记动作的比例。
6. 净筹码换算每百手收益时使用固定大盲筹码数（与夹具口径一致，`10`）；给出报告工件时**交叉核对**该换算，不一致即停止。
7. 样本量低于 `30` 对的桶照样输出并标记稀疏。

**必须声明**：上述分桶**不属于**判定器已钉死的口径，因此这些读数**不得**与判定口径或任何历史轮次的桶化数字**跨轮比较**。
