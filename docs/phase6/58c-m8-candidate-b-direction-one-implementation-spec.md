## 4. 方向①的机械明细

### 4.1 新增字段（**必须带默认值且默认等价现状**）

| 项 | 明细 |
|---|---|
| 字段 | `situational_active_gate: bool = False` |
| 语义 | `False` ⇒ 沿用既有主动分支门槛（`@1`–`@7` 的分布**逐位不变**）；`True` ⇒ 启用「按风格且随公开局面变化」的主动门槛偏移 |
| `@8` 取值 | `True` |

**为什么用一个布尔字段 + 模块常量，而不是新增逐风格数值字段**：沿用 `A-i` 的既有做法（`docs/phase6/62` §4.1 / §4.2），把可调面收敛到**实施前固定、之后不得按读数调整**的模块常量，并把摘要字段面控制在最小增量（§10）。

### 4.2 新增模块常量（**实施前固定，之后不得按读数调整**）

| 常量 | 取值 | 依据（**原理性，不是按读数**） |
|---|---|---|
| `_VALUE_GATE_TOLERANCE` | `120` | 把 `mixed_policy.py` 中现有的**内联字面量** `120`（`value_quality = max(0, score - value_threshold + 120)`）提取为具名常量，**取值不变** ⇒ 开关关闭时逐位不变 |
| `_ACTIVE_GATE_WEIGHT`（逐风格） | `tight = −6`、`aggressive = +8`、`calling = +1` | 符号由**风格语义**决定（`tight` 更少半诈唬、`aggressive` 更多），量级取**容差 `120` 的约 `5%`**（`≤8`），刻意克制；三档**互不相等**，使风格分化不存在平局 |
| `_ACTIVE_GATE_INDEX_CAP` | `100` | 局面指数的上限；使 `G` 的值域为 `[−8, +8]`，即相对容差不超过约 `6.7%` |
| `_ACTIVE_GATE_POSITION_SPAN` | `60` | 局面指数的位置分量权重 |
| `_ACTIVE_GATE_DRAW_SPAN` | `40` | 局面指数的听牌分量权重；两项合计 `= _ACTIVE_GATE_INDEX_CAP`，使指数落在 `[0, 100]` 而无需再缩放 |

**为什么这些取值不构成「为跨阈值调常量」**：`120` 是现状原值；`−6 / +8 / +1` 由**风格语义与容差的比例**给出，与任何门槛数值无关；本规格**禁止**在读数之后调整它们，也**禁止**以「让域二达到 `10` 个百分点」为目标反推取值。

### 4.3 局面指数与门槛偏移（公式）

```text
# 只在翻后生效；翻前 G = 0。
I = clip( (position + 40) * _ACTIVE_GATE_POSITION_SPAN // 80
        + min(draw, _NON_VALUE_DRAW_CAP) * _ACTIVE_GATE_DRAW_SPAN // _NON_VALUE_DRAW_CAP,
        0, _ACTIVE_GATE_INDEX_CAP )                      # I ∈ [0, 100]

G(style, features) = _ACTIVE_GATE_WEIGHT[style] * I // _ACTIVE_GATE_INDEX_CAP   # G ∈ [-8, +8]
```

```text
value_quality = max(0, score - value_threshold + _VALUE_GATE_TOLERANCE + G)

bluff_raw     = _non_value_quality(features, rules)          # 既有函数，不改
bluff_quality = max(0, bluff_raw + G) if bluff_raw > 0 else 0
```

**要点**：

1. **`I` 只由公开特征构成**（位置与听牌质量），二者都是既有代码已在用的公开量；**不读取**暗牌、未发牌或任何非公开信息；
2. **`G` 随局面变化**：`I = 0` 时三档偏移同为 `0`（与现状一致），`I` 越大偏移越大 ⇒ 满足「随公开局面变化」而**不是常量平移**；
3. **`bluff_quality` 不凭空造依据**：`bluff_raw = 0` 时仍为 `0`（「只在有公开依据时给分」的既有不变量**不变**）；只在 `bluff_raw > 0` 时按同一 `G` 调整幅度；
4. **整数运算**：全部为整数加减与向下取整除法，**无浮点**，同一输入必得同一输出；
5. 翻前 `G ≡ 0` ⇒ 翻前主动分支与 `@7` **逐位相同**。

### 4.4 与现状的差异（**最小化**）

| 情形 | 现状 | 启用后 |
|---|---|---|
| 开关关闭（任一既有身份） | — | **逐输入逐输出相同**（`_VALUE_GATE_TOLERANCE = 120`）|
| 翻前（`@8`） | — | **与 `@7` 逐位相同**（`G = 0`）|
| 翻后、`I = 0` | — | **与 `@7` 逐位相同**（`G = 0`）|
| 翻后、`I > 0` 且 `bluff_raw = 0` | `value_quality` 与 `bluff_quality` 与风格无关 | 三档 `value_quality` 分别 `−6/+1/+8` 的**按 `I` 缩放**偏移；`bluff_quality` 仍为 `0` |
| 翻后、`I > 0` 且 `bluff_raw > 0` | 同上 | `value_quality` 与 `bluff_quality` **同时**按同一 `G` 偏移 |

⇒ 本改动**只移除一处**：主动分支门槛与半诈唬幅度在**翻后**上的**风格无关性**。

### 4.5 保留不变的部分（**不得一并改动**）

- 四条准入判断保持原样：`live_opponents == 0` 归零、`recent_aggression > 1` 归零、翻前 `position < 0 或 base < 280` 归零、翻后 `draw <= 0 且无 A/K 阻断` 归零；

- `active_scale_percent` / `contender_penalty_cap` 的 `@6` 取值**不动**；
- `_non_value_quality` 的既有准入与两个分量的算法（`continuous_non_value_basis` 的连续式）**不动**；
- 翻前跟注偏移（`preflop_call_bonus` / `postflop_call_bonus`）**不动**。

2. **不得以跨阈值为目标**：§4.2 的取值只由风格语义与容差比例给出；本规格**禁止**在读数后调整；
3. **显式保护**：§8.2 的六项全部进入 `B-3` / `B-4` / `B-5` 的回归与并列报告；
4. **稳定性不作改善证据**：写入 §12 与 §13。

### 8.4 被排除的更强变体（**不在本规格范围**）

- 调整 `fold_percent` / `call_percent`（**分母**参数）以消除「分母反噬」：**不做**。理由是它会同时移动被动分支的全部既有行为，归因无法与 `A-i` 分离，且属「改被动分支」而非方向①；
- 把门槛偏移做成**逐风格数值字段**（进摘要面）：**不做**，沿用布尔字段 + 模块常量的最小增量（§4.1）。

### 8.5 本设计**不消除**分母影响（必须一并披露）

方向①分化的是**分子上的准入与幅度**；**分母**（`fold_percent` / `call_percent` / 翻后跟注偏移）**保持不变**。因此：

- 主动率的排序**仍然**受分母影响，只是分子现在**自身携带风格差异**；
- 因此 `B-2`（主动率排序与主动权重排序一致）在**部分节点上仍可能不成立**——这是**设计的已知边界**，不是实现缺陷；
- 若 `B-2` 不成立，正确的处置是**如实记为「机制未达成其目标」并上报**，**不得**回头调大 `_ACTIVE_GATE_WEIGHT` 或改判据。
