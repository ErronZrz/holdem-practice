## 3. 阻断一：支持界前提失效时的处置

### 3.1 裁定要求

`74h` §3.5 把 `M_C² := E²` 作为回退对象，但 `E` 本身依赖 C-1′；C-1′ 不成立时 `E` 与 `M_C²` 均无有效定义，不能「回退 `M_C²`」。

### 3.2 域 C 的分层失效处置（取代 `74h` §3.5「失效处置」）

| 情形 | 处置 |
|---|---|
| **C-1′ 不成立**（或 `E` 尚未由规则推出） | 域 C 的本条路径**没有有效支持界**：`E`、`M_C²`、`V_max^C` 均**无定义**。不得写「回退 `M_C²`」，也不得报告为「退化」。须如实报告为「**支持界缺失、本路径不可用**」，直到另行给出有效的逐手或块级支持界（见 §3.3） |
| **C-1′ 成立**，但 C-2′ 或 F-0 不成立 | 回退到已定义的 `M_C² = E²`，并报告「**本结构路径退化**」；或另行给出不依赖该前提的非退化界 |
| C-1′、C-2′、F-0 均成立 | `V_max^C = E² / K_min`（`74h` §3.5）；非退化条件为 `K_min ≥ 2` |

### 3.3 替代支持界的登记要求

若未来给出不同于 C-1′ 的支持界（例如块级而非逐手的界，或由不同规则口径推出的界），必须单列：

- 替代界的**记号**（不得复用 `E` / `M_C`）、对象（逐手或块级）与**来源**（规则推导或冻结模板，不得来自任何身份读数、实测离散度或成本读数）；
- **适用条件**与**保守方向**；
- 在该替代界下的朴素界定义、非退化比较与退化报告口径；
- 与本记录 `V_max^C` 推导的关系（若逐手界改变，`74h` §3.4 的推导须以替代界重做，不得静默沿用）。

### 3.4 域 A / 域 B 的平行处置（同一逻辑，一并写明）

## 4. 阻断二：A/B 的权重类与统一上界关系

### 4.1 裁定要求

`74h` §6.4 的绝对统一上界 `max_{ℓ ∈ L_s} [c_ℓ R_ℓ² / (4 n_ℓ)]` 可由大范围层决定，而合法权重可几乎全部压在小范围层上，此时该上界不小于 `M_AB(v)²`。因此不能同时声称「对全部非负、和为 `1` 的权重给出统一上界」与「该统一上界相对每个 `M_AB(v)²` 非退化」。须在固定权重路径与受限权重类路径之间择一。

### 4.2 撤回

**撤回** `74h` §6.4「绝对统一上界」一段、§6.5 中「且对全部非负、和为 `1` 的权重一致成立」一语，以及 `74h` 中任何「A/B 非退化界对全部非负、和为 `1` 的权重一致成立」的表述。域 A / 域 B 在本记录中**不再**主张对全部权重一致非退化。

### 4.3 采用：固定权重路径

本记录采用**固定权重路径**：

- 层权重 `v` 须由设计裁定写定并冻结，冻结后不得变更；本记录**不**选定 `v` 的取值。
- 适用权重类为**单点类** `{v}`；因此满足 `74f` §4.2.3 第一款「对该已冻结权重类一致成立」的要求（单点类上的一致即对该 `v` 成立）。
- 解算用统一上界为 `v` 与模板量的确定函数，对全部未来块成立（不含任何种子值或块依赖项）：

```text
V_max^{AB}(v) := ( Σ_{ℓ ∈ L_s} v_ℓ · √c_ℓ · R_ℓ / (2 √n_ℓ) )²          （通用形式，推导见 §5.3）
V_max^{AB,0}(v) := Σ_{ℓ ∈ L_s} v_ℓ² · c_ℓ · R_ℓ² / (4 n_ℓ)              （仅在层间零协方差时可用的收紧形式，见 §5.5）
L_s 为空时两者均为 0
```

- 非退化比较对象为同一 `v` 下的 `M_AB(v)²`（`74h` §6.3），见 §5.4。

### 4.4 受限权重类路径：登记为未来候选

受限权重类路径（给出权重类 `W`，并证明存在同一上界 `U` 使得对每个 `v ∈ W` 同时有 `V_j ≤ U < M_AB(v)²`）**不在本记录推导**。若未来提出，须另行写明 `W` 的定义与冻结方式，并完整证明 `sup_{v ∈ W} V_max^{AB}(v) ≤ U < inf_{v ∈ W} M_AB(v)²` 或等价结论；未完成前不得援引。

## 5. 阻断三：AB-2′ 的适用范围与通用层间协方差推导

### 5.1 裁定要求

`74h` §5.3 的 AB-2′ 允许「零协方差**或**显式非退化层间协方差界」，但 `74h` §6.4 只推导了零协方差情形。须二选一：收窄 AB-2′ 为零协方差；或补齐通用交叉项界并证明其仍严格非退化。

### 5.2 采用：补齐通用交叉项界

本记录采用第二种：给出**不对层间协方差作任何假设**的通用界，并把零协方差降为可选的收紧前提（§5.5）。所需前提只有 AB-0 与 AB-1′；层间协方差由 Cauchy–Schwarz 不等式**推出**界，**不是**假设。

### 5.3 推导（在 AB-0 与 AB-1′ 下）

```text
记 s_ℓ := √Var(ȳ_{j,ℓ}) 。
层内（74h §6.4，AB-0 ＋ AB-1′ ＋ Popoviciu）：
  ℓ ∈ L_s：  s_ℓ ≤ √c_ℓ · R_ℓ / (2 √n_ℓ)
  ℓ ∈ L_e：  s_ℓ = 0

交叉项（Cauchy–Schwarz，对任意联合分布成立）：
  |Cov(ȳ_{j,ℓ}, ȳ_{j,ℓ'})| ≤ s_ℓ · s_{ℓ'}

块级方差：
  V_j = Σ_ℓ v_ℓ² s_ℓ² + 2 · Σ_{ℓ < ℓ'} v_ℓ v_{ℓ'} · Cov(ȳ_{j,ℓ}, ȳ_{j,ℓ'})
      ≤ Σ_ℓ v_ℓ² s_ℓ² + 2 · Σ_{ℓ < ℓ'} v_ℓ v_{ℓ'} · s_ℓ s_{ℓ'}
      = ( Σ_ℓ v_ℓ s_ℓ )²
      ≤ ( Σ_{ℓ ∈ L_s} v_ℓ · √c_ℓ · R_ℓ / (2 √n_ℓ) )²  =  V_max^{AB}(v)
```

- 该式对层间的任意相关结构成立，**包括**跨层去重 / 补足导致的相关；它不需要、也不使用 AB-2′。
- 交叉项 `2 Σ v_ℓ v_{ℓ'} |Cov|` 的界即 `2 Σ v_ℓ v_{ℓ'} s_ℓ s_{ℓ'}`，已完整进入 `V_max^{AB}(v)`。

### 5.4 非退化比较（固定 `v`）

```text
记 n_s := min_{ℓ ∈ L_s} n_ℓ 。由 c_ℓ ≤ 1、n_ℓ ≥ n_s 及 v_ℓ R_ℓ ≥ 0：
  √V_max^{AB}(v) = Σ_{ℓ ∈ L_s} v_ℓ √c_ℓ R_ℓ / (2 √n_ℓ)
                 ≤ (1 / √n_s) · Σ_{ℓ ∈ L*} v_ℓ R_ℓ / 2
                 = M_AB(v) / √n_s
⇒ V_max^{AB}(v) ≤ M_AB(v)² / n_s
```

- `M_AB(v) > 0` 且 `L_s` 为空：`V_max^{AB}(v) = 0 < M_AB(v)²`。
- `M_AB(v) > 0` 且 `n_s ≥ 2`：`V_max^{AB}(v) ≤ M_AB(v)² / n_s < M_AB(v)²`，**严格非退化**，收紧倍数不小于 `n_s`。
- `n_s = 1`：本记录**不**主张严格非退化。
- `M_AB(v) = 0`：平凡情形（`74h` §6.3），不作非退化主张。
- 由此，在 AB-0 与 AB-1′ 成立时，层间协方差**不再**构成退化条件；§3.4 表中的退化只来自 AB-1′ 失效。

### 5.5 零协方差收紧（可选前提）

```text
AB-2z：对任意 ℓ ≠ ℓ'：Cov(ȳ_{j,ℓ}, ȳ_{j,ℓ'}) = 0 。（未建立；不再是非退化的必要前提）
在 AB-0、AB-1′、AB-2z 下：
  V_j = Σ_ℓ v_ℓ² s_ℓ² ≤ V_max^{AB,0}(v) ≤ V_max^{AB}(v)
```

`V_max^{AB,0}(v) ≤ V_max^{AB}(v)` 由各项非负（平方和不超过和的平方）给出。AB-2z 的构造来源须另行给出；`74h` §5.2 第 1 条的更正（存在去重 / 补足时，输入端独立不能推出 AB-2z）继续有效。

### 5.6 与 `74h` §5.4 候选路径的关系（登记，不作裁定）

- 本节表明：若采用通用界，`74h` §5.4 各候选路径中「层间协方差满足所需非退化界」一项在 AB-0 与 AB-1′ 成立时由 §5.3 自动满足；**AB-1′（每层边缘为写定总体上的均匀无放回分布）仍须由所选路径完整给出**，且在保留去重 / 补足时其成立与否正是待证对象。
- 是否据此调整 `74h` §5.4 的要求、以及选用 `V_max^{AB}(v)` 还是 `V_max^{AB,0}(v)`，属于设计裁定事项；本记录**不**改动 `74h` §5.4 的要求，也**不**作选择。
- 本节推导由推导方给出，须经独立于推导方的主体在 ③ 中核验后方可援引。
