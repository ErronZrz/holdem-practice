## 2. 域 C：主判范围、路线与基线池

### 2.1 主判格与片段口径

| 项 | 固定取值 |
|---|---|
| 主判人数 | `N ∈ {2, 3, 4, 5, 6, 7, 8, 9}`；八个人数逐一为主判格 |
| 主判深度 | 标准深度 `100 BB` |
| 盲注 | 小盲 `5`、大盲 `10`；全部金额使用整数筹码单位 |
| 起始筹码 | 每座位 `1000`，即 `100 BB` |
| 按钮位 | 每个主判格按 `0..N−1` 等权轮换；不构成新的主判比较维度 |
| 片段长度 | 每片段 `K = 100` 手 |
| 片段构成 | 每手均为新鲜起始牌局；全部座位均重置为相同的 `1000` 起始筹码；手内不补码；片段是唯一统计单元 |

### 2.2 路线、基线与聚合

| 项 | 固定取值 |
|---|---|
| 域 C 路线 | 唯一选择 `R2`（Cantelli）；`R1` 不作为本战役冻结路线，也不得作为失败后的替代路线 |
| 基线池 | `heuristic@1` 与 `random@1`，成员数 `M = 2` |
| 基线角色 | `heuristic@1` 为迁移基线；`random@1` 为固定辅助基线；两者均为同权主判成员 |
| 聚合 | 每个 `N` 下对两个基线成员取同时下界的最小值；八个人数必须全部满足 |
| 比较数 | `G = 8`、`M = 2`，故 `N_cmp,C = 16` |
| 逐项水平 | `α_C′ = 0.05 / 16`；`β_C′ = 0.20 / 16` |
| 风险与功效输入 | `δ_budget = −10 BB/100`、`δ_alt = 0 BB/100`、`m = 10 BB/100`、`α_C = 0.05`、`β_C = 0.20` |

`random@1` 的随机源可注入 `seed`，`heuristic@1` 同样接受可注入 `seed`；两者均作为未来清单的固定版本化成员。不得把 `random@1` 的弱度或任何相对 `heuristic@1` 的结果表述为强度已证明。

## 3. 域 D：探针池

冻结探针池如下；它们只属于报告域，不进入域 C 基线池：

```text
passive-call-probe
fixed-pressure-probe
size-signal-probe
position-pressure-probe
marginal-call-pressure-probe
aggression-rate-probe
```

- 探针池版本随未来冻结的 `code_identity` 一并锁定。
- `marginal-call-pressure-probe` 的纳入只为保持探针覆盖连续性，不将 `58n` 升格为因果根因或调参依据。
- 域 D 只允许报告「本次样本集与本次探针池下未观察到 / 观察到某信号」，不得用于强度结论。

## 4. 域 A：人格可感知性

### 4.1 人格集合与权重

```text
I = {TIGHT, AGGRESSIVE, CALLING}
v_TIGHT = v_AGGRESSIVE = v_CALLING = 1/3
```

### 4.2 主判情境

| 情境 ID | 外生节点条件 | 有向人格对 | 预注册动作类别 |
|---|---|---|---|
| `A1-free-aggression` | 当前行动者可 `CHECK` 或 `BET/RAISE`，且不存在待跟注额 | `AGGRESSIVE → TIGHT` | `BET ∪ RAISE` |
| `A2-facing-fold` | 当前行动者面对正待跟注额，且可合法弃牌 | `TIGHT → CALLING` | `FOLD` |

```text
情境数 = 2
有向人格对数 = 1 / 情境
N_cmp,A = 2
α_A′ = 0.05 / 2 = 0.025
β_A′ = 0.20 / 2 = 0.10
π_A = 0.15
Π_alt = 0.30
Δ_alt = 0.15
```

两个情境均按 `N = 2..9` 的外生等权节点来源构成。人数只作为节点生成分层，不额外进入域 A 的比较数。不得按人数、人格、风格实际出现频率或候选读数重加权。

## 5. 域 B：不可预测性

### 5.1 主判分域与联合边缘化

```text
B1-preflop：翻前、当前行动者至少有两个合法动作
B2-facing-bet：翻后、当前行动者面对正待跟注额且至少有两个合法动作
B3-free-action：翻后、当前行动者无待跟注额且至少有两个合法动作

HandMode 权重：
NORMAL   = 0.80
CAUTIOUS = 0.10
PRESSED  = 0.10

人格权重：
TIGHT       = 1/3
AGGRESSIVE  = 1/3
CALLING     = 1/3
```

### 5.2 金额语义与金额集合

```text
Action.amount 为 BET / RAISE 后的总额，单位为整数筹码。
P := max(1, 当前节点 state.pot)。
```

主判锚点集合 `A_B`：

| 锚点 | 整数区间定义 |
|---|---|
| `half-pot` | `2 × amount ≥ P` 且 `4 × amount < 3 × P` |
| `pot-sized` | `4 × amount ≥ 3 × P` 且 `4 × amount ≤ 5 × P` |

条件熵分区 `P_B`：

| 分区 | 整数区间定义 |
|---|---|
| `under-half` | `2 × amount < P` |
| `half-to-three-quarter` | `2 × amount ≥ P` 且 `4 × amount < 3 × P` |
| `three-quarter-to-one-and-quarter` | `4 × amount ≥ 3 × P` 且 `4 × amount ≤ 5 × P` |
| `over-one-quarter` | `4 × amount > 5 × P` |
| `other` | 仅在金额无法归入前四个互斥区间时使用；不得进入 `A_B` |

### 5.3 比较数、统计水平与阈值

```text
分域数 = 3
|A_B| = 2
N_cmp,B = 3 × (2 + 2) = 12
α_B′ = 0.05 / 12
β_B′ = 0.20 / 12

ω_B = 0.50 bit
ω_alt = 0.80 bit
Δ_Ω = 0.30 bit

π_min^act = 0.20
π_act^alt = 0.35
Δ_act = 0.15

π_min = 0.05
π_alt = 0.10
Δ_π = 0.05
```

`π_min` 对 `A_B` 中每个锚点分别适用；`P_B`、`other` 与金额条件熵不适用该阈值。若 `A_B` 与概率单纯形不兼容，必须否决该集合设计，不得降低门槛。
