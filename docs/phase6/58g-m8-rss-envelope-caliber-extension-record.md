## 4. 与冻结清单文本的差异（必须如实披露）

清单内的 `resource_envelope` 文本由**共享常量**生成（`MIXED_RESOURCE_ENVELOPE` 引用 `STAGE_RSS_BYTES = 1024 × 1024 × 1024`），因此：

- 任何**将来冻结**的清单（含第五次独立验证的第六套清单）其文本仍会写作 `RSS ≤ 1073741824 字节`（`1 GiB`）；
- 本裁定**只改变判定与记账口径**，**不改变清单内容**，也**未授权**改动该常量 ⇒ 二者之间**存在已披露的差异**：清单文本 `1 GiB`，本文件起判定上界 `1.5 GiB`；
- **不得**为了让清单与本裁定一致而重新生成或覆盖清单，也**不得**声称清单已更新；
- 若将来需要让清单文本与判定上界一致，须**单独授权**改常量并评估其对既有清单可复现性的影响（该动作**本轮未做**）。
