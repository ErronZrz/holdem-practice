## 1. 选定口径

下列口径由本文件直接选定。被排除的做法只作边界，不再并列待选。

| 缺口 | 选定做法 | 排除 |
|---|---|---|
| V-1 配对路径 | 包外 `backend/tools/pairing_harness.py` 用两份独立引擎、同一份注入发牌和显式行动脚本打到终局；`verification` 只核对终局记录 | 在 `verification` 内创建引擎或提交行动 |
| V-2 净差上界 | 由「开手每人 `S`、终局非负、总和仍为 `N·S`」推出单座净差区间 `[-S, (N-1)·S]`，再推出两臂之差上界 `N·S`；不守恒的终局直接拒绝 | 把某次运行时抽查写成规则证明，或改终局分配语义 |
| V-3 片段 | `DomainRunSpec` 增加含端点的连续手序片段。片段必须按序、互不相交，并恰好覆盖手序计划。最短片段不足两手时必须显式登记退化 | 就地改写 `74v`；在规格里偷偷填默认片段 |
| V-4 权重 | 每个片段带既约整数分数，且必须等于该片段手数除以块内总手数 | 用浮点近似；把域 C 片段权重写成域 A／B 的层权重 |
| `domain_ab_*` | `CampaignLockVersions` 增加六项，且每一项必须为 `1`，并进入配置摘要。包内静态表核对节点快照、桶归属与层选择键；合法动作由快照字段推出，再与引擎当场的合法动作对照 | 只在文档里声明版本、不进入摘要 |
| 域 B 观测链 | 策略层按金额分段，并只在「未指定模式的合并输出」上累加主判桶的整数单位，再给出两身份之差的分子与共用分母 | 在 `verification` 内调用策略或推进对局来冒充实测 |

`74v` 与 `74ab` 的已生效句子保持原样。本文件只增加可执行载体与核对，不升那些锁定文本的版本号。

## 3. 直接断言覆盖的机械项

| 原来不可执行的原因 | 现在的直接断言 |
|---|---|
| 无配对路径，不能核对两臂发牌、开手重置与终局净差 | 包外脚本打完两臂；校验器拒绝发牌不一致、开手不是 `S`、终局不守恒或净差越界 |

| 无权重字段 | 权重与手数占比用整数交叉相乘核对，不经过浮点 |
| 配置摘要没有六项域版本 | 摘要载荷含六项且都为 `1`；绕过构造校验后仍被拒绝 |
