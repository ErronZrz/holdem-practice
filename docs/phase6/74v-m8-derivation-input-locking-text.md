### 4.1 锁定规则（`74u` 裁定：P-1 至 P-4）

| 编号 | 规则 |
|---|---|
| PR-1（P-1） | **同一 deal（D-a）**：两臂使用同一份发牌材料 `G_h`；底牌与公共牌由已锁定 L-1 映射唯一确定；两臂材料逐字节相同 |

**排除**：**D-b**（双洗牌种子）不得作为「同一 deal」口径。

## 5. `per_hand_bound`（拟定锁定版本 1；送审稿，未锁定）

**`lock_versions` 字段**：`per_hand_bound: 1`（生效后）。

**适用范围**：在 PR-3 与下列规则前提下，单手上被测座位净筹码差 `d_h` 的**规则上界**；用于 ② 中 `D`、`E` 与 `74h` 域 C 记号；**不**代入具体 `N`、`S` 数值。

**白名单归属**：**属于**「引擎规则给出的每手上界」。**② 使用**；**③ 使用**。

### 5.1 规则前提（裁定锁定）

下列前提在锁定文本中**写死**，作为上界推导的假定：

1. **无抽水**：本手无 rake、无外部筹码注入或抽出。
2. **筹码守恒**：本手全部投入仅在参与该手的座位之间重新分配。
3. **手内不补码**：与 PR-3 一致。
4. **整数筹码单位**：所有筹码量为非负整数（单一整数单位）；`d_h`、`m_h`、`b_h` 为整数。

### 5.2 上界与记号（裁定：`D = N · S`）

在 §5.1 前提下：

```text
m_h, b_h ∈ [−S, (N−1)·S]   （整数）
⇒ d_h ∈ [−N·S, N·S]
D := N · S
E := 100 · D / BB = 100 · N · S / BB
```

**裁定拒绝**将 `D` 取为 `2(N−1)S` 作为本锁定版本 1 的口径（历史 `73b` 更松上界不在此锁定）。

**边池／平分／余筹**：在 §5.1 与 `poker/` 引擎规则下，终局 `m_h`、`b_h` 仍须满足 `|d_h| ≤ D`；③ 的机械核验义务包括核验规则推导与引擎结构在该前提下不越界（**不得**读取身份输出）。

### 5.3 来源

`74u` 裁定（`D = N·S` 与前提四项）；`74j` §4.3；`74h` §3.5（`E`、`V_max^C` 记号）。

## 7. `weight_class`（拟定锁定版本 1；送审稿，未锁定）

**适用范围**：**仅域 C** 的片段权重类与默认权重公式；**不**锁定域 A／域 B 的层权重 `v_ℓ`（须另案）。

**白名单归属**：**属于**「块内权重」。**② 使用**（域 C 一致界）；**③ 使用**。

### 7.1 锁定规则（裁定：仅域 C）

**适用类 WC-1**：片段权重向量 `(w_f)` 满足：

- 对每个片段 `f`，`w_f` 为实数且 `w_f ≥ 0`；
- `Σ_f w_f = 1`（精确归一，非近似）。

**默认公式 WC-2（裁定锁定）**：在 `K_f` 已按 §6 确定时，

```text
w_f := K_f / Σ_{f'} K_{f'}
```

该默认公式为锁定版本 1 的**规范默认估计权重**；具体数值权重向量在 ⑥ 第二层冻结，但须落在 WC-1 内，且若采用默认估计对象则须等于 WC-2。

**排除**：不得在 ② 中引用未锁定的域 A／B 层权重类；不得把 `73b` 历史权重当作已冻结依据。

### 7.2 来源

`74u` 裁定（仅域 C、非负归一、默认 `w_f = K_f/ΣK_f`）；`74j` §8.3；`74h` §3.5；`74f` §4.2.3（适用权重类）。
