## 2. 统计对象与术语

| 术语 | 定义 |
|---|---|
| **对局片段** | 一个**不可再分**的统计单元，由 §3 的外生规则从一次会话的对局序列中切出 |
| **块** | 一组共享同一随机源的片段；**最小的重抽样单元** |
| **格子** | 由**主判/次判/诊断**维度（§5.1）确定的取值组合 |
| **基线池** | 预先冻结的一组**强度比较基线**及其配对规则（§6） |
| **探针池** | 预先冻结的一组**对手条件探针**（§7）；**不是**强度基线 |
| **配对差** | 同一片段下「被测身份」与「某基线」在同一牌堆派生流 / 同一位置 / 同一起始深度上的净结果差 |

### 2.1 估计目标（estimand）

对每个**主判格子** `g` 与基线池成员 `b`，定义：

```text
Δ(g, b) = 片段级配对差的期望，单位为「每 100 个大盲的筹码数」
          由片段内先按手求和、再按该片段的百大盲数归一化得到
```

**硬约束**：

1. `Δ` **必须**建立在**片段**之上，**禁止**把单手底池直接提纯为长期 `BB/100`；
2. 归一化所用的「百大盲数」**必须**由片段的**实际大盲参与量**决定，而**不是**由手数乘一个固定倍数；
3. 判定**只**使用 `Δ` 的**区间下界**（或等价的单侧检验），**不**使用点估计。

### 2.2 单元层级

```text
手 → 片段 → 块 → 格子 → 主判层
```

任一层级的聚合规则必须在冻结时**显式声明**；**禁止**跨层跳步（例如直接从手到主判层）。

## 3. 片段定义（外生且对称）

### 3.1 入选规则（唯一依据）

一个对局进入某个片段，**只**允许由下列条件决定：

1. **对局序号**：该对局在所属会话对局序列中的位置；
2. **公共条件**：人数、起始深度、按钮起始位、盲注结构；
3. **配对条件**：与配对基线的对应关系（§3.3）。

### 3.2 起止与切分规则（与策略无关）

- 片段按**预注册的序号边界**切分（例如「每 `K` 连续对局为一个片段，`K` 在冻结时固定」），或按预注册的**固定序号列表**切分；
- `K`（或序号列表）**不得**依赖任何动作、收益、行动线或事件的发生；
- 片段的起止**不得**因「某条行动线是否发生」而被延长、截断或跳过；
- **禁止**用「焦点是否进入某分支」「是否出现某动作」「是否发生某事件」作为入选或切分条件。

### 3.3 对称性核验（必须在运行前完成）

冻结后，必须能对**任一侧（被测或基线）**独立重放，得到**完全相同**的片段集合：

1. 片段划分是**身份的纯函数**：给定（清单、种子、片段规则），片段集合唯一；
2. 核验方式（**只读**，可用既有工件或新清单的构造期数据）：对同一（人数 × 深度 × 起始按钮位）构造两侧的对局序列，逐片段比对**成员对局序号集合**是否逐项相等；
3. 任一不相等 ⇒ **框架不得冻结**（这是可自动判定的硬门）。

### 3.4 禁止项汇总

| 禁止 | 原因 |
|---|---|
| 依赖被测策略的动作 / 收益决定入选或切分 | 策略会改变样本构成 ⇒ 自证 |
| 依赖基线策略的动作 / 收益决定入选或切分 | 同上（对称性破坏） |
| 以「是否进入某行动线」切分 | 把结果条件写进样本定义 |
| 以「是否发生某事件」事后调整片段边界 | 事后选样本 |
| 让片段长度随人数 / 风格变化而不预先声明 | 不可审查的隐含分层 |

## 4. 配对、块与方差处理

### 4.1 配对规则

- 配对**必须**满足：同牌堆派生流、同位置（按钮位与座位关系）、同起始深度；
- **禁止**把新动作接到旧历史后缀上算反事实 EV；
- **禁止**用不同牌堆的样本拼出「改善」。

### 4.2 块的定义与来源

- **块 = 最小的重抽样单元**，其成员来自同一随机源；
- **块数由样本集设计决定**（种子结构与派生规则，属**清单层**、与任何身份无关）；
- **禁止**按读数增删块、合并块或改变块与种子的对应关系。

### 4.3 区间与聚类

- 区间**必须**在**块层**聚类（块级重抽样，或等价的聚类稳健方法）；
- **必须并列报告**：点估计、区间、块级离散度、块极值、逐主判格子分解；
- **禁止**只报合并均值；**禁止**用合并均值代替逐格子结论。

### 4.4 方差输入的独立来源（**不含任何候选身份读数**）

方差输入**只**允许来自**引擎与清单层的解析量**：

```text
单手净筹码的绝对值上界：      |net| ≤ (N − 1) · S
片段级配对差的绝对值上界：    |Δ| ≤ 2 · (N − 1) · S / BB · 100 / K
⇒ 保守标准差上界：           σ(g) ≤ 2 · (N_g − 1) · S_g / BB · 100 / K_g
```

其中（全部为**引擎 / 清单层**常量，与策略无关）：

| 符号 | 含义 | 来源 |
|---|---|---|
| `N_g` | 该格子的人数 | 清单 |
| `S_g` | 该格子的起始筹码 | 清单 / 引擎构造参数 |
| `BB` | 大盲 | 引擎盲注结构 |
| `K_g` | 该格子的片段手数 | §3.2（冻结值） |

**说明与限定**：

1. 该上界**保守**（把最坏情形当作常态），因此**只会**把样本量要求推高，不会放宽；
2. 该上界**只**用于 §9 的样本量解算，**不得**被当作真实方差、**不得**被当作任何结果的证据；
3. 冻结时必须**重新读取当时代码的实际常量**并记录为快照；**禁止**沿用任何历史轮次记录的数值作为本次输入；
4. **禁止**用任何候选身份（含 `mixed-local@8`）的实测离散度替换该解析上界——`-v10` 的离散度读数**只能**作为**描述性现象**引用（`docs/phase6/57m` §4.2、`58n` §4.2 / §5.1）。

## 5. 分层与主判层

### 5.1 维度角色表（每一项必须显式归类，不得留白）

| 维度 | 取值 | 角色（本草案的建议，须在冻结时确认） |
|---|---|---|
| 人数 | 2–9（逐人数各自成格） | **主判**（逐人数**独立**判定，禁止跨人数归因） |
| 起始深度 | 短码 / 标准 / 深码 | **次判**（每档必报；不阻断） |
| 街道 | 翻前 / 翻牌 / 转牌 / 河牌 | **次判**（每档必报；不阻断） |
| 风格 / 人格 | 已注册的风格集合 | **次判**（每档必报；不阻断） |
| 座位 / 位置 | 按钮位与相对位置 | **次判** |
| 对手族（探针族） | 已冻结探针池成员 | **诊断**（§7；不得作为强度判定输入） |
| 牌力档 / 尺度档 | 既有分桶口径 | **诊断**（**口径唯一化之前**不得作为判定输入） |

**硬约束**：

1. **禁止**以**未说明的跨维度最差值**（例如「逐人数取最差族」式的极值统计）替代产品结论；
2. 次判失败**必须**完整报告，**不阻断**；**不得**因次判失败改写主判结论，**也不得**因次判成功掩盖主判失败；
3. 主判层的合并方式**必须**在冻结时以**显式清单**给出（§5.2）。

### 5.2 主判格子必须在运行前固定

- 主判格子以**显式枚举清单**形式写入冻结文本（不得只写「笛卡尔积」这类生成规则而不落清单）；
- 清单一旦冻结，**不得**增删、不得合并、不得改名、不得改权重；
- 清单中的每个格子**必须**同时登记：`N_g`、`S_g`、`K_g`、块数、以及 §9 解出的**最小有效样本**。

### 5.3 样本不足的处置（**无歧义**）

| 情形 | 处置 |
|---|---|
| 某主判格子有效样本低于其登记下限 | **整体状态 = 不可判定**（§10）；该格子**同时**以诊断形式报告，**但**整体**不得**给出「满足」 |
| 事后发现格子划分有误 | 只能**重开根编号战役并重新预注册**；**禁止**在本次战役内修改格子后重判 |
| 运行中途发现某格样本不足 | **不得**延长运行去补足该格（§9.4 的停止条件优先）；状态按本表首行处理 |

⇒ **禁止**「事后把主判格降为诊断，再给出通过结论」。这一条是本框架对旧形态的主要修正之一。

## 6. 基线池

### 6.1 与探针池的**分离**（硬约束）

- **基线池** = 用于**强度比较**的基线，其成员是**策略**（含版本）；
- **探针池** = 用于**对手条件检查**的探针族（§7），其成员是**对手条件**，**不是**策略基线；
- 两者**必须**分节登记、**各自**独立版本化；
- **禁止**把机械探针族的收益读入强度判定；**禁止**把探针命中率解释为强度改善 / 恶化；
- 若某成员**同时**想充当两者，必须在冻结文本中**显式双重登记**并说明其配对与聚合方式；默认**不允许**。

### 6.2 基线池成员与版本

冻结文本**必须**含一张表，逐成员登记：

| 字段 | 要求 |
|---|---|
| 成员标识 | 策略标识 + **版本 / 摘要**（如配置摘要） |
| 冻结来源 | 该成员的代码 / 配置在冻结时点的标识 |
| 角色 | 迁移基线 / 固定基线（见下） |
| 配对方式 | 与 §4.1 一致；不得对个别成员另设配对 |
| 权重 | 在 §6.3 的聚合规则中显式给出 |

**成员准入条件**：

1. **已冻结且可确定性重放**（同一输入必得同一结果）；
2. **不依赖在线外部服务**；
3. 一经冻结，**不得**按任何读数增删、替换或升版。

**`heuristic@1` 的角色**：

- 作为**迁移基线**（保证与既有轮次的对话）保留；
- **明文声明**：`heuristic@1` **不是**真实强度上界、**不是**教学正确性基准、**不是**「可接受强度」的定义者；
- 「优于 `heuristic@1`」**不得**被表述为强度已获证明。

**是否引入辅助基线**：**需要**（理由：单一基线不足以界定「可接受劣势」，且单一旧策略易被误读为上界）。辅助基线的**具体成员**属冻结清单内容，**须在冻结时裁定并登记**；本草案**不指定**成员，只定准入条件。

### 6.3 配对与聚合规则

1. **逐一成员配对**：对每个基线成员 `b` 独立计算 `Δ(g, b)`；
2. **主判聚合 = 对基线池取最不利成员**：

```text
Δ_main(g) = min over b ∈ 基线池 of Δ(g, b)      （区间下界亦取对应最不利成员）
```

3. 该规则**必须在冻结时写定**；**不得**事后改为均值、最大值或按结果挑选成员；
4. 报告时**必须**并列全部成员的分量（不得只报聚合值）；
5. 基线池**规模受限**时须在局限中声明其覆盖不足。

### 6.4 防掩盖规则（较弱成员不得掩盖相对劣势）

- 由于主判取**最不利成员**，较弱成员**不可能**用于提高通过概率；
- **禁止**任何形式的「按成员加权平均后通过」作为主判；
- 若某成员被判定为**退化或不可用**（例如无法确定性重放），处置只能是：**在冻结前**将其移出池并重算样本量；**冻结后**发现 ⇒ 状态按 §10 记为**不可判定**，**禁止**临时移除后重判。

## 7. 探针池（独立小节）

### 7.1 成员与冻结

- 探针池成员、版本与比较口径**必须在冻结时登记**；
- 一经冻结，**不得**按读数增删、重定义或替换（含「探针重叠导致伪独立」的处理方式）；
- 探针池的作用**仅**在于：在**已声明**的对手条件下，检查被测身份是否出现**新的**可利用信号。

### 7.2 结论边界（强约束）

- 结论**只能**表述为「**本次样本集与本次探针池下未观察到 X**」；
- **不得**表述为「不可剥削」，**不得**作为 exploitability / NashConv / best response 上界；
- **不得**把探针命中率上升 / 下降包装为强度改善 / 恶化；
- **不得**把探针池的有限性说成「已覆盖」。

## 8. 双口径的角色（不得重建旧式一票否决）

### 8.1 两口径的估计对象是否同一？

| 口径 | 估计对象 |
|---|---|
| **区间口径** | **块均值的下界**（`Δ_main(g)` 的区间下界） |
| **块极值口径** | **块级极值**（单块最差均值）——这是**另一个估计对象**（分布的下尾，而非均值） |

⇒ 二者**不同一**：区间口径估计**均值**，块极值口径估计**极值**。因此若两者**都**作阻断条件，等价于对同一数据施加**两个**未联合预声明的否决点，**会重建旧式一票否决**。

### 8.2 裁定建议（**须在冻结时确认**）

| 项 | 建议角色 |
|---|---|
| **区间口径** | **主判**（阻断） |
| **块极值口径** | **停止护栏 + 风险报告**：触发即**暂停并要求调查**，但**不**作为「满足 / 未满足」的判据 |

理由：极值口径在块数有限、单片段方差大的情形下**几乎必然**为负尾部，把它作阻断会把「通过」变成不可达；把它作护栏则保留其作为**风险信号**的价值。

### 8.3 若坚持「双阻断」

则**必须**在冻结前补齐：**(a)** 证明两者针对**同一估计对象**（或给出联合估计对象的显式定义）；**(b)** 给出**联合**的预声明功效与多重比较处置；**(c)** 说明其**解释价值**（读者如何从「两个都过」推出结论）。**缺任一项 ⇒ 不得双阻断。**

## 9. 功效与样本规模

### 9.1 输入清单（四项，来源必须独立于候选身份）

| 输入 | 来源 | 状态 |
|---|---|---|
| **方差上界** `σ(g)` | §4.4 的引擎解析界（引擎与清单常量） | 公式已定；常量快照待冻结时记录 |
| **最小可检测效应 MDE** `δ` | **= 风险预算**（同一对象） | 【待用户产品裁定】，见 §9.2 |
| **块数** `B_g` | 样本集设计（种子结构，清单层） | 由清单决定，待冻结时登记 |
| **片段手数** `K_g` | §3.2 冻结节拍 | 【待冻结时固定】 |

**禁止**：以上四项中的任一项**不得**用任何候选身份的实测读数赋值或校核。

### 9.2 风险预算（唯一需要产品裁定的输入）

- **来源**：**用户的产品风险裁定**——这是本框架唯一被允许的风险预算来源；
- 必须在冻结文本中注明其**性质**：它是**产品风险决策**，**不是**教学标准、**不是** GTO 基准、**不是**强度上界；
- **禁止**以任何候选身份读数反推该数值；
- **框架内同值**：`74` 战役及其后全部身份共用同一数值；
- **若无法给出**满足上述条件的数值 ⇒ 框架**不得冻结**，相应战役**不得开始运行**（与 `73a` §4.4 一致）。

### 9.3 样本量解算（先算后跑）

```text
以块为重抽样单元，逐主判格子 g 解算所需块数：
    B_g ≥ ceil( ( t_{1−α/2}(B_g−1) + z_{1−β} )² · σ(g)² / δ² )
    （迭代求解，因自由度依赖 B_g）
以及：每块所需片段数 = 使该块内片段级统计量达到预声明精度
⇒ 每主判格子的最小有效样本 = B_g × 每块片段数
```

- 参数 `α`、`β`（功效）**必须**在冻结时显式写定；
- 解算必须给出**中间量**（`σ(g)`、`δ`、`B_g`、总片段数、总手数、预计 `wall`），以便审查；
- **算不出就不冻结、不运行**；
- 若解算结果**超出**既有包络（`wall` / 峰值 RSS / 输出）⇒ **不得**自行扩容；只能**缩减规模并把缩减如实写入局限**，或**先单独裁定包络**。

### 9.4 停止条件（必须在冻结时写定）

必须包含：

1. **正常停止**：样本达到 §9.3 解算量即停；
2. **护栏停止**：块极值口径触发（§8.2）、块级离散度异常、截断率越界；
3. **成本停止**：触及 `wall` / 峰值 RSS / 输出任一上界；
4. **错误停止**：合法性、信息边界、摘要一致性、确定性重放任一失败；
5. **样本不足停止**：某主判格无法达到 §9.3 下限。

**禁止**事后延长、缩短或重跑样本以改变状态。

## 10. 状态机（结果状态固定为三类）

### 10.1 三类状态

| 状态 | 含义 |
|---|---|
| **满足** | 全部主判格子齐备**且**全部满足 |
| **未满足** | 至少一个主判格子齐备**且**未满足，或出现**硬失败**（见 §10.2） |
| **不可判定** | 证据不足或不完整：无法给出「满足」也**不能**记为「未满足」 |

### 10.2 触发映射（**必须预注册**）

| 触发 | 状态 | 理由 |
|---|---|---|
| 全部主判格子齐备且区间下界均达标 | **满足** | — |
| 任一主判格子齐备但区间下界未达 | **未满足** | 判定已有证据 |
| **硬失败**：合法性 / 信息边界 / 摘要一致性 / 确定性重放失败 | **未满足** | 属正确性缺陷，不是「缺证据」 |
| **主判格子样本不足**（§5.3） | **不可判定** | 缺证据 |
| **成本越界**（§9.4 第 3 条） | **不可判定**（标注原因 = 成本） | 缺证据；**不得**记为满足 |
| **运行错误**（构造 / 序列化 / 入口等非正确性错误） | **不可判定**（标注原因 = 错误） | 缺证据 |
| **护栏停止**（§9.4 第 2 条） | **不可判定**（标注原因 = 护栏） | 缺证据，但须把护栏读数作为风险报告并列 |
| 正常停止但仍有格子未达样本下限 | **不可判定** | 缺证据 |

**说明（须在冻结时确认）**：「硬失败 ⇒ 未满足」这一条把正确性缺陷与「缺证据」区分开；若用户要求改为「不可判定」，**必须在冻结前裁定**；**冻结后不得修改**。

### 10.3 状态与默认策略

- **只有**「满足」**且**用户完成质量签收，才可能改变默认策略；
- 「未满足」与「不可判定」**均保持** `heuristic@1`；
- 任一状态**均不得**被表述为「验证通过」「已达生产门槛」。

### 10.4 措辞约束

- 「满足」**只能**表述为「**本次独立验证下主判满足**」；**不得**表述为稳健达标、质量已证明或不可剥削；
- 「不可判定」**不得**被表述为「通过」或「接近通过」；
- 「未满足」**不得**被归因为口径问题、工程问题或门槛过严。
