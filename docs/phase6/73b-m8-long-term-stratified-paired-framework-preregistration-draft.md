### 2.3 归一化分母与截断 / 零 / 缺失处置（**可执行规则**）

即：**分母 = 片段手数 `K_f` × 该会话大盲 `BB_s`**；`BB_s` 在一个片段内**必须**唯一。

**判定单元的强制执行口径（第三次修订：术语与前提更正；上界 `M` 的前提，见 §4.4.1）**：

1. **每手 = 构成记录（新鲜起始牌局）**：每一手开始时，**两臂所有座位**一律重新初始化为同一 `S`（同深度、同盲注结构）；手内不补码、不追加投入；
2. **片段仍是不可再分的统计单元**（与 `73a` §2 的术语一致）：**片段内各手不得作为独立样本**；单手只是**记录单位**，不是统计单元；
3. 之所以强制「每手重置」：引擎在**手与手之间**会为筹码清零者补码，并保留其他玩家已累积的筹码 ⇒ 连续会话的总筹码**不等于** `N·S`。因此本框架**不采用**「多手连续会话」作为判定单元，**也不采用**会话筹码上界路线（该路线在本框架中**不开放**）；
4. **estimand 必须明示范围**：本框架估计的是「**固定深度、每手重新买入（起始筹码重置）的牌局表现**」；**不覆盖**连续会话中的筹码演化（补码累积、动态深度、破产重置路径）；结论**不得**外推为连续会话表现；
5. **未来实现前置（本轮不实施）**：该「每手重置」条件**必须**由**测试夹具或运行器**落实（每手为两臂设定同一 `S` 的起始筹码，且不引入跨手筹码累积）；在整改落实并记录之前，**不得**据本框架运行任何判定。本轮**不**改任何现存夹具、**不**新增夹具；
6. 本节表格中的「会话」指该片段所在的连续对局段；每个片段内 `BB_s` **必须**唯一。升盲处按**预先声明**的盲注结构边界切分（边界与对局序号一一对应、在冻结时写定），**不得**依读数事后切分。

| 情形 | 处置 |
|---|---|
| 盲注结构在会话内可变（升盲） | **必须**按升盲边界切分片段，使每个片段内 `BB_s` 唯一 |
| 同一片段内出现两个不同 `BB_s` | 该片段**作废**，计入作废率 |
| `K_f = 0`（空片段） | 片段**作废**，计入作废率 |
| 某一手在一侧**配对不完整** | 该片段**整体作废**（**禁止**逐手丢弃，避免选择偏差） |
| `d_h = 0` | **有效观测**（同一结果）；**不得**剔除，**不得**不计入样本 |
| `BB_s ≤ 0` 或缺失 | 该**会话整体作废**；**禁止**用默认值兜底 |
| 会话级作废的对称性 | **必须两侧同时作废**（同一会话在两侧一并剔除）；**禁止**单侧剔除，否则破坏 §3.3 的对称性核验口径 |
| 截断手（达到动作上限的手） | **保留在片段内并照实计入**；**不得**剔除截断片段；**必须**分别报告截断率 |
| 截断率超过预注册上限 | 触发停止（§9.5），并按 §10 定状态 |

**禁止**：按片段内**实际投入**、**实际底池**或**实际大盲参与量**动态构造分母——那会把策略行为写进分母，破坏外生性。分母**只**由 `K_f` 与 `BB_s` 决定。

**作废率**：作废片段数与作废会话数的**上限**必须在冻结时预注册；超过上限 ⇒ 触发停止（§9.5）。

## 3. 片段定义（外生且对称）

### 3.1 入选规则（唯一依据）

一个对局进入某个片段，**只**允许由下列条件决定：**(a)** 对局序号；**(b)** 公共条件（人数、起始深度、按钮起始位、盲注结构）；**(c)** 配对条件（§3.3）。

### 3.2 起止与切分规则（与策略无关）

- 片段按**预注册的序号边界**切分（每 `K` 连续对局为一个片段，`K` 在冻结时固定；或按固定序号列表切分）；
- `K` **不得**依赖任何动作、收益、行动线或事件的发生；
- 片段起止**不得**因「某条行动线是否发生」而被延长、截断或跳过；
- **禁止**用「焦点是否进入某分支 / 是否出现某动作 / 是否发生某事件」作为入选或切分条件。

### 3.3 对称性核验（运行前完成，硬门）

1. **片段划分必须是身份的纯函数**：给定（清单、种子、片段规则），片段集合唯一；
2. 核验方式（**只读**）：对同一（人数 × 深度 × 起始按钮位）构造两侧序列，逐片段比对**成员对局序号集合**是否逐项相等；
3. 任一侧不相等 ⇒ **框架不得冻结**。

### 3.4 禁止项汇总

| 禁止 | 原因 |
|---|---|
| 依赖被测或基线的动作 / 收益决定入选或切分 | 对称性破坏 ⇒ 自证 |
| 以「是否进入某行动线」切分 | 把结果条件写进样本定义 |
| 以「是否发生某事件」事后调整片段边界 | 事后选样本 |
| 让片段长度随人数 / 风格变化而不预先声明 | 不可审查的隐含分层 |

## 4. 配对、块与方差依据

### 4.1 配对规则

- 配对**必须**满足：同牌堆派生流、同位置、同起始深度；
- **禁止**把新动作接到旧历史后缀上算反事实 EV；**禁止**用不同牌堆的样本拼出「改善」。

### 4.2 块的定义与来源

- **块 = 最小的重抽样单元**，成员来自同一随机源（同一牌堆派生流）；
- **块数由功效计算先确定**（§9.3 解出每格 `B_g`），再由**全新清单**提供**不少于**该数量的**预注册块**；块与种子的对应关系属**清单层**，与身份无关；
- **禁止**按读数增删、合并块或改变块与种子的对应关系；**禁止**「先固定少量种子、事后延长或增补块」的路径；
- 块的**独立性依据**必须由**种子抽样机制**构造性地给出（§4.4.3），**不得**仅以「来自不同种子」作为依据；该依据是**结构性声明**，其可执行核验见 §4.4.3。**同分布**只在主张「共同总体期望」时才需要（§4.4.2 R1 的目标量条目）；主张「固定设计平均」时**不要求**同分布。

### 4.3 区间与聚类

- 任何区间**必须**在**块层**构造（块级重抽样或等价的聚类稳健方法）；
- **必须并列报告**：点估计、区间、块级离散度、块极值、逐主判格子分解；
- **禁止**只报合并均值；**禁止**用合并均值代替逐格子结论。

### 4.4 方差依据（第一次修订更正；第二、三次修订补前提与推断方法）

#### 4.4.1 上界 `M` 及其**强制执行的前提**（第二次修订；第三次修订校正术语）

```text
前提（§2.3 的判定单元口径）：每手 = 新鲜起始牌局（两臂全员重置为同一 S、手内不补码）
                            片段 = 不可再分的统计单元（片段内各手不作为独立样本）
⇒ 每手总筹码 = N · S
单手配对差上界：     |d_h| ≤ D_max := 2 · (N − 1) · S          （两侧各自净额上界）
片段级统计量：       Δ_f = ( Σ_{h ∈ f} d_h ) · 100 / ( K_f · BB_s )
⇒ 上界：             |Δ_f| ≤ M := 2 · (N − 1) · S · 100 / BB_s        （与 K_f 无关）
⇒ 取值域（R1 用）：  Δ_f ∈ [ −M, M ]
```

**前提是硬性的**：上式**不来自引擎的默认行为**，而来自 §2.3 强制执行的测量口径。引擎会跨手保留已累积筹码并为筹码清零者补码，连续会话的总筹码**不等于** `N·S`。因此：

1. 满足 §2.3 第 1–5 条 ⇒ 上式成立，`M` 与取值域 `[−M, M]` 可用于 R1（§4.4.2）；
2. **不满足**（多手连续会话、或手内筹码不等）⇒ 上式**不成立**：该数据**不得**进入判定；**禁止**用运行后观测到的峰值在场筹码回填；
3. **禁止**把「上界很大但也许够用」当作可行性依据——R1 的可行性必须由 §9.3 / §9.4 的算术证实；算不出、或解出的 `B_g` 超出清单可提供的预注册块数 ⇒ **不得采用**。

**另外两条结论保持不变**：

- `K_f` 在分子（最坏损失随 `K` 线性累加）与分母（归一化随 `K` 线性累加）中**相消**：把多手聚合成片段**不会**自动带来任何最坏情形缩减，`M` **与 `K_f` 无关**；
- 「`σ ∝ 1/K`」**不成立**（初版错误即在此）；`1/√K` **不是**一般式，只在足够强的独立同分布条件下成立，一般情形必须使用 §4.4.2 的有限样本方差形式。

**共同的禁止项**：**禁止**用任何候选身份（含 `mixed-local@8`）的实测离散度替换方差或上界输入；`-v10` 的离散度读数**只能**作为**描述性现象**引用（`docs/phase6/57m` §4.2、`58n` §4.2 / §5.1）。

#### 4.4.2 主判候选路线（**冻结时在 R1 / R2 之间择一写定**）

**共同的抽样假设（第三次修订新增；R1 与 R2 都必须声明并写入冻结文本）**：块级统计量之间**相互独立**。该独立性是**结构性假设**，**不是**可由「块来自不同种子」「块数足够多」或任何事后核验**证明**的性质；其依据必须由**种子抽样机制**构造性给出（§4.4.3）。核验只能**发现部分违例**，不能验证独立。

| 路线 | 推断方法 | 所需假设 | 依赖候选读数 | 主要风险 |
|---|---|---|---|---|
| **R1 有界变量的有限样本单侧界** | **分布无关**的有限样本界：**Hoeffding**（**唯一变体**；「经验 Bernstein」已在第四次修订中删除） | 块间独立 + 权重**非负且和为 1** + 块级统计量落在 `[−M, M]` | 否 | 可行性**未知**（`M` 可能极大）：**不得预判不可行**，须在合法 `m` / `α′` / `M` 确定后由**预注册算术**回答 |
| **R2 有限样本协方差和 + Cantelli 下界** | 一般协方差形式（或经**独立论证**的平稳性自协方差形式）⇒ **逐块**方差上界 `V_j` ⇒ 均值方差上界 `V̄_B` ⇒ **Cantelli 单侧不等式**给出有限样本下界；**解算块数**用与 seed 无关的块模板统一上界 `V_max`（§4.4.2 (vi)） | 块间独立 + **逐块 `V_j`**（以及由它得到的 `V̄_B`）的**独立**推导（**必须含片段间协方差处置**）+ **与 seed 无关的 `V_max`**（建清单前可得，禁止用未来清单的量解 `B`） | 否 | 若片段间协方差只能取 `\|Cov\| ≤ M²`，则逐块 `V_j ≤ M²`（保守统一时 `V_1 ≤ M²`）⇒ **退化到不优于 R1**，必须如实报告该退化 |

**R1 的形式化（第五次修订：只保留一套统一解算式）**：

```text
块级统计量：  X_j = Σ_f w_{jf} · Δ_f ，其中权重 w_{jf} ≥ 0 且 Σ_f w_{jf} = 1（**冻结时预注册**）
              权重非负、和为 1 与 |Δ_f| ≤ M（§4.4.1）共同保证 X_j ∈ [ −M, M ]
目标量（第七次修订：**只能**用固定设计平均记号）：
              μ̄_B := ( 1 / B ) · Σ_{j=1..B} E[ X_j ]   （各块期望不同时**不得**写 μ = E[X_j]）
块间独立 ⇒ 单侧 Hoeffding（分布无关，不需要正态 / 方差模型）
              （域 C 语境：逐项水平一律记作 α_C′ / β_C′，N_cmp = G × M）：
              P( μ̄_B ≥ X̄_B − M · √( 2 · ln(1/α_C′) / B ) ) ≥ 1 − α_C′
判定：        L := X̄_B − M · √( 2 · ln(1/α_C′) / B ) ≥ δ_budget  ⇒ 该格满足
解算（**唯一采用**；取值域宽度 R、预注册裕度规则 hw ≤ m/2）：
              B ≥ 2 · R² · max{ ln(1/α_C′) , ln(1/β_C′) } / m²
              R1 代入 R = 2M ⇒ B_g ≥ 8 · M² · max{ ln(1/α_C′) , ln(1/β_C′) } / m²
              （`M` 只依赖 `N` / `S` / `BB_s`，与 seed 及清单块无关 ⇒ 上式**可直接解算**）
```

- **只有一套系数（第五次修订修正；第八次修订统一记号）**：半宽 `hw := M·√( 2·ln(1/α_C′)/B ) ≤ m/2` 单独推出 `B ≥ 8·M²·ln(1/α_C′)/m²`，它是上式在 `ln(1/β_C′) ≤ ln(1/α_C′)` 时的**特例**；前一稿另列的 `2·M²·ln(1/α′)/m²` **系数错误（差 4 倍）**，**已删除**，不得再出现；

- **目标量（estimand）必须写明是哪一种（第七次修订：记号写死）**：主判目标量一律写 **`μ̄_B := (1/B)·Σ_{j=1..B} E[X_j]`**。各块期望**不完全相同**时**不得**写成 `μ = E[X_j]`（那会暗示共同总体均值），也**不得**把 `μ̄_B` 表述为「共同总体期望」；只有**额外预注册同分布 / 代表性抽样条件**时，才可简写为共同总体均值 `μ`，并须同时声明该条件的依据；
- **权重纪律**：权重必须**非负、和为 1**，且在冻结时预注册；**禁止**事后按读数挑选权重；
- **变体已删除（第四次修订）**：前一稿的「经验 Bernstein 变体」表述**不准确**（经验 Bernstein 需要样本方差与特定的独立 / 同分布条件，**不等价于**「已有独立方差上界」），故**删除**；若将来要引入，必须指明**唯一**采用的定理、假设与常数，并另开修订送审；
- **不得预判不可行**：R1 是否可行只能在 `m`、`α′`、`M` 依法确定后由**冻结时的预注册算术**回答；在此之前**不得**预判其不可行，**也不得**为此运行任何试探性运行；
- **必须**给出该算术并按 §9.4 第 6 条检查「解出的 `B_g` ≤ 清单预注册块数」；**禁止**把「以 `σ = M` 代入块层 t 型区间」当作 R1（它既非分布无关，也不给有限样本保证）。

**R2 的形式化（第五次修订：更正上界记号、各块不同上界与目标量口径）**：

```text
(i) 方差的一般形式（**不得**默认平稳）：
      Var( Σ_{h ∈ f} d_h ) = Σ_{r ∈ f} Σ_{s ∈ f} Cov( d_r , d_s )
      若采用自协方差写法 Σ_{|ℓ| ≤ K−1}(K − |ℓ|)·γ_ℓ ，**必须**在冻结时预注册并
      **独立论证二阶平稳性**（Cov 只依赖滞后）；未论证 ⇒ **不得**使用该写法。

(ii) 逐块方差上界（**必须显式含片段间协方差**）：
      块级统计量 X_j = Σ_f w_{jf}·Δ_f ，w_{jf} ≥ 0、Σ_f w_{jf} = 1（预注册）
      Var( X_j ) = Σ_{f, f'} w_{jf} w_{jf'} Cov( Δ_f , Δ_{f'} ) ≤ V_j    （**逐块**上界，允许不同）
      推导二选一（冻结时写死）：
        (a) 同块内片段相互独立（**须预注册并给出依据**）：
            V_j = Σ_f w_{jf}² · U_{K_f} · 100² / ( BB_s² · K_f² ) ，U_{K_f} ≥ Var( Σ_{h∈f} d_h )
        (b) 不假设片段独立：必须给出 Σ_{f ≠ f'} w w' |Cov| 的**独立**上界；
            若只能取 |Cov| ≤ M²，则 V_j ≤ M² ⇒ R2 **退化到不优于 R1**，必须如实报告。
      统一记号：**仅当写明为保守统一时**才可用 V_1 := max_j V_j（于是对全部 j 有 V_j ≤ V_1）。

(iii) 均值方差的上界（**是上界，不是等式**）：
      块间独立 ⇒ Var( X̄_B ) ≤ V̄_B ，其中
        · 统一上界：  V̄_B := V_1 / B            （因 Var(X̄_B) = (1/B²)·Σ_j Var(X_j) ≤ V_1 / B）
        · 各块不同：  V̄_B := ( 1 / B² ) · Σ_j V_j
      **不得**写成「V_B = V_1 / B」；必须写成方向明确的**上界**。

(iv) 有限样本置信下界（**唯一采用 Cantelli 单侧不等式**；分布无关，只依赖均值与方差上界）：
      （本节属**域 C** 语境，逐项水平一律记作 α_C′ / β_C′，N_cmp = G × M）
      L = X̄_B − √V̄_B · √( (1 − α_C′) / α_C′ )
      覆盖保证：P( L ≤ μ̄_B ) ≥ 1 − α_C′
      界宽：    hw := √V̄_B · √( (1 − α_C′) / α_C′ )

(v) 功效（**设计备择在满足侧**，m = δ_alt − δ_budget > 0）：
      当 hw ≤ m / 2 时  P( L ≥ δ_budget | μ̄_B = δ_alt ) ≥ 1 − V̄_B / ( V̄_B + (m/2)² ) ≥ 1 − β_C′
        ⇔  V̄_B ≤ ( m² / 4 ) · β_C′ / ( 1 − β_C′ )

(vi) 样本量（块间独立时；由 (iii) 的 V̄_B 与 (v) 的功率要求联立解出，
      等价于 V̄_B ≤ (m²/4) · min{ α_C′/(1−α_C′) , β_C′/(1−β_C′) }）：
      **唯一允许的解算路径（第七次修订：消除与未来清单的循环依赖；
      第八次修订：收紧 V_max 的独立性与来源）**——
      必须**在建清单之前**冻结**块模板**及其**统一上界** V_max。
      V_max **必须同时**满足三条（缺一即不得用于解算 B）：
        (a) **与具体 seed 无关**（不含任何依赖未来清单块或未来 seed 的项）；
        (b) **独立于任何候选身份读数**——**禁止**用非候选策略或其它身份的经验
            方差、离散度读数主张它同样上界被测身份；
        (c) **由冻结的块模板、取值域与解析协方差界推出**（模板化的 U_{K_f}、
```

**α / β 的统计层级（第五次修订新增；R1 / R2 与域 A / 域 B 共用）**

主判是 **AND 语义**（每个主判格 / 情境 / 分域 / 锚点都必须满足），因此**逐项**的 `α` 与 `β` **都不等于**域级水平。必须按下式**预注册**：

```text
N_cmp := 该域内必须同时满足的**比较数**
         · 域 C：N_cmp = G × M                    （G = 主判格数，M = |基线池|）
         · 域 A：N_cmp = （情境数）× （有向人格对数）
         · 域 B：N_cmp = （分域数）× （2 + |A_B|）

               （A_B = **主判指名锚点集合**；金额条件熵为必报非阻断量，**不进入** N_cmp；
                其分区 P_B 含 other 桶，**不参与**主判与 N_cmp；见 §5.5）
逐项水平：α′ := α / N_cmp      （并集界 ⇒ 全部分析同时成立的概率 ≥ 1 − α）
逐项功效：β′ := β / N_cmp      （并集界 ⇒ 全部比较同时判定的概率 ≥ 1 − β）
分配路径（第七次修订：命名与路径唯一，域 C 与 §6.3 必须一致）：
  域 C：先按格分配 α_g := α_C / G ，再在成员间 α_C′ := α_g / M = α_C / ( G · M )
        同理 β_g := β_C / G ，β_C′ := β_g / M = β_C / ( G · M )
        域 C 的**比较集合** = { (格 g, 成员 b) }，共 G · M 个
```

- **域 C 的分配路径（第七次修订）**：本节写定的 `α_C′ = α_C / (G · M)` 与 §6.3 的逐成员校正**必须**使用**同一命名与同一比较集合**（先按格、再按成员；等价于 `α_g := α_C / G` 之后 `α_C′ = α_g / M`）；`β_C′` 使用**完全相同**的分配路径与比较集合；**不得**在 §6.3 单独出现 `α′ = α / M` 而缺少 `α_g := α_C / G` 的定义；
- **样本量式一律使用逐项水平**（域 C 记作 `α_C′` / `β_C′`；域 A / 域 B 记作 `α_A′` / `β_A′` 与 `α_B′` / `β_B′`）；**不得**在逐项公式里直接用对应的域级 `α` / `β`，**也不得**在同一公式里混用 `α′` 与 `β_C′` 这类不一致记号（第八次修订）；
- **域级功效的表述**只能写作「**全部比较同时成立**」的概率 ≥ `1 − β`；**不得**把逐项 `1 − β` 说成总体 / 域级功效；
- **联合备择向量（第六次修订新增）**：上述「域级功效 ≥ `1 − β`」**只在全部比较同时达到各自预注册设计备择**时成立。因此冻结文本**必须**预注册该域的**联合备择向量**——逐比较列出其设计备择取值（域 C 的逐格 `δ_alt(g, b)`、域 A 的逐情境 `Δ_alt`、域 B 的逐分域 `Δ_Ω` / `Δ_act` / `Δ_π`）；**不得**只写一个「代表备择」而声称域级功效；
- **跨域总体功效的边界（第六次修订新增）**：若结论要宣称「A / B / C 三域**同时**满足」具有 `1 − β` 功效，**必须**另行预注册**跨域 `β` 分配**（各域 `β_A` / `β_B` / `β_C` 之和 ≤ `β`，或等价的联合构造）并写入冻结文本；未预注册 ⇒ **只能**分别声明各域功效，**不得**出现「总体功效 `1 − β`」或任何等价的跨域功效表述；

**备选设计（第三次修订：**不作为主判候选**）：R3 块层比例型判据**

R3 改变的是**强度风险的估计对象**（由 §2.2 / `73a` §4 的「长期配对劣势」改为「越界块概率」），属**框架级**变更，**不能**由本文件自行宣布取代。因此：

2. 若未来要把 R3 升为主判，**必须先取得一次单独的框架级路线裁定**，并在**新的根编号战役**中重新预注册与重新冻结；届时本框架的冻结文本作废；
3. 若该裁定通过，R3 的**假设方向与临界规则必须按下式写死**（方向不可含糊）：

```text

坏事件：        E_j = 1[ X_j < δ_budget ]      （δ_budget 为产品风险预算，负值）
观测越界数：    X = Σ_j E_j                     （X 越小越好：这是「劣化」的方向）
零假设/备择：   H0: p ≥ p0   对   H1: p < p0    （p 为越界概率，p0 为允许上限）
拒绝规则：      H0 在水平 α′ 下被拒绝 ⇔ X ≤ c_crit
                其中 c_crit := max{ k : P_{p0}( X ≤ k ) ≤ α′ }   （**允许的最大越界数**）
等价判定：      单侧上置信界 U_{1−α′}(X) ≤ p0  ⇔  X ≤ c_crit  ⇒  该格「满足」
设计备择：      p1 < p0（更小的越界概率才是要检出的改善）
功效：          P_{p1}( X ≤ c_crit ) ≥ 1 − β

                （**仅作初估**；`c_crit` 与功效必须用**精确二项分布**计算，§9.3）
```

4. **硬性禁止**：**不得**以「未能拒绝 `H0: p ≥ p0`」或「`p̂ ≤ p0`」判「满足」——那会把「**未拒绝劣化**」误作满足；必须使用**单侧上置信界 / 精确非劣检验**（即 `X ≤ c_crit`）；
5. `c_crit` 与功效**必须用精确二项分布计算**；正态近似公式只可作初始规模估算，并须声明其失效边界；
6. `p0`（**产品风险参数**）与 `p1`（**设计备择比例**，`p1 < p0`）的性质与来源，必须在授权 R3 的那次**独立裁定**中登记（§9.2）；
7. **并列报告**：连续幅度 `Δ̂(g,b)` 与其块级聚类区间（若报告）**只能**作为非阻断报告，其区间宽度**不**作任何功效承诺；

| **方向必须预注册** | 方向（哪个人格在该情境应更激进 / 更保守）**必须在冻结时写死**；有产品含义时**必须**使用**有向差**，**不得**改用绝对值；**禁止**读数后选择方向 |
| **唯一判定方法与界** | **有界变量有限样本单侧 Hoeffding**（唯一方法）：`L := Π̂_s − R·√( ln(1/α_A′) / (2·B_s) )`，`R = 2`（有向概率差的取值域宽度）；**满足** ⇔ `L ≥ π_A = 0.15`（预注册最低可感知有向差，即 15 个百分点，产品参数）。`L` 的覆盖对象是**固定设计平均** `μ̄_{s,B} := (1/B_s)·Σ_{j=1..B_s} E[Π_{s,j}]`（期望对 §5.7 的 `σ_j` 生成分布取），**不得**写成共同总体均值。**其它方法（精确区间、置换检验等）本框架不采用**；将来若要引入，必须**先指明唯一构造**并另开修订送审 |
| **样本量与功效（本域自有）** | 通用式（§4.4.2 R1）代入 `R = 2` 与**逐项功效预算**：`B_A ≥ 8 · max{ ln(1/α_A′) , ln(1/β_A′) } / Δ_alt²`，其中 `Π_alt = 0.30`、`π_A = 0.15`、`Δ_alt := Π_alt − π_A = 0.15`（设计备择裕度）；`α_A′` / `β_A′` 依本行下列统计层级（`N_cmp,A = 情境数 × 有向人格对数`）。**禁止**套用域 C 的 `M` / `B_g` / R1·R2 的代入值 |
| **多重比较与聚合** | **AND 规则**：全部情境 × 全部有向人格对都必须满足；`α_A = 0.05`、`β_A = 0.20`、`α_A′ = α_A / N_cmp,A`、**`β_A′ = β_A / N_cmp,A`**。域 A 的目标功效为 `1−β_A = 0.80`，只在全部比较同时达到各自设计备择时成立；**禁止**跨情境加权平均得出结论，**不得**把逐项 `1 − β_A′` 说成域级功效，也不得声明与 B / C 的跨域总体功效 |
| **零分母与缺失** | `D_{s,j} = 0` 只可能源于**清单设计**（该块内无合格的外生节点），**不是**策略依赖：冻结时**必须**保证每块 ≥ 登记的**每块最小节点数**，否则**清单不合规、不得冻结**；运行中出现 `D_{s,j} = 0` 或节点查询失败 ⇒ 该块**整块作废（双侧同时）**并计入作废率；作废率超预注册上限、或**有效块数**低于登记下限 ⇒ 停止（§9.5）并按 §10 记该情境**不可判定**；**结构性恒等条目**（数学上不可能出现差异的节点）**照实计入分母并单列**（它们不是缺失） |
| **阈值来源** | `π_A` 必须**独立于任何候选身份读数**；**不得**以沿用任何历史文档的取值作为依据——历史文档在本框架中**只能**作术语与问题域的承接 |
| **状态映射** | 本域按 §10.1 取 `{满足, 未满足, 不可判定}`；任一字段的**方法**未定或缺失 ⇒ 冻结文本不成立（§11.1）；被测身份**不具备** §5.6 的分布观测能力 ⇒ 本域 **不可判定**，**不得**退回「按采样动作临时补算」 |

**A 的样本量记账（三项分开，第五次修订）**：**独立统计样本量 = 有效块数**；**每块最小节点数**（设计约束）；**总节点数**（成本量）。三者**分别登记**，**不得**相乘后称「最小有效样本」（§5.2）。

### 5.5 域 B：行为不可预测性（主判）规格（第五次修订：外生分母与「概率质量」读取；第六次修订：节点级分布熵、直接概率质量估计量并恢复金额条件熵）

**方法已收敛为唯一一种；已授权数值如下**：`ω_B = 0.50 bit`、`ω_alt = 0.80 bit`、`Δ_Ω = 0.30 bit`；`π_min^{act} = 0.20`、`π_act^{alt} = 0.35`、`Δ_act = 0.15`；`π_min = 0.05`、`π_alt = 0.10`、`Δ_π = 0.05`；`α_B = 0.05`、`β_B = 0.20`。这些是用户的产品 / 设计裁定，不来自任何候选读数；分域、`A_B`、`P_B` 与具体清单仍未确定，且本域**尚不可冻结或运行**。

**本域必须同时覆盖四类量（第六次修订）**：**(1)** 节点级动作分布熵（**主判**）；**(2)** 主动动作概率（**主判**）；**(3)** 各指名额度锚点比例（**主判**）；**(4)** **金额条件熵**（**必报非阻断**，`73a` §3.2 要求）。前三类进入 `N_cmp`（见下表「多重比较与聚合」），第 4 类**不进入**。

### 5.7 域 A / 域 B 的外生节点抽样总体与独立块生成协议（第七次修订新增）

**为什么必须有本节**：域 A / 域 B 的概率质量在**给定节点上是确定值**，因此仅有一份「冻结的共同节点清单」**不会**自动产生置信区间或功效。Hoeffding / Cantelli 的随机性**必须**来自**外生的节点抽样**，且该抽样**必须**独立于被测身份。

**本节的地位（第十次修订）**：本节给出**唯一**的生成算法（**不是**待填字段模板）。算法形式已经确定；具体有限集合、层、配额、枚举上限、外生种子与清单仍属冻结项，**本轮不生成、不冻结**。

**一、外生节点总体 `𝒩`、可查询状态与规范枚举**

```text
节点 n = ( 人数 N ∈ N_set , 起始深度 S ∈ S_set , 盲注结构 BB ∈ BB_set ,
           按钮位 b ∈ {0, …, N−1} , 牌面 D ∈ D_set , 完整行动历史 H ∈ H_set )
```

- 座位标识固定为环形序 `0, …, N−1`；`b` 指明按钮位。`D` 必须逐座位登记底牌，并按发牌顺序登记公共牌；`H` 必须从发牌后的空历史起逐项记录 `(街道, 行动座位, 动作类别, 引擎整数金额)`，不得省略弃牌、全下、加注或街道推进。冻结时必须列出有限的 `N_set` / `S_set` / `BB_set` / `D_set` / `H_set`；
- 对每个六元组，唯一调用冻结 `code_identity` 对应的纯引擎转移函数 `Replay(N, S, BB, b, D, H)`：它从唯一的初始状态施加盲注，按座位环顺序确定行动者，并逐项重放 `H`。重放唯一恢复当前行动座位、各座当前投入与剩余筹码、当前最高投入、最小加注、已弃牌 / 全下状态、行动权与加注重开状态；重放失败即该六元组不合法；
- **空历史规则写死**：`H = ()` 仅表示翻前盲注已施加、尚无自愿行动的状态；首个行动者为大盲位之后第一个仍可行动的座位。其后街道的首个行动者由按钮位之后第一个仍可行动的座位确定，且只能由成功重放的完整 `H` 到达；
- 安全查询状态定义为 `SafeState(n)`：对 `Replay` 的当前状态保留行动者自身底牌、公开牌面、座位 / 投入 / 筹码 / 行动权信息，并移除其他座位底牌。合法动作集定义为 `Legal(n) := LegalActions(Replay(n))`。因此同一 `n` 唯一对应安全状态与合法动作集；
- 规范序固定为：`N`、`S`、`BB`、`b` 按数值升序；`D` 按冻结牌码字典逐位字典序；`H` 按上述四元动作编码逐项字典序。以上六元组依该字段序组成唯一全序；
- 先对六个有限集作笛卡尔枚举，再以**不读取策略输出**的 `Replay` 与 `Legal` 保留「重放成功且 `\|Legal(n)\| ≥ 2`」的六元组，所得有序集合即为 `𝒩`。这是一次确定性总体构造，不是抽样期的过滤或拒绝采样；
- `𝒩`、`Replay`、`SafeState` 与 `Legal` 不得含策略输出、候选读数或对局结果；其分布观测值仅由 §5.6 契约在 `SafeState(n)` 与 `Legal(n)` 上读取。

**二、层、候选序列与唯一映射 `Φ`**

- 冻结时穷举层集合 `L`、层优先序与每层静态成员谓词 `I_ℓ(n)`。`I_ℓ` 只能引用节点的外生字段、分域 / 情境标签与合法动作集；不得引用策略输出、分布观测、候选读数或结果；
- 对每层，按 `𝒩` 的规范序列出 `C_ℓ := (n ∈ 𝒩 : I_ℓ(n))`，记 `L_ℓ := \|C_ℓ\|`。`C_ℓ` 内元素唯一；冻结时必须验证 `L_ℓ > 0`；
- 第 `j` 块种子为偏移量向量 `σ_j := (o_{j,ℓ})_{ℓ∈L}`，其中每个 `o_{j,ℓ}` 独立均匀取自 `{0, …, L_ℓ−1}`。唯一映射定义为 `Φ(σ_j, ℓ, t) := C_ℓ[(o_{j,ℓ} + t) mod L_ℓ]`，其中 `0 ≤ t < L_ℓ`；
- 因此同一层在一个块内的候选序列是 `C_ℓ` 的循环移位，直到 `t = L_ℓ−1` 前**绝不重复**。`Φ` 只使用 `σ_j`、`ℓ`、`t` 与已冻结的规范序，且不读取任何策略或结果。

**三、唯一生成算法（固定配额、优先去重与补足；不采用拒绝采样）**

```text
冻结前验证：在步骤 1 的参数写定后，枚举偏移量空间 Σ := ×_{ℓ∈L}{0, …, L_ℓ−1}；对每个 σ ∈ Σ 执行步骤 2–3，
            必须证明每层均在 Θ_ℓ 内达到 n_ℓ。证明失败 ⇒ 该设计不可冻结，且不得生成任何 σ_j。
输入：第 j 块的外生偏移量向量 σ_j
1. 冻结时为每层写定整数配额 n_ℓ 与枚举上限 Θ_ℓ，满足 0 ≤ n_ℓ ≤ Θ_ℓ ≤ L_ℓ。
2. 按冻结的层优先序依次处理 ℓ；从 t = 0 至 Θ_ℓ−1 依序计算 Φ(σ_j, ℓ, t)。
3. 仅当该节点尚未被更高优先层接受时，将其接受至 S_{j,ℓ}；继续枚举直到
   \|S_{j,ℓ}\| = n_ℓ 或 t 达到 Θ_ℓ−1。较低优先层因重复而跳过后，必须继续同一
   固定序列以补足配额，不得重抽、换序或改配额。
4. 任一层未在 Θ_ℓ 内达到 n_ℓ ⇒ 该整份清单生成尝试失败；不得换 σ_j、补抽块、
   重生成整份清单或条件选择 seed。该失败只能使本次冻结尝试终止。
5. 全部层达标后，S_j := ∪_{ℓ∈L} S_{j,ℓ}；此时每个节点至多出现一次。
```

- 步骤 2–3 的跳过只处理**已知的层间重复**，不检查策略输出、分布观测或结果；它是固定有限序列上的去重，不是拒绝采样；
- 冻结前验证覆盖 `Σ` 的**全部**可能偏移量，因此一经通过，任一按既定均匀分布抽得的 `σ_j` 都应合格；若实际生成仍出现不合格块，整份清单生成尝试立即失败。后续如要改变层、配额、上限或映射，必须另开修订并重新送审，**不得**在本设计下换 seed 或重生成。
- **块内与块间的地位**：每块内按上述步骤无放回接受节点，块内节点不必独立，也不被当作独立样本；统计上只以块为独立单元（§5.2）。R1 用取值域 `[−M, M]` 的分布无关界；R2 的逐块 `V_j` 必须覆盖块内相关性与片段间协方差（§4.4.2 (ii)）。

**四、`σ_j` 的抽样分布与生成方式**

- 仅在「三」的全偏移量验证通过后，各 `σ_j` 才可独立同分布地一次性生成；同一 `σ_j` 内的各层偏移量亦相互独立，分布严格按「二」中的有限均匀分布；
- `σ_j` 由与身份无关的外部随机源在清单冻结时一次性生成并写入清单（**本轮不生成**）；不得与对局随机流、策略随机流或任何候选身份的派生路径共享来源。任何块不合格时，该整份清单生成尝试终止，**不得**替换任一 `σ_j` 或重生成整份清单；
- 块间独立由 `σ_j` 的独立生成构造性给出（§4.4.3）；核验仍只能发现部分违例，不能验证独立。

**五、配额的外生边界与确定性处置**

| 情形 | 确定性处置 |
|---|---|
| 层内候选 | `C_ℓ` 已在总体构造阶段满足进入条件；不得在生成期按策略或结果再过滤 |
| 层间重复 | 按层优先序保留高优先层节点；低优先层依固定 `Φ` 序列继续枚举以补足 |

| 是否可按结果反复生成 | 禁止：`S_j` 一经生成即落盘冻结，运行期只读；不得因任何分布、动作或结果重新生成 |

**六、其余确定项**

| 项 | 内容 |
|---|---|
| **目标量（必须二选一写死）** | **(a) 生成分布下的期望（本框架采用）**：`μ̄_B := (1/B)·Σ_{j=1..B} E[X_j]`，期望对 `σ_j` 的生成分布取；此时才允许使用 Hoeffding / Cantelli 的有限样本保证。**(b) 冻结有限清单的精确平均**：若目标只是对已冻结清单求平均，该平均是确定量，不得再用 Hoeffding / Cantelli 声称总体推断（只能作描述性报告，或重按 (a) 设计） |
| **样本量记账不受影响** | 独立统计样本量仍是有效块数；块内节点数只是设计约束，不得当独立观测数（§5.2） |
| **域 A 的具体化** | 域 A 的 `Π_{s,j}` 同样以 `σ_j` 为唯一随机性来源；情境 `s` 对应外生层，`S_{s,j} ⊆ S_j` 由层配额确定，不得按读数增减 |

**禁止**：把「给定节点后分布确定」与「块间抽样」混为一谈；用块内节点数冒充独立样本量；在未冻结本节已定义的总体、层、`σ_j`、`n_ℓ`、`Θ_ℓ` 与清单的具体取值时声称域 A / 域 B 的区间或功效成立；把具体枚举、数值或 seed 尚未冻结误写为算法尚未确定。

## 6. 基线池

### 6.1 与探针池的**分离**（硬约束）

- **基线池** = 用于**强度比较**的基线策略（含版本）；
- **探针池** = 用于**对手条件检查**的探针族（§7），成员是**对手条件**，**不是**策略基线；
- 两者**分节登记、各自独立版本化**；
- **禁止**把探针族收益读入强度判定；**禁止**把探针命中率解释为强度改善 / 恶化；
- 若某成员想**同时**充当两者，必须在冻结文本中**显式双重登记**并说明配对与聚合方式；默认**不允许**。

### 6.2 成员与版本

冻结文本**必须**含一张表，逐成员登记：成员标识（策略标识 + 版本 / 摘要）、冻结来源、角色（迁移基线 / 固定基线）、配对方式（不得对个别成员另设）、以及其在 §6.3 中的处置。

**准入条件**：**(a)** 已冻结且可确定性重放；**(b)** 不依赖在线外部服务；**(c)** 一经冻结，**不得**按任何读数增删、替换或升版。

**`heuristic@1` 的角色**：作为**迁移基线**保留；**明文声明**其**不是**真实强度上界、**不是**教学正确性基准、**不是**「可接受强度」的定义者；「优于 `heuristic@1`」**不得**表述为强度已获证明。

**是否引入辅助基线**：**需要**（单一基线不足以界定「可接受劣势」）。具体成员属冻结清单内容，**须在冻结时裁定并登记**；本草案**不指定**成员。

### 6.3 主判聚合（第一次修订消除选择偏差；第四次修订改为与 R1 / R2 一致的分布无关同时下界；第七次修订统一域 C 的 `α` / `β` 分配命名）

**问题（原件缺陷）**：先看数据挑出「最不利成员」，再直接使用该成员**未经校正**的单个区间下界，属于**事后选择**，会低估区间覆盖误差。

**修订后的主判方法（唯一采用：对 `min_b` 的同时下界；第四次修订改为与 R1 / R2 一致的分布无关构造）**：

```text
目标量：          Δ_main(g) = min over b ∈ 基线池 of Δ(g, b)
命名（第七次修订，**必须**与 §4.4.2 的分配路径一致）：G = 主判格数
                  α_g := α_C / G                    （先按格分配）
                  α_C′ := α_g / M = α_C / ( G · M )  （再在成员间分配）
                  β 同路径：β_g := β_C / G ，β_C′ := β_g / M = β_C / ( G · M )
逐成员保守下界：  L(g, b) = 依所选路线（R1 的 Hoeffding 或 R2 的 Cantelli）
                  在**校正后的置信水平 α_C′** 下计算的单侧下界（M = |基线池|）
同时下界：        L_main(g) = min over b of L(g, b)
判定：            L_main(g) ≥ δ_budget  ⇒  该格满足
```

**要点**：

1. **多重比较的施加方式必须与所选路线一致（第四次修订更正；第七次修订统一命名）**：R1 / R2 都是**分布无关界**，校正方式是把**界内的置信水平改为 `α_C′ = α_g / M`**（半宽随 `α_C′` 变化；`α_g := α_C / G`，路径见上框与 §4.4.2）；**禁止**写成缺少 `α_g` 定义的 `α′ = α / M`，也**不得**沿用「`c = z_{1−α/M}` 乘 `SE`」的正态写法（该写法对 R1 / R2 无效）。`G`、`M` 与校正方式必须在冻结时写定，**不得**事后更改；
2. 该构造给出的是 `min_b Δ(g,b)` 的**同时**下界：在声明的置信水平下，`L_main(g) ≤ min_b Δ(g,b)` 以不小于 **`1 − α_C`**（**域 C 的族水平**，不是未限定的 `1 − α`）的概率成立（Bonferroni 保守；若采用其它同时构造，其**有效性证明**必须一并预注册）；
3. **禁止**「先按读数挑成员、再用未经校正的单个界」；
4. **R3（备选设计，当前**非**主判候选，第三次修订更正）**：R3 在本框架中只作**非阻断报告**（§4.4.2 / §8.1），**不参与**本节的主判聚合；若未来经**单独的框架级路线裁定**授权其为主判，则对每个成员按 §4.4.2 的**精确单侧上界规则**（`X ≤ c_crit`，等价于单侧上置信界 `≤ p0`）检验，逐项水平取 `α_C′ = α_g / M = α_C / (G · M)`（同一分配路径），并采用 **AND 规则**；
5. **备选（须由用户替换指定，本草案不默认采用）**：
   - **(a)** 预先指定**唯一主基线**，其余成员仅作次判报告（不参与判定）；
   - **(b)** 全部成员**分别**作为共同主判并做多重比较校正；
6. **报告纪律**：**必须**并列每个成员的分量，**不得**只报聚合值；
7. **所选界的全部参数必须写死（第四次修订更正；第六、七次修订统一记号与解算路径）**：R1 的界形式与常数、R2 的**逐块 `V_j` 与均值上界 `V̄_B`** 以及**用于解算块数的统一上界 `V_max`**（必须与 seed 无关）与 Cantelli 参数、块级聚合方式（权重**非负且和为 1**）、以及**逐成员 `α_C′` 的施加方式**（`α_g := α_C / G` 之后再除 `M`），均属 §11.1 必填项；**未写定 ⇒ 不得冻结**。**禁止**把「正态区间 + Bonferroni 乘子」当作 R1 / R2 的实现；
8. **`α` 的层级必须写死（第二次修订新增）**：`α` 定义在「逐格」还是「跨格族」层面，必须在冻结时写定。在「全部主判格与全部主判域都必须满足」的 AND 语义下，跨格层面的族错误率是**保守**的，但该性质**不替代**写定 `α` 的层级。

### 6.4 防掩盖规则

- 主判取**最不利成员**（含多重校正）⇒ 较弱成员在数学上**不可能**用于提高通过概率；
- **禁止**任何形式的「按成员加权平均后通过」作为主判；
- 若某成员事后被判定为**退化或不可用**：**冻结前**发现 ⇒ 移出池并重算样本量；**冻结后**发现 ⇒ 按 §10 记为 **不可判定**，**禁止**临时移除后重判。

## 7. 探针池（独立小节）

- 成员、版本与比较口径**必须在冻结时登记**；一经冻结**不得**按读数增删、重定义或替换（含「探针重叠导致伪独立」的预声明处理方式）；
- 探针池的**唯一**作用：在**已声明**的对手条件下检查被测身份是否出现**新的**可利用信号；
- **结论边界（强约束）**：结论**只能**表述为「**本次样本集与本次探针池下未观察到 X**」；**不得**表述为「不可剥削」，**不得**作为 exploitability / NashConv / best response 上界；**不得**把探针命中率变化包装为强度改善 / 恶化；**不得**把探针池的有限性说成「已覆盖」；
- 探针池为**次判 / 报告域**（§10 域 D），**不阻断**。

4. 停止护栏触发 ⇒ **暂停并要求调查**，并按 §10 定状态（**不得**直接记为「未满足」或「通过」）；
5. **与 `73a` §4.3 第 4 条的取代关系（第二次修订新增，必须显式声明）**：`73a` §4.3 第 4 条要求「两口径并列，任一口径不一致即判未满足」。本框架**只允许单一口径阻断**（§8.1 与本节第 2 条），因此该条**在本框架的未来战役中不再适用**，由本节取代。`73a` 正文**不改写、不重编号、不移动路径**；本声明**只**界定其适用范围。该取代**不构成**对 `-v10` 的改判：`-v10` 仍按 `58f` 判定，结论完全保留。

## 9. 功效、样本规模与停止规则

### 9.1 输入清单（四项来源，均须独立于候选身份）

### 9.2 判定方向、风险预算、设计备择与可检出间隔（第四次修订：统一判定方向）

**判定方向（唯一，先于一切数值写定）**：主判用**下置信界支持「满足」**，即 `L ≥ δ_budget ⇒ 该格满足`。因此：

```text
目标量（第七次修订：**只能**用固定设计平均）：μ̄_B := ( 1 / B ) · Σ_{j=1..B} E[ X_j ]
满足侧（可接受侧）：μ̄_B ≥ δ_budget
设计备择 δ_alt **必须位于满足侧**：δ_alt > δ_budget（在同一负值区间内即「劣势更小」）
可检出间隔 m := δ_alt − δ_budget > 0
功效定义：P( 判定满足 | μ̄_B = δ_alt ) ≥ 1 − β
（**不得**把 μ̄_B 写成共同总体均值 μ；只有额外预注册同分布 / 代表性抽样时才可简写）
```

| 项 | 定义 | 用途 | 来源 |
|---|---|---|---|
| **风险预算 `δ_budget`** | **产品可接受劣势边界**：`δ_budget = −10 BB/100`，固定设计平均 `μ̄_B ≥ −10 BB/100` 即视为可接受 | 判定门槛 | **用户产品裁定**；性质为产品风险决策，**不是**教学标准 / GTO 基准 / 强度上界，也不来自候选读数 |
| **设计备择 `δ_alt`**（R1 / R2；位于满足侧） | `δ_alt = 0 BB/100`；固定设计平均达到该点时，全部主判比较同时判定满足的概率按逐项 `β′ = β / N_cmp` 设计。该式只在全部比较同时达到各自预注册设计备择（联合备择向量）时成立；跨域仍须另行裁定 | 样本量解算 | **用户设计裁定**，不来自候选读数 |
| **可检出间隔 `m := δ_alt − δ_budget`** | `m = 10 BB/100`；`μ̄_B` 落在 `[−10, 0)` BB/100 内时不保证能判定满足 | 设计报告与局限声明 | **用户设计裁定** |
| **`p0` / `p1`（备选，非主判；仅 R3）** | `p0` = 允许的越界块比例上限（**产品风险参数**）；`p1` = 设计备择比例（设计参数，`p1 < p0`） | 仅在 R3 经单独框架级路线裁定授权为主判时进入判定 / 解算 | `p0`：**产品裁定**；`p1`：设计参数；**当前不构成本框架的冻结前置** |

**修正与纪律**：

1. **方向统一（第四次修订）**：主判只对**满足侧**作判定；设计备择一律取 `δ_alt > δ_budget`、`m > 0`；**禁止**把功效目标写成「判定未满足」；
2. 判定边界与功效目标**不再视为天然等价**，**必须分别列示**；
3. **不得**再声称「`|δ_mde| > |δ_budget|` ⇒ 更严格」——该表述**不普遍成立**。正确的表述是：`m` 越小（备择越靠近边界），所需样本量越大；其可行性必须由 §9.3 解算证实；`m` 的取值是**设计选择**，必须附理由并预注册；
4. **功效不对称与「未满足」的措辞（第四次修订；第五次修订细化）**：`L < δ_budget` 时按 §10 记 **未满足**，但该方向**不作功效承诺**：**只能**表述为「**本次主判未能支持满足**」，**不得**表述为「已证明**固定设计平均** `μ̄_B` 劣于 `δ_budget`」或「已证明劣化」。若产品需要对**劣化侧**的有功效判定，**必须单独立项**（另设上置信界 / 第二检验并**重新定义三态映射**）；**禁止**复用 R1 / R2 的样本量式实现它；
5. **符号统一**：全部劣势量取**负值**；判定为「量 `≥ δ_budget` ⇒ 满足」；R3 的边界事件同向（§4.4.2）；
6. `p0` 与 `δ_budget` 同属**产品风险参数**，其性质须登记为「产品风险决策」，**不是**教学标准 / GTO 基准 / 强度上界；
7. 上述全部数值均不得由任何候选身份读数反推或校核；
8. **本次已获授权填写** `δ_budget`、域 A / 域 B 阈值、设计备择、域级 `α` / `β` 与理论聚合权重；它们不构成清单、seed 或其他冻结项的授权，也不得据此执行样本量算术、全偏移量验证或包络估算；
9. **R3 相关数值当前不请求**：`p0` / `p1` / `c_crit` 只有在 R3 经**单独的框架级路线裁定**授权为主判时才有意义；本框架当前状态不得据此索要任何数值。

**域级统计水平（用户裁定）**：`α_A = α_B = α_C = 0.05`，`β_A = β_B = β_C = 0.20`，各域目标功效为 `1−β = 0.80`。逐项水平必须按各域既定比较集合派生：`α_A′ = α_A / N_cmp,A`、`β_A′ = β_A / N_cmp,A`；`α_B′ = α_B / N_cmp,B`、`β_B′ = β_B / N_cmp,B`；`α_C′ = α_C / (G·|基线池|)`、`β_C′ = β_C / (G·|基线池|)`。**不得声明 A / B / C 同时满足具有总体 80% 功效**；跨域总体功效须另行裁定跨域 `β` 分配。

### 9.3 样本量解算（按所选路线分列；先算后跑，顺序不可颠倒）

**顺序硬约束（第二次修订新增）**：先由功效解出每主判格（含**域 A 的情境**与**域 B 的分域**）所需的块数 `B_g` 与每块片段数，**再**由**全新清单**提供**不少于该数量**的**预注册块**（块数与种子结构属清单层，§4.2）。**禁止**「先固定少量种子、事后延长或按读数增补块」。

**本次仅落盘输入值，不执行算术**：已填入域 C 的 `δ_budget = −10 BB/100`、`δ_alt = 0 BB/100`、`m = 10 BB/100`；域 A / B 的设计备择、域级 `α = 0.05` / `β = 0.20` 与理论聚合权重见 §5.4 / §5.5 / §5.6 / §9.2。`N_cmp`、逐项 `α′` / `β′`、路线、`V_max`、块数及包络仍未解算或冻结。

- **R1（Hoeffding，唯一方法）**：`B_g ≥ 8 · M² · max{ ln(1/α_C′) , ln(1/β_C′) } / m²`（§4.4.2 的**唯一**统一式代入 `R = 2M`；`m = δ_alt − δ_budget`；`α_C′` / `β_C′` 为**域 C 的逐项水平**，`N_cmp = G × M`；逐项水平按 §4.4.2 的分配路径（`α_g := α_C / G` 之后再除 `M`））；解出的 `B_g` 必须 ≤ 清单可提供的预注册块数，否则 R1 **不可行**（须如实记录该算术；**不得**预判）；
- **R2（Cantelli；第七次修订：解算路径唯一，消除循环依赖）**：先给出**逐块 `V_j`** 与**均值上界 `V̄_B`**（**必须含片段间协方差处置**，§4.4.2 (ii)(iii) 的 (a) 或 (b)），并**在建清单之前**冻结**块模板统一上界 `V_max`**（要求 ∀j：`V_j ≤ V_max`；且 `V_max` **必须**同时满足 §4.4.2 (vi) 的三条：与 seed 无关、**独立于任何候选身份读数**、由冻结块模板 / 取值域 / 解析协方差界推出；解析只能得 `M²` 时**必须**如实使用该退化上界），然后按 `B ≥ ( 4 · V_max / m² ) · max{ (1 − α_C′)/α_C′ , (1 − β_C′)/β_C′ }` 解算；逐块 `V_j` 的一般式**只**用于清单落盘后的**事后合规校验**（`(1/B²)·Σ_j V_j ≤ (m²/4)·min{ α_C′/(1−α_C′) , β_C′/(1−β_C′) }`），**不得**用于解 `B`（§4.4.2 (vi)）；若逐块 `V_j` 只能取到 `M²`（退化情形）必须**如实报告**；`σ(d)` / `U_{K_f}` / `V_j` / `V_max` 的独立来源必须登记；
- **域 A / 域 B**：按 §5.4 / §5.5 的**自有代入值**（各自的取值域宽度、`Δ_alt` 与逐项 `β_A′` / `β_B′`）解算 `B_A` / `B_B`，**不得**套用本节 R1 / R2 的代入值或 `M`；其块级随机性来源与解算量口径依 §5.7（`σ_j` 生成协议；解算**只**用与 seed 无关的量）；域 B 的锚点比较数为 `|A_B|`（`P_B` 与 `other` **不进入**），聚合权重 `v_i` / `w_m` 见 §5.5 / §5.6；
- R1 / R2 与域 A、B 均**必须**给出**中间量**（取值域 / 上界参数 `V_j` / `V̄_B` / **统一上界 `V_max`**、`δ_budget` / `δ_alt` / `m`、`α` / `α′` / `β` / `β′`、`N_cmp`、块数、**清单所需预注册块数**、**每块最小节点 / 片段数**、**总节点 / 总片段 / 总手数**、`σ_j` 生成协议要点（含 `Φ`、`n_ℓ`、`Θ_ℓ`）、`A_B` 与 `P_B` 两个桶集合、聚合权重 `v_i` / `w_m`、预计 `wall`、预计输出、预计峰值 RSS）以便审查；
- **算不出、或解出的块数超过清单可提供的预注册块数 ⇒ 不冻结、不运行**；
- **三项分开登记（第五次修订）**：**独立统计样本量 = 有效块数**；**每块最小节点 / 片段数**（**仅为设计约束**）；**总节点 / 总片段 / 总手数**（**成本量**）。**禁止**把三者相乘后称「最小有效样本」——块内数量**不会**按独立观测数提高 R1 / R2 的功效（§5.2 / §5.4 / §5.5）；
- **（备选，非主判）R3**：若未来经**单独的框架级路线裁定**授权其为主判，则须用**精确二项分布**解算 `B_g` 与 `c_crit := max{ k : P_{p0}(X ≤ k) ≤ α′ }`，并给出 `p0` / `p1`（`p1 < p0`）与精确功效中间量；**在本框架当前状态下不需要这些数值，也不得据此请求数值**。

### 9.4 包络可行性（**先算，不得"跑跑看"**）

1. 冻结前**必须**由 §9.3 的中间量估算**预计 `wall` / 输出 / 峰值 RSS**，并与既有包络（`wall` / 峰值 RSS / 输出三项）对比；
2. 若预计**超出**包络：**不得**自行扩容；只能 **(a)** 缩减规模并把缩减**如实**写入局限，或 **(b)** **先单独裁定**包络；
3. 由于 §10 把**成本越界记为「未满足」**（而非「不可判定」），**不得**以「先跑跑看，越界再说」的方式推进——越界本身就是一个明确的未满足状态；
4. 成本口径**必须并列**整个调用的最大常驻集（判定口径）与模块自记峰值（**下界**）；
5. **包络判定值与来源必须显式登记（第二次修订新增）**：`wall` 上界、峰值 RSS 上界（含口径）、输出上界**各自**的数值，以及**每一个值的裁定来源与生效范围**（例如某次放宽是否适用于本次规模 / 身份 / 样本集），均属 §11.1 必填项；**不得**只写「沿用既有包络」；
6. **`B_g` 可达性检查（第二次修订新增）**：§9.3 解出的每格 `B_g` 必须 **≤ 清单预注册块数**；不满足即为**可行性不成立**（**禁止**「先跑跑看」）。

### 9.5 停止规则（与 §10 状态机联动，必须预注册）

| # | 停止类型 | 触发 | 结果状态（§10） |
|---|---|---|---|
| 1 | 正常停止 | 样本达到 §9.3 解算量 | 按主判结果定 |
| 2 | 护栏停止 | 块极值口径触发 / 块级离散度异常 / 截断率越界 / 作废率越界 | **不可判定**（原因 = 护栏），并把护栏读数作为风险报告并列 |
| 3 | 成本停止 | 触及 `wall` / 峰值 RSS / 输出任一上界 | 域 E = **未满足** ⇒ 总体 **未满足（运行成本未满足）** |
| 4 | 错误停止 | 合法性 / 信息边界 / 摘要一致性 / 确定性重放失败 | 总体 **未满足**（原因 = 正确性） |
| 5 | 运行错误停止 | 构造 / 序列化 / 入口等**非正确性**错误 | **不可判定**（原因 = 错误） |
| 6 | 样本不足停止 | 某主判格无法达到 §9.3 下限 | **不可判定**（原因 = 样本不足） |

**禁止**事后延长、缩短或重跑样本以改变状态。

## 10. 状态机（第一次修订：分域状态 + 总体状态；第二次修订补 A / B 口径前置）

### 10.1 分域状态

对五个域**分别**记录状态：**主判域（A / B / C / E）** 取值域为 `{满足, 未满足, 不可判定} `；**报告域（D）** 取值域为 `{已报告, 未报告}`，**不适用**前三者：

| 域 | 内容 | 是否主判 | 状态取值 |
|---|---|---|---|
| **A** | 人格可感知性 | **主判** | 满足 / 未满足 / 不可判定 |
| **B** | 行为不可预测性 | **主判** | 满足 / 未满足 / 不可判定 |
| **C** | 强度风险（§4 / §6 / §8） | **主判** | 满足 / 未满足 / 不可判定 |
| **D** | 已定义探针风险（§7） | **次判 / 报告** | 已报告 / 未报告（**不阻断**） |
| **E** | 运行成本（§9.4） | **主判**（必要条件） | 满足 / 未满足 / 不可判定 |

**E 的特别说明（更正原件矛盾）**：成本**越界是已观测事实**，说明该必要条件**明确不满足** ⇒ 记为 **E = 未满足**，**不得**记为「不可判定」。仅当成本**未能测得**（例如运行在更早阶段被中止）时才记 E = 不可判定。

**A / B 的特别说明（第二次修订新增）**：域 A / 域 B 的判定口径（估计对象、分母、主判情境 / 分域、阈值来源、区间、样本量与功效、多重比较、缺失处置）必须在 §5.4 / §5.5 中定义，并逐项写入 §11.1 清单；**缺任一项 ⇒ 冻结文本不成立**。**未定义**的域**不得**以任何形式参与 §10.2 的总体状态判定。

**「未满足」的两种语义必须区分（第五次修订新增；第七次修订对齐目标量记号）**：域 **E** 的「未满足」是**已观测事实**（成本越界）；域 **A / B / C** 的「未满足」是**保守门禁结果**，**只能**表述为「**本次主判未能支持满足**」，**不得**解释为「**固定设计平均**已被证明劣于门槛」或「已证明劣化」。

### 10.2 总体状态映射（三类，必须预注册）

```text
1. 若任一主判域（A / B / C / E）= 未满足                ⇒ 总体 = 未满足
      （必须列出未满足域，例如「运行成本未满足」或「强度风险未满足」）
2. 否则，若任一主判域 = 不可判定                        ⇒ 总体 = 不可判定
      （必须列出原因，例如「样本不足」或「运行错误」）
3. 否则（A / B / C / E 全部满足）                       ⇒ 总体 = 满足
```

**补充规则**：

- **硬失败**（合法性 / 信息边界 / 摘要一致性 / 确定性重放失败）⇒ 总体 = **未满足**，原因 = 正确性；这条把正确性缺陷与「缺证据」区分开（若用户要求改为「不可判定」，**必须在冻结前裁定**；冻结后不得修改）；
- **D 域**永不参与总体状态（无阈值、不阻断）；但 D = 未报告时**必须**在局限中声明；
- **总体 = 满足**还**必须**满足：**三个主判域（A / B / C）的格子 / 情境 / 分域全部齐备**，且无任何主判格 / 主判情境 / 主判分域为不可判定。

### 10.3 状态与默认策略

- **只有**「满足」**且**用户完成质量签收，才**可能**改变默认策略；
- 「未满足」与「不可判定」**均保持** `heuristic@1`；
- 任一状态**均不得**表述为「验证通过」「已达生产门槛」。

### 10.4 措辞约束

- 「满足」**只能**表述为「**本次独立验证下主判满足**」；**不得**表述为稳健达标、质量已证明或不可剥削；
- 「不可判定」**不得**表述为「通过」或「接近通过」；
- **成本导致的未满足**：**只能**表述为「**运行成本未满足**」（**已观测事实**），**不得**淡化为「统计证据不足」；
- **A / B / C 的未满足（第五次修订新增；第七次修订对齐记号）**：**只能**表述为「**本次主判未能支持满足**」；**不得**表述为「已证明**固定设计平均** `μ̄_B` 低于 `δ_budget`」、「已证明劣化」或任何等价说法；
- 「未满足」**不得**被归因为口径问题、工程问题或门槛过严。
