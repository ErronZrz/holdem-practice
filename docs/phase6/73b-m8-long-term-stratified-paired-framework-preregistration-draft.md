## 2. 统计对象与归一化

### 2.1 记号

| 符号 | 含义 |
|---|---|
| `N` | 人数 |
| `S` | 该格子的起始筹码（引擎构造参数） |
| `BB_s` | 该会话的大盲值 |
| `K_f` | 片段 `f` 的手数 |
| `m_h` / `b_h` | 第 `h` 手被测身份 / 基线成员的净筹码（含盲注与全部投入） |
| `d_h` | 配对差筹码：`d_h = m_h − b_h` |
| `Δ_f` | 片段级配对差，单位为「每 100 手的筹码 / 大盲」口径（见 §2.3） |

### 2.2 估计目标（estimand）

对每个**主判格子** `g` 与基线池成员 `b`：

```text
Δ(g, b) = 片段级配对差 Δ_f 的期望，单位与 Δ_f 相同
```

**硬约束**：

1. `Δ` **必须**建立在**片段**之上；**禁止**把单手底池直接当作长期 `BB/100`；
2. 判定**不得**只使用点估计；必须使用**区间或等价的保守判定量**（§8）；
3. 片段级统计量的**构造**必须在冻结时写定（等权还是按手数加权），**不得**事后选择。

### 2.3 归一化分母与截断 / 零 / 缺失处置（**可执行规则**）

**唯一允许的归一化**：

```text
Δ_f = ( Σ_{h ∈ f} d_h ) · 100 / ( K_f · BB_s )
```

即：**分母 = 片段手数 `K_f` × 该会话大盲 `BB_s`**；`BB_s` 在一个片段内**必须**唯一。

| 情形 | 处置 |
|---|---|
| 盲注结构在会话内可变（升盲） | **必须**按升盲边界切分片段，使每个片段内 `BB_s` 唯一 |
| 同一片段内出现两个不同 `BB_s` | 该片段**作废**，计入作废率 |
| `K_f = 0`（空片段） | 片段**作废**，计入作废率 |
| 某一手在一侧**配对不完整** | 该片段**整体作废**（**禁止**逐手丢弃，避免选择偏差） |
| `d_h = 0` | **有效观测**（同一结果）；**不得**剔除，**不得**不计入样本 |
| `BB_s ≤ 0` 或缺失 | 该**会话整体作废**；**禁止**用默认值兜底 |
| 截断手（达到动作上限的手） | **保留在片段内并照实计入**；**不得**剔除截断片段；**必须**分别报告截断率 |
| 截断率超过预注册上限 | 触发停止（§9.5），并按 §10 定状态 |

**禁止**：按片段内**实际投入**、**实际底池**或**实际大盲参与量**动态构造分母——那会把策略行为写进分母，破坏外生性。分母**只**由 `K_f` 与 `BB_s` 决定。

**作废率**：作废片段数与作废会话数的**上限**必须在冻结时预注册；超过上限 ⇒ 触发停止（§9.5）。

## 3. 片段定义（外生且对称）

### 3.1 入选规则（唯一依据）

一个对局进入某个片段，**只**允许由下列条件决定：**(a)** 对局序号；**(b)** 公共条件（人数、起始深度、按钮起始位、盲注结构）；**(c)** 配对条件（§3.3）。

### 3.2 起止与切分规则（与策略无关）

- 片段按**预注册的序号边界**切分（每 `K` 连续对局为一个片段，`K` 在冻结时固定；或按固定序号列表切分）；
- `K` **不得**依赖任何动作、收益、行动线或事件的发生；
- 片段起止**不得**因「某条行动线是否发生」而被延长、截断或跳过；
- **禁止**用「焦点是否进入某分支 / 是否出现某动作 / 是否发生某事件」作为入选或切分条件。

### 3.3 对称性核验（运行前完成，硬门）

1. **片段划分必须是身份的纯函数**：给定（清单、种子、片段规则），片段集合唯一；
2. 核验方式（**只读**）：对同一（人数 × 深度 × 起始按钮位）构造两侧序列，逐片段比对**成员对局序号集合**是否逐项相等；
3. 任一侧不相等 ⇒ **框架不得冻结**。

### 3.4 禁止项汇总

| 禁止 | 原因 |
|---|---|
| 依赖被测或基线的动作 / 收益决定入选或切分 | 对称性破坏 ⇒ 自证 |
| 以「是否进入某行动线」切分 | 把结果条件写进样本定义 |
| 以「是否发生某事件」事后调整片段边界 | 事后选样本 |
| 让片段长度随人数 / 风格变化而不预先声明 | 不可审查的隐含分层 |

## 4. 配对、块与方差依据

### 4.1 配对规则

- 配对**必须**满足：同牌堆派生流、同位置、同起始深度；
- **禁止**把新动作接到旧历史后缀上算反事实 EV；**禁止**用不同牌堆的样本拼出「改善」。

### 4.2 块的定义与来源

- **块 = 最小的重抽样单元**，成员来自同一随机源（同一牌堆派生流）；
- **块数由样本集设计决定**（种子结构，属**清单层**，与身份无关）；**禁止**按读数增删、合并块或改变块与种子的对应关系；
- 块的**独立性**（不同块来自不同种子派生流）是**结构性声明**，其可执行核验见 §4.4.3。

### 4.3 区间与聚类

- 任何区间**必须**在**块层**构造（块级重抽样或等价的聚类稳健方法）；
- **必须并列报告**：点估计、区间、块级离散度、块极值、逐主判格子分解；
- **禁止**只报合并均值；**禁止**用合并均值代替逐格子结论。

### 4.4 方差依据（**本次修订的核心**）

#### 4.4.1 正确的分布无关界（更正原错误）

```text
单手配对差的上界：   |d_h| ≤ D_max := 2 · (N − 1) · S          （两侧各自净额上界）
片段级统计量：       Δ_f = ( Σ_{h ∈ f} d_h ) · 100 / ( K_f · BB_s )
⇒ 分布无关的上界：   |Δ_f| ≤ M := 2 · (N − 1) · S · 100 / BB_s
⇒ 有界支撑的标准差界：σ(Δ_f) ≤ M                              （两端点分布取等）
```

**关键更正**：`K_f` 在分子（最坏损失随 `K` 线性累加）与分母（归一化随 `K` 线性累加）中**相消**。因此：

1. **把多手聚合成片段，不会自动带来任何最坏情形缩减**；`M` **与 `K_f` 无关**；
2. 「`σ ∝ 1/K`」**不成立**（初版错误即在此）；
3. 若要**真正**在 `K` 上获益，**必须**引入片段内手间**独立或可混合（mixing）**的假设。在该假设下才有：

```text
σ(Δ_f) = σ(d) · 100 / ( BB_s · √K_f )        （注意是 1/√K，不是 1/K）
```

4. 上述独立/可混合假设**必须**独立且可验证地预注册；**未经验证不得使用**（§4.4.3）；
5. 无论采用哪条路线，**禁止**用任何候选身份（含 `mixed-local@8`）的实测离散度替换方差输入；`-v10` 的离散度读数**只能**作为**描述性现象**引用（`docs/phase6/57m` §4.2、`58n` §4.2 / §5.1）。

#### 4.4.2 三条合法路线（**冻结时必须择一写定**）

| 路线 | 方差 / 功效来源 | 需独立性假设 | 依赖候选读数 | 主要风险 |
|---|---|---|---|---|
| **R1 分布无关区间界** | `σ ≤ M`（§4.4.1，**与 `K` 无关**） | 否 | 否 | **可能不可行**：`M` 很大 ⇒ 所需块数可能极大；冻结时必须做**可行性算术**并如实记录；不可行即**不得**采用 |
| **R2 预注册方差模型** | `σ(Δ_f) = σ(d)·100/(BB_s·√K_f)` + `σ(d)` 的**独立**来源 | **是**（且须可验证） | 否 | 假设不成立则区间失真；`σ(d)` 的独立来源必须显式登记（引擎解析界 / 独立预注册测量协议），**不得**取自候选身份读数 |
| **R3 块层比例型判据**（**推荐**） | **不需要方差模型**：判定对象改为「越界块的比例」；样本量由**二项功效**决定，只依赖 `(p0, p1, α′, β)` | 否（块为计数单元） | 否 | 丢弃幅度信息 ⇒ 需把连续幅度并列作**非阻断**报告 |

**R3 的形式化（推荐主判）**：

```text
对块 j 与基线成员 b：
    块级统计量：   Δ_{g,b,j} = 该块内片段级 Δ_f 的预注册加权平均
    边界事件：     E_{g,b,j} = 1[ Δ_{g,b,j} < δ_budget ]        （δ_budget 为产品风险预算，负值）
    主判量：       比例 P̂_{g,b} = ( Σ_j E_{g,b,j} ) / B_g
判定规则：        逐成员单侧二项检验（多重比较按 §6.3 校正）；
                  全部成员均**不得**超出允许的越界比例（AND 规则）
样本量：          B_g ≥ ceil( ( z_{1−α′}·√(p0(1−p0)) + z_{1−β}·√(p1(1−p1)) )² / (p1 − p0)² )
```

- `p0` = 允许的越界块比例上限（**判定性质的产品参数**）；`p1` = 期望在给定功效下可检出的更高比例（**功效设计参数**）；`α′` / `β` = 校正后的显著性水平与第二类错误率；
- `(p0, p1, α′, β)` **全部是设计 / 产品参数**，**不含任何候选身份读数**；
- **结构理由**（不是经验理由）：块是计数单元，块内相关性**不进入**二项方差模型；该理由**依赖**于「块之间由不同种子派生流独立生成」这一**结构性声明**，其核验见 §4.4.3；
- R3 下连续幅度 `Δ̂(g,b)` 与其块级聚类区间**仍须报告**，但**明确定位为非阻断报告**，且其区间宽度**不**作任何功效承诺。

#### 4.4.3 独立性与可验证性要求

| 声明 | 必须配套的核验（预注册、可执行、只读） |
|---|---|
| 块之间独立 | 对块级统计量做**预注册的独立性核验**（例如块间序列相关 / 游程检验的预声明判据），仅对**统计结构**（不含任何质量结论）作断言 |
| 片段内手间独立或可混合（**仅 R2 需要**） | 对片段内 `d_h` 做**预注册的序列相关 / 变差系数核验**；核验不通过 ⇒ **R2 不得使用** |
| 片段划分是身份的纯函数 | §3.3 的成员序号集合逐项比对 |

**核验失败处置**：核验**未通过** ⇒ 相应路线**不得使用**；若冻结时已选定该路线而事后核验失败 ⇒ 按 §10 记为 **不可判定**（**不得**改口径后重判）。

## 6. 基线池

### 6.1 与探针池的**分离**（硬约束）

- **基线池** = 用于**强度比较**的基线策略（含版本）；
- **探针池** = 用于**对手条件检查**的探针族（§7），成员是**对手条件**，**不是**策略基线；
- 两者**分节登记、各自独立版本化**；
- **禁止**把探针族收益读入强度判定；**禁止**把探针命中率解释为强度改善 / 恶化；
- 若某成员想**同时**充当两者，必须在冻结文本中**显式双重登记**并说明配对与聚合方式；默认**不允许**。

### 6.2 成员与版本

冻结文本**必须**含一张表，逐成员登记：成员标识（策略标识 + 版本 / 摘要）、冻结来源、角色（迁移基线 / 固定基线）、配对方式（不得对个别成员另设）、以及其在 §6.3 中的处置。

**准入条件**：**(a)** 已冻结且可确定性重放；**(b)** 不依赖在线外部服务；**(c)** 一经冻结，**不得**按任何读数增删、替换或升版。

**`heuristic@1` 的角色**：作为**迁移基线**保留；**明文声明**其**不是**真实强度上界、**不是**教学正确性基准、**不是**「可接受强度」的定义者；「优于 `heuristic@1`」**不得**表述为强度已获证明。

**是否引入辅助基线**：**需要**（单一基线不足以界定「可接受劣势」）。具体成员属冻结清单内容，**须在冻结时裁定并登记**；本草案**不指定**成员。

### 6.3 主判聚合（**本次修订：消除选择偏差**）

**问题（原件缺陷）**：先看数据挑出「最不利成员」，再直接使用该成员**未经校正**的单个区间下界，属于**事后选择**，会低估区间覆盖误差。

**修订后的主判方法（唯一采用：对 `min_b` 的同时置信下界）**：

```text
目标量：        Δ_main(g) = min over b ∈ 基线池 of Δ(g, b)
同时置信下界：  L_main(g) = min over b of [ Δ̂(g, b) − c · SE(g, b) ]
其中 c 由**预先声明**的多重比较规则给出（例如单侧 Bonferroni：c = z_{1 − α/M}，M = |基线池|）
判定：          L_main(g) ≥ δ_budget  ⇒  该格满足
```

**要点**：

1. `c` 的取值规则**必须在冻结时写定**（含 `M` 与校正方式）；**不得**事后更改；
2. 该构造给出的是 `min_b Δ(g,b)` 的**同时**下界：在声明的置信水平下，`L_main(g) ≤ min_b Δ(g,b)` 以不小于 `1 − α` 的概率成立（Bonferroni 保守；若采用 max-t 或块层自助等替代方法，其**有效性证明**必须一并预注册）；
3. **禁止**「先按读数挑成员、再用未经校正的单个区间」；
4. **R3 路线**下的对应处置：对每个成员做单侧二项检验，`α′ = α / M`，并采用 **AND 规则**（全部成员均不得超出允许越界比例）——同样是预声明的多重比较控制；
5. **备选（须由用户替换指定，本草案不默认采用）**：
   - **(a)** 预先指定**唯一主基线**，其余成员仅作次判报告（不参与判定）；
   - **(b)** 全部成员**分别**作为共同主判并做多重比较校正；
6. **报告纪律**：**必须**并列每个成员的分量，**不得**只报聚合值。

### 6.4 防掩盖规则

- 主判取**最不利成员**（含多重校正）⇒ 较弱成员在数学上**不可能**用于提高通过概率；
- **禁止**任何形式的「按成员加权平均后通过」作为主判；
- 若某成员事后被判定为**退化或不可用**：**冻结前**发现 ⇒ 移出池并重算样本量；**冻结后**发现 ⇒ 按 §10 记为 **不可判定**，**禁止**临时移除后重判。

## 7. 探针池（独立小节）

- 成员、版本与比较口径**必须在冻结时登记**；一经冻结**不得**按读数增删、重定义或替换（含「探针重叠导致伪独立」的预声明处理方式）；
- 探针池的**唯一**作用：在**已声明**的对手条件下检查被测身份是否出现**新的**可利用信号；
- **结论边界（强约束）**：结论**只能**表述为「**本次样本集与本次探针池下未观察到 X**」；**不得**表述为「不可剥削」，**不得**作为 exploitability / NashConv / best response 上界；**不得**把探针命中率变化包装为强度改善 / 恶化；**不得**把探针池的有限性说成「已覆盖」；
- 探针池为**次判 / 报告域**（§10 域 D），**不阻断**。

## 8. 口径角色（不得重建旧式一票否决）

### 8.1 本次修订后的口径清单

| 口径 | 估计对象 | 地位 |
|---|---|---|
| **主判口径** | R3：越界**块比例**（相对产品风险预算）；R1 / R2：`min_b` 的**同时置信下界** | **唯一阻断项** |
| 连续幅度口径 | `Δ̂(g,b)` 的点估计 + 块级聚类区间 | **非阻断报告**；区间宽度**不作**功效承诺 |
| 块极值口径 | 块级下尾极值 | **停止护栏 + 风险报告**；**不**作「满足 / 未满足」判据 |

### 8.2 硬约束

1. **只有**主判口径可阻断；
2. **禁止**同时把多个口径都设为阻断条件——那会重建旧式一票否决；
3. 若坚持「多口径阻断」，**必须**在冻结前补齐：**(a)** 证明各口径针对**同一估计对象**（或给出联合估计对象的显式定义）；**(b)** 给出**联合**的预声明功效与多重比较处置；**(c)** 说明其**解释价值**。缺任一项 ⇒ **不得**多口径阻断；
4. 停止护栏触发 ⇒ **暂停并要求调查**，并按 §10 定状态（**不得**直接记为「未满足」或「通过」）。

## 9. 功效、样本规模与停止规则

### 9.1 输入清单（四项来源，均须独立于候选身份）

| 输入 | 来源 | 状态 |
|---|---|---|
| **方差 / 计数模型** | R1：`σ ≤ M`（§4.4.1，引擎常量）；R2：`σ(d)` 的独立来源 + 独立性核验；R3：二项模型（无需方差） | 路线未定；**冻结时择一并登记** |
| **产品风险预算 `δ_budget`** | **用户产品裁定**（§9.2） | 【未请求】 |
| **功效设计目标 `δ_mde`（R1/R2）/ 越界比例 `p1`（R3）** | 设计参数（§9.2） | 【待冻结时写定】 |
| **块数 `B_g` / 片段手数 `K_g`** | 样本集设计（清单层） | 由清单决定，待冻结时登记 |

**禁止**：以上任一项**不得**用任何候选身份的实测读数赋值或校核。

### 9.2 风险预算与 MDE 的**独立定义**（**本次修订**）

| 项 | 定义 | 用途 | 来源 |
|---|---|---|---|
| **风险预算 `δ_budget`** | **产品可接受劣势边界**：长期上被测身份相对基线的劣势达到此值即视为不可接受 | 出现在**判定规则**（门槛） | **用户产品裁定**（外部）；性质须登记为「产品风险决策」，**不是**教学标准 / GTO 基准 / 强度上界 |
| **MDE `δ_mde`**（R1 / R2）或**可检出越界比例 `p1`**（R3） | **功效设计目标**：在给定 `(α, β, 样本量)` 下实验希望**能够检出**的最小真实劣势（或比例） | 出现在**样本量解算**（功效） | **设计参数**，须在冻结时写定 |

**二者不再视为天然等价**：

1. `δ_budget` 是**判定**的边界；`δ_mde` 是**实验能力**的目标，二者**概念不同**；
2. 若最终取同值，**必须**说明理由（例如：接受「在边界附近的效应可能检不出」这一风险）；
3. 建议（须在冻结时确认）：使 `δ_mde` **严格严于** `δ_budget`（即 `|δ_mde| > |δ_budget|`），并预注册一个**裕度因子**，以免「未检出」与「恰在边界」混淆；
4. **必须分别列示**，**禁止**只给一个数；
5. 二者**均不得**由候选身份读数反推；
6. **在 §0 的六项被接受之前，不请求用户给出 `δ_budget` 数值**——否则该数值会建立在尚未成立的估计对象与功效模型之上。

### 9.3 样本量解算（按所选路线分列，先算后跑）

- **R3（推荐）**：`B_g ≥ ceil( ( z_{1−α′}·√(p0(1−p0)) + z_{1−β}·√(p1(1−p1)) )² / (p1 − p0)² )`，`α′ = α / M`；
- **R1**：以 `σ = M` 代入块层区间公式，逐格迭代解 `B_g`（自由度依赖 `B_g`）；
- **R2**：以 `σ(Δ_f) = σ(d)·100/(BB_s·√K_f)` 代入同一块层公式；`σ(d)` 的独立来源必须登记；
- 三者均**必须**给出**中间量**（方差 / 计数模型参数、`δ`、`p0` / `p1`、`B_g`、总片段数、总手数、预计 `wall`、预计输出、预计峰值 RSS）以便审查；
- **算不出就不冻结、不运行**；
- 每格的最小有效样本 = `B_g` × 每块片段数，**必须**逐格登记（§5.2）。

### 9.4 包络可行性（**先算，不得"跑跑看"**）

1. 冻结前**必须**由 §9.3 的中间量估算**预计 `wall` / 输出 / 峰值 RSS**，并与既有包络（`wall` / 峰值 RSS / 输出三项）对比；
2. 若预计**超出**包络：**不得**自行扩容；只能 **(a)** 缩减规模并把缩减**如实**写入局限，或 **(b)** **先单独裁定**包络；
3. 由于 §10 把**成本越界记为「未满足」**（而非「不可判定」），**不得**以「先跑跑看，越界再说」的方式推进——越界本身就是一个明确的未满足状态；
4. 成本口径**必须并列**整个调用的最大常驻集（判定口径）与模块自记峰值（**下界**）。

### 9.5 停止规则（与 §10 状态机联动，必须预注册）

| # | 停止类型 | 触发 | 结果状态（§10） |
|---|---|---|---|
| 1 | 正常停止 | 样本达到 §9.3 解算量 | 按主判结果定 |
| 2 | 护栏停止 | 块极值口径触发 / 块级离散度异常 / 截断率越界 / 作废率越界 | **不可判定**（原因 = 护栏），并把护栏读数作为风险报告并列 |
| 3 | 成本停止 | 触及 `wall` / 峰值 RSS / 输出任一上界 | 域 E = **未满足** ⇒ 总体 **未满足（运行成本未满足）** |
| 4 | 错误停止 | 合法性 / 信息边界 / 摘要一致性 / 确定性重放失败 | 总体 **未满足**（原因 = 正确性） |
| 5 | 运行错误停止 | 构造 / 序列化 / 入口等**非正确性**错误 | **不可判定**（原因 = 错误） |
| 6 | 样本不足停止 | 某主判格无法达到 §9.3 下限 | **不可判定**（原因 = 样本不足） |

**禁止**事后延长、缩短或重跑样本以改变状态。

## 10. 状态机（**本次修订：分域状态 + 总体状态**）

### 10.1 分域状态

对五个域**分别**记录状态：**主判域（A / B / C / E）** 取值域为 `{满足, 未满足, 不可判定} `；**报告域（D）** 取值域为 `{已报告, 未报告}`，**不适用**前三者：

| 域 | 内容 | 是否主判 | 状态取值 |
|---|---|---|---|
| **A** | 人格可感知性 | **主判** | 满足 / 未满足 / 不可判定 |
| **B** | 行为不可预测性 | **主判** | 满足 / 未满足 / 不可判定 |
| **C** | 强度风险（§4 / §6 / §8） | **主判** | 满足 / 未满足 / 不可判定 |
| **D** | 已定义探针风险（§7） | **次判 / 报告** | 已报告 / 未报告（**不阻断**） |
| **E** | 运行成本（§9.4） | **主判**（必要条件） | 满足 / 未满足 / 不可判定 |

**E 的特别说明（更正原件矛盾）**：成本**越界是已观测事实**，说明该必要条件**明确不满足** ⇒ 记为 **E = 未满足**，**不得**记为「不可判定」。仅当成本**未能测得**（例如运行在更早阶段被中止）时才记 E = 不可判定。

### 10.2 总体状态映射（三类，必须预注册）

```text
1. 若任一主判域（A / B / C / E）= 未满足                ⇒ 总体 = 未满足
      （必须列出未满足域，例如「运行成本未满足」或「强度风险未满足」）
2. 否则，若任一主判域 = 不可判定                        ⇒ 总体 = 不可判定
      （必须列出原因，例如「样本不足」或「运行错误」）
3. 否则（A / B / C / E 全部满足）                       ⇒ 总体 = 满足
```

**补充规则**：

- **硬失败**（合法性 / 信息边界 / 摘要一致性 / 确定性重放失败）⇒ 总体 = **未满足**，原因 = 正确性；这条把正确性缺陷与「缺证据」区分开（若用户要求改为「不可判定」，**必须在冻结前裁定**；冻结后不得修改）；
- **D 域**永不参与总体状态（无阈值、不阻断）；但 D = 未报告时**必须**在局限中声明；
- **总体 = 满足**还**必须**满足：全部主判格齐备且无任何主判格为不可判定。

### 10.3 状态与默认策略

- **只有**「满足」**且**用户完成质量签收，才**可能**改变默认策略；
- 「未满足」与「不可判定」**均保持** `heuristic@1`；
- 任一状态**均不得**表述为「验证通过」「已达生产门槛」。

### 10.4 措辞约束

- 「满足」**只能**表述为「**本次独立验证下主判满足**」；**不得**表述为稳健达标、质量已证明或不可剥削；
- 「不可判定」**不得**表述为「通过」或「接近通过」；
- **成本导致的未满足**：**只能**表述为「**运行成本未满足**」，**不得**淡化为「统计证据不足」；
- 「未满足」**不得**被归因为口径问题、工程问题或门槛过严。
