## 4. `A-i` 的机械明细

### 4.1 新增字段（**必须带默认值且默认等价现状**）

| 项 | 明细 |
|---|---|
| 字段 | `continuous_non_value_basis: bool = False` |
| 语义 | `False` ⇒ 沿用既有三档对手数表（`@1`–`@6` 的分布**逐位不变**）；`True` ⇒ 启用连续式非价值进攻依据 |
| `@7` 取值 | `True` |

### 4.2 新增模块常量（**实施前固定，之后不得按读数调整**）

| 常量 | 取值 | 理由 |
|---|---|---|
| `_NON_VALUE_BASE` | `12` | 与既有对手数表的**最大值**一致 ⇒ 单挑量级不变，不产生全局跳变 |
| `_NON_VALUE_POSITION_WEIGHT` | `4` | 位置分量的上限；与 `position ∈ [-40, 40]` 的既有刻度同阶 |
| `_NON_VALUE_DRAW_WEIGHT` | `4` | 听牌质量分量的上限 |
| `_NON_VALUE_DRAW_CAP` | `180` | 与翻牌听牌分数上限一致 |

### 4.3 公式

```text
对手数分量 = max(1, _NON_VALUE_BASE // contenders)
位置分量   = _NON_VALUE_POSITION_WEIGHT * (position + 40) // 80
听牌分量   = _NON_VALUE_DRAW_WEIGHT * min(draw, _NON_VALUE_DRAW_CAP) // _NON_VALUE_DRAW_CAP
非价值进攻质量 = min(_NON_VALUE_BASE, 对手数分量 + 位置分量 + 听牌分量)
```

对手数分量取值：`c = 1..9` ⇒ `12, 6, 4, 3, 2, 2, 1, 1, 1`。

**与既有表的差异（最小化）**：`c = 1`（`12`）与 `c = 2`（`6`）**与现状完全相同**；`c = 3` 由 `3` 变为 `4`（`+1`）；`c ≥ 4` 由 `0` 变为 `1`–`3`。即本改动**只移除「≥4 名对手时恒为零」这一处**，其余尽量不动。

### 4.4 保留不变的部分（**不得一并改动**）

- 四条准入判断保持原样：`live_opponents == 0` 归零、`recent_aggression > 1` 归零、翻前 `position < 0 或 base < 280` 归零、翻后 `draw <= 0 且无 A/K 阻断` 归零；
- 「危险尺度保护」（`payment == stack` 或 `payment > 3 × 底池参考`）与 `value_quality` 的算法**不动**；
- `active_scale_percent` / `contender_penalty_cap` 的 `@6` 取值**不动**；
- 非价值质量只在**非危险**候选上计入（既有行为）**不动**。

## 5. 更正（勘误）：翻前多人桌零主动的成因

`docs/phase6/61` §7 曾把「翻前多人桌未面对下注时主动率 `0.00%`」也归因于「同一张对手数表」。**该归因不准确**，此处更正：

- 实测（只读普查，`-iqv3` 夹具）：`facing-first-raise` `N=4` 的 `contenders = 3`（表内**有条目**，取值 `3`），但 `position = -14 < 0` ⇒ **在到达该表之前就被翻前准入门归零**；
- 因此翻前多人桌的零主动，成因是 **§3 的 `A-ii`（翻前准入门）**，不是 `A-i`。

**`docs/phase6/61` 已推送，不追溯改写；更正以此处为准。** 该更正**不改变** `docs/phase6/61` 的读数（§6 的读数与结论原样有效），只修正其**机制归因**。

## 7. 算术披露（**推演，不是读数；不承诺达标**）

### 7.1 对 L3 第 4 项（域二）

**口径声明（不得混用）**：上表的「现状」与「`A-i` 后」**都是 `normal` 单手模式的算术推演**，两者可比。而 `docs/phase6/57k` §7 公布的域二读数 `4.51` pp 是**三种手模式合计 units 后按节点等权**的**工件读数**，**与本表不等价**，不得并列或互相换算。

### 7.2 对 L4

`docs/phase6/61` §6.3 显示负差 `85.99%` 落在「街道＝翻前」的配对上，而 `A-i` **只覆盖翻后**。因此：

- `A-i` 对 L4 的作用面是**翻后**那部分（约占负差的 `14.01%`）；
- **方向未知**：主动率上升会放大底池方差，而 `docs/phase6/57m` 已显示 L4 由极少数大额底池主导；
- 本规格**不承诺** L4 会改善。

### 7.3 覆盖的量化边界

按原理性取值，`A-i` 把「翻后多人桌有听牌」这一类的主动依据从 `0` 提到 `1`–`6`（对照单挑上限 `12`），即恢复到单挑量级的 `8%`–`50%`；这是**有意的克制**，而非为达标而定的数值。

## 8. `X6`：翻前准入门（**需单独裁定**）

`X1` 的裁定理由提到「证据已从翻牌面对下注扩展到多人桌翻前无人下注」，但 §5 的机制核实表明：**该扩展所指向的代码位置与 `A-i` 不同**。因此把它单列为 `X6`，并给出三个变体：

| 变体 | 内容 | 新增非零节点 | 主要风险 |
|---|---|---|---|
| **`A-ii-1`** | 完全放开翻前的 `position ≥ 0` 门（保留 `base ≥ 280`） | `+42`（累计 `62`） | 会改变**单挑**与**已满足**的域一：`unopened-open` `N=2`（焦点 `position = -40`）的非价值质量由 `0` 变为 `12`，`facing-reraise` `N=2` 亦由 `0` 变为 `12`；`tight` 的进池率将上升，可能**缩小域一现有的 `18.57` 个百分点差距**，从而使 L3 第 4 项在域一也失去 `2/3` 对 |
| **`A-ii-2`** | 仅在 `contenders ≥ 2`（3 人及以上）时放开该门 | 少于 `A-ii-1` | 仍会改变 `unopened-open` `N ≥ 3`（属**域一**）的进池率，风险同上但幅度小 |
| **`A-ii-3`** | 本轮**不做** `A-ii` | `0` | 翻前多人桌零主动保持现状 ⇒ `docs/phase6/61` 揭示的 L4 负差主体**不受影响** |

**建议**：`A-ii-3`（本轮不做）或先就 `A-ii-2` 单独出规格。理由：`A-ii` 会触及**已满足的域一**，属于「可能同时击穿已达标项」的改动，按 `docs/53` §13.2 需要先有**专门的反例与分层评测**支撑；`docs/phase6/61` 的证据只到「翻前多人桌未面对下注主动率为 `0`」这一步，尚不足以论证「提高 `tight` 的翻前进攻是正确方向」。
