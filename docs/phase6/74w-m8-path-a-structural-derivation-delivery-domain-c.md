### 5.2 概率空间（块 `j`）

记块 `j` 的样本空间为

```text
Ω_j  :=  ∏_{h=1}^{H}  Ω_h
```

其中 `Ω_h` 为第 `h` 手所有合法原始随机材料组合的集合，由已锁定 L-3 的用途、索引键、输出域与拒绝规则所诱导（`deal`、`non_probed`、`arm_m`、`arm_b` 在键 `(campaign, block=j, hand, …)` 上的接受输出）。

**概率测度**（设计层，非实现证明）：

- 在 `74k` **随机化公理**下，对固定 `j`，各手材料按 L-3 规范遍历顺序自外部接口一次性生成；公理**建模**为：在各自有限输出域上，各次有效抽取相互独立且均匀（`74k` §3.1–§3.2）。
- 由此诱导 `Ω_h` 上的乘积测度，并在 `{Z_h}_{h=1}^H` 上得到**手间两两独立**（§11.2 的 C-2′ 构造来源）。
- **块间**：若 campaign 含多块，块 `j` 与 `j'` 的材料索引键在 `block` 字段上区分；在相同公理与一次性生成义务下，**不同块**的材料族相互独立。该独立性用于将来块间统计，**不**进入本节 `V_j` 的推导（`V_j` 为**单块内**方差）。

### 5.3 `Z_h` 与取值函数（与锁定对象对齐）

**推荐语义**（与 `74j` §5.1、`74k` §4.2、`74r` L-3 一致，不引入新设计）：

```text
Z_h  := 由 L-3 在键 (campaign, block, hand) 下接受的全部原始输出所组成的元组

e_h  := 100 · d_h / BB
d_h  := m_h − b_h     （74v PR-4，终局净筹码差）
```


## 6. 块级估计对象与 `V_j` 显式表达

### 6.1 记号（块 `j` 内）

沿用 `74h` §3.2–§3.4，并绑定 `74v` 口径：

```text
规范化单手值     e_h := 100 · d_h / BB
片段 f           块内手的非空集合，两两不相交（F-0）
片段大小         K_f := |f|
片段均值         Δ_f := (1 / K_f) · Σ_{h ∈ f} e_h
片段权重         w_f ≥ 0 ， Σ_f w_f = 1          （WC-1）
块级统计量       X_j := Σ_f w_f · Δ_f
块级方差目标     V_j := Var(X_j)                  （单块理论方差，给定该块的手级联合分布）
```

**估计对象含义（与 L-2／`74n` 对齐）**：`X_j` 是域 C 配对比较下、在 L-2 限定的构造映射与输入口径（`mixed-local@9`、`bot_seats = (probed_seat,)`、`tight`）下的块级加权片段均值；**不**覆盖其他风格或 `all-seats` 口径（`74r` L-2 §5.3）。

### 6.2 `V_j` 的结构表达式（前提条件性）

在前提 C-1′、C-2′、F-0 **成立**时（§11；**当前未建立**），`74h` §3.4 给出：

```text
Var(Δ_f) ≤ E² / K_f
Cov(Δ_f, Δ_{f'}) = 0     （f ≠ f'）
V_j = Var(X_j) = Σ_f w_f² · Var(Δ_f) ≤ E² · Σ_f w_f² / K_f
```

其中 `E` 来自 `74v` §5.2：`E = 100 · N · S / BB`。

该式**不**使用平稳性、同方差或条件零均值；逐手 `Var(e_h)` 可不等，只用到 `|e_h| ≤ E`（C-1′）。

## 7. 统一上界 `V_max^C`（域 C、全块适用）

### 7.1 定义

```text
K_min := min_f K_f
V_max^C := E² / K_min
```

对**任意**满足 WC-1 的权重 `w`：

```text
Σ_f w_f² / K_f ≤ (1 / K_min) · Σ_f w_f² ≤ 1 / K_min
⇒  V_j ≤ E² · Σ_f w_f² / K_f ≤ V_max^C
```

故 `V_max^C` 是对**全部未来块**（在同一冻结模板 `K_f` 划分与 WC-1 下）的统一上界，**不含** seed 或块索引 `j`（`74f` §4.1 第 3 条）。

### 7.2 与朴素支持界 `M_C²` 的对照（非退化比较）

在 C-1′ 成立时：

```text
M_C² := E²        （每手 e_h ∈ [−E, E] 的 Popoviciu 对照，74h §3.5）
V_max^C / M_C² = 1 / K_min
```

- **`K_min ≥ 2`**：结构界相对 `M_C²` **严格**更紧（非退化方向）。
- **`K_min = 1`**：结构界与 `M_C²` **重合**，属**退化**（§12.2），不得宣称非退化。

### 7.3 适用权重类（与 `74v` 锁定一致）

| 编号 | 内容 |
|---|---|
| **WC-1** | 全部 `w_f ≥ 0` 且 `Σ_f w_f = 1` 的片段权重向量；`V_max^C` 对该类**一致**成立 |
| **WC-2** | 默认规范估计权重 `w_f = K_f / Σ_{f'} K_{f'}`；用于解释估计对象时，有 `Σ_f w_f² / K_f = 1 / H`（`H = Σ_f K_f`） |

域 A／B 的层权重 `v_ℓ` **未**锁定，不在 §7 中出现。

| 层级 | 随机量 | 处置 | 依据 |
|---|---|---|---|
| **片段内** | 同一 `f` 内不同手 `h ≠ h' ∈ f` | `Cov(e_h, e_{h'})` 由 C-2′ 设为 `0`；`Var(Δ_f)` 用逐手 `Var(e_h) ≤ E²` 求和 | `74h` §3.4 第一段 |
| **片段间** | 不同片段 `f ≠ f'` | `Cov(Δ_f, Δ_{f'}) = 0`：双重求和中每对 `(h,h')` 分属不同手，由 F-0 不相交与 C-2′ | `74h` §3.4 第二段 |
| **块内（合成）** | `X_j = Σ_f w_f Δ_f` | 片段间协方差为零时，`V_j = Σ_f w_f² Var(Δ_f)`；无遗漏交叉项 | 上表两行 |
| **块间** | `X_j` 与 `X_{j'}` | 本交付的 `V_j` 公式为**块内**量；块间独立用于将来重复块推断，**不**改写单块 `V_max^C` | §5.2 |

**显式禁止的捷径**（`74h` §4、`74f` §4.2.1–§4.2.2）：共同块种子派生各手材料、单条推进流、PRF「近似独立」、输入端独立不经结构直接断言手间零协方差——均**不得**作为域 C 本路径的 A 类依据。

若 C-2′ 不成立：片段内或片段间可能出现非零协方差，§6.2 不等式**失效**，按 §12 处置。

## 9. 适用权重类与 `74f` §4.2.3
