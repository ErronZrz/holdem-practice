## 1. 已审阅结论的接收（照录，不改写）

用户对 `docs/phase6/58n` 的判断，按原意接收如下（不作扩写）：

1. `58n` **合理，但仅是探索性只读诊断**：它复现了 L4 锚点，并正确揭示 `marginal-call-pressure-probe` 是当前 L4 逐人数最差族的重要直接来源；单手配对、高方差与固定 `16` 个 seed 块也解释了读数离散度；
2. **不能据此修改或否定 v10 标准**：`-v10` 的 L4 是**读数前冻结、已计算且明确未达**，不是口径缺失或不可判定；`mixed-local@8` / `-v10` 仍维持「**质量未获支持**」，默认保持 `heuristic@1`；
3. **不能把 `58n` 分桶升级为因果结论**：分桶采用 `mixed-focus` 臂条件分类，且部分占比跨维度取分母；「显著为负」「极少数底池主导」等表述应**降调为描述性现象**——它**不能**直接证明某个桶、某个强牌场景或某个 probe 就是可修根因；
4. **暂不直接新开身份**：现有诊断仍未定位到可归因、可回归的具体机制；直接依 L4 的负差、某个桶均值或最差族来调常量，仍会回到**按结果调参**。

**本草案据此降调**：凡引用 `58n` 之处，只作**描述性现象**引用（「读数分布在此维度上如此」），**不作**「根因」「可修因」「主导机制」的表述。

## 2. 本轮唯一要回答的问题

> **未来的 L4（不劣化判据）应扮演什么角色？**

这个问题的**前置事实**（全部来自已落盘文档，不是新读数）：

- L4 在**连续两轮**独立验证中都被判**未满足**，且两轮的「t 区间」与「块极值」两口径**结论一致**（`docs/phase6/58b` §8、`58l` §8）；
- 两轮的 L4 配对单元都是**单手**，逐对 `bb_per_100` 是单手提纯，离散度达数千 bb/100 量级（`docs/phase6/57m` §4.2、`58n` §4.2）；
- `58n` §5.2 的**单块退出敏感性**显示：去掉任意一块、乃至去掉最差 `3` 块，块均值下界**仍未回到 −5 以上**（`58n` 为 `−118.77` / `−58.18`；上一轮同型结论见 `docs/phase6/57m` §5.2）；
- 四份既有签收 + 本次 `58m` 均为「质量未获支持」，即**从未**有任何一轮据 L4 或 L3 得出过「质量获支持」。

⇒ 这不是「某一次没通过」，而是「**该判据在当前引擎的方差结构下，几乎不可能给出通过侧的可判别信号**」这一**框架层**问题。因此问题不能只在「门槛数值」层面解决——**改数值属于 `docs/phase6/58f` 明令禁止的「读数后放宽」**，且**不得**用于 `-v10`。

## 3. 三条候选路线：内容与后果

### 3.1 路线 **甲**：L4 继续作为**阻断门**

| 项 | 内容 |
|---|---|
| 做法 | 保持现形态：逐人数各自取最差族、块均值双侧 t 区间下界 + 块极值两口径、门槛 `−5 BB/100`；任一未达即「质量未获支持」 |
| 后果 | 若引擎的方差结构不变，**后续身份大概率继续被判未满足**；默认策略将长期停在 `heuristic@1` |
| 代价 | 每轮仍需完整阶段 `B` + 补算（`-v10` 机械量：阶段 `B` 整调用 `wall 507.40 s` / 峰值 RSS `1201.00 MiB`、补算 `436.41 s` / `950.94 MiB`） |
| 风险 | 判据的**通过侧不可判别**会被误读成「产品不行」，而实际上它只说明**判据设计与该引擎方差不匹配**；反之也可能被误读为「只要多跑就能过」 |
| 需要的动作 | **零**（纯维持） |
| 不可越过的边界 | **不得**为让它通过而调门槛、换分母、删样本、按结果换 seed |

### 3.2 路线 **乙**：L4 降为**强度风险报告层**

| 项 | 内容 |
|---|---|
| 做法 | L4 的读数**继续计算、继续如实报告**，但**不再阻断**；阻断权交给未来的新判据体系（见 3.3）。L4 的定位改为「相对 `heuristic@1` 的非劣化**风险信号**」 |
| 后果 | 需要**同时**给出「那什么才算阻断」的替代安排，否则等于取消阻断；若替代安排尚未预注册，本路线**不可单独成立** |
| 代价 | 需要一份新预注册，说明取代性判据；`-v10` 的签收**不变** |
| 风险 | 若替代安排设计不严，会把「取消阻断」误读为「放宽标准」；必须明文声明**不是**放宽，而是**换框架**且**只对新战役生效** |
| 需要的动作 | 一份新预注册（`73a` 起） |
| 不可越过的边界 | **不得**把本路线说成对 `-v10` 的改写或对四份旧签收的反转 |

### 3.3 路线 **丙**：改为**新的预注册长期 / 分层 / 基线池框架**（**推荐**）

| 项 | 内容 |
|---|---|
| 做法 | 新开一套**只对未来新身份、新清单、新战役生效**的质量框架，至少包含三件：**(1) 长期**——判定单元从「单手」改为**预算内可重复的聚合单元**，并预注册每格手数与块数；**(2) 分层**——按人数 / 风格 / 对手族**分层预先指定**主判与次判，避免「逐人数取最差族」这种**极值统计**主导；**(3) 基线池**——不以单一 `heuristic@1` 为唯一基线，而是预注册一个**基线池**与其配对规则 |
| 后果 | L4 的角色由新框架决定（可仍作阻断项之一，但**统计量形态改变**）；`-v10` 与既有四份签收**完全不动** |
| 代价 | 需要**先设计、先预注册、再运行**；阶段 `B` 的手数或分块若增大，成本会上升，**可能触及既有包络**（`wall ≤1800 s` / 整调用峰值 RSS `≤1.5 GiB` / 输出 `≤100 MiB`）——若需要更大规模，**须另行裁定包络**，不得自行扩容 |
| 风险 | 设计本身可能引入新的选择自由度；因此**必须在任何读数之前冻结**，且要明确「哪些是预注册、哪些是事后披露」 |
| 需要的动作 | `73a`（框架规格）→ 预注册 → 后续实施/清单/运行各自单独授权 |
| 不可越过的边界 | **只对未来生效**；**不追溯**改写 `-v10`、v1–`-v9`、四份旧签收与 `docs/phase6/58f` 的任何取值 |

### 3.4 三路线对照

| 维度 | 甲 · 继续阻断 | 乙 · 降为报告层 | 丙 · 新预注册框架 |
|---|---|---|---|
| 对 `-v10` 的影响 | 无 | 无 | 无 |
| 是否改存量判据 | 否 | 否（新增取代性安排） | 否（新框架另立） |
| 是否需新预注册 | 否 | **是**（取代性判据） | **是**（完整框架） |
| 是否可能解除长期 `heuristic@1` 停滞 | 低 | 取决于取代安排 | **较高**（针对已识别的方差/极值问题设计） |
| 是否会被误读为「放宽」 | — | 风险较高 | 中等（可用「换框架 + 只对未来」界定） |
| 本轮是否需要改代码 | 否 | 否 | 否（设计阶段不改代码） |
| 成本 | 维持现状 | 维持现状 + 设计 | 设计 + 未来可能的更高运行成本 |

**推荐：路线 丙**（一句话理由：`58n` 已把问题定位到**统计形态**——单手配对、高方差、极值型「最差族」统计——而 甲 不动形态、乙 只换是否有阻断权，只有 丙 直接改形态，且它是三者中唯一能**在不碰任何存量取值**的前提下推进的路线）。

## 4. 三路线共同必须携带的边界（无论选哪条）

1. **不追溯**：新框架**只适用于未来的新身份、新清单、新战役**；**绝不**追溯改写 `-v10`、v1–`-v9`、四份既有签收（`docs/phase5/53c`、`docs/phase6/55g`、`56h`、`57k`）与 `docs/phase6/58m`；
2. **不改存量取值**：`docs/phase6/58f` 的门槛、机会分母、估值块、区间方法、两个机会域定义**全部不动**；
3. **先冻结再运行**：任何新框架必须在**产生任何读数之前**预注册（先冻结再运行的反作弊约束原样沿用）；
4. **不按结果调参**：不得依 L4 的负差、某个桶均值或某个最差族来调任何常量（用户判断第 4 条）；
5. **默认策略**：在**新框架下的新身份取得质量签收之前**，默认策略**保持 `heuristic@1`**；
6. **口径唯一化前置**：分桶派生结论在口径唯一化之前**不得**作为判定输入（`docs/phase6/58f` §10、`docs/phase6/57k` §16、`docs/phase6/58n` §10）；
