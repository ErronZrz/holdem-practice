## 4. 对 A 的准入条件（② 的前置）

### 4.1 硬约束（逐条保留）

1. **输入白名单**：不得输入候选或非候选身份读数、实测离散度、历史成本读数或历史机械量；输入只能来自冻结对象（块模板、片段划分、配对与重置口径、座位轮换、引擎规则给出的每手上界、层定义与配额、块内权重）。
2. **协方差处置**：必须对**片段内**与**块内**协方差作**显式处置**（给出界，或用结构性理由说明其为零 / 可被吸收）。
3. **产出与前沿**：必须在清单冻结前给出对**全部未来块**适用的**非退化统一上界** `V_max < M²`，以及与模板对应的 `V_j` 表达或分类上界。
4. **退化报告**：若只得到 `M²`，必须**报告退化**，**不得**称该路线满足。
5. **前提可核验**：结构前提须有**构造来源**与**可执行判据**；推导人**不得**兼任独立核验结论的签署人。
6. **核验时点**：形式、机械、前提三类核验均应在清单冻结前完成；**机械核验不得读取身份输出**。

### 4.2 三项修订（对上述条件的限定）

**4.2.1 A1 尚未成立，不得预先写成既有事实。** 现有协议只提供**块间**外生种子 `σ_j` 的独立构造；同一块内节点由同一偏移量向量与**确定性映射**生成，**未建立**节点独立，更**未建立**「方差随层内节点数下降」一类量级收紧。A1 只作**待推导候选路径**，其未来推导必须明确：抽样单位、概率空间与层内抽样机制；节点之间的独立、负相关、无放回有限总体或其他可用相关结构；与块内权重、分层配额、层间去重的关系；方差收紧的准确形式与适用范围。

**4.2.2 A2 尚未成立，不得把「条件零均值」直接等同于协方差消失。** 座位轮换与同一派生流**本身不自动**给出该结论。A2 只作**待推导候选路径**，其未来推导必须逐项给出：手序过滤及条件零均值的精确定义；配对臂、座位轮换与派生流如何导出该性质；重置口径与跨手随机流的关系；从该条件到协方差项消失的完整推导；片段间、片段内与块内协方差的分列处置。

**4.2.3 权重约束改为「明确适用类」。** 上界须**明确其适用的预注册权重类**：

- 若要在清单冻结前**直接用作** `V_max` 解算，则必须对该**已冻结权重类**一致成立；
- 若不做一致界，则权重必须**先于推导固定**，且**不得事后变更**。

不得把「任意预注册权重」当作已成立事实，也不得在权重未知时以「未来任意权重」的口号替代推导。

### 4.3 尚待推导项（② 的交付内容，本记录不实施）

对 A 的推导至少须交付：概率空间与抽样单位；逐块 `V_j` 与统一 `V_max` 的显式表达；片段内 / 片段间 / 块内协方差的分列处置；适用权重类；与 seed 及任何身份读数的独立性说明；每条结构前提的构造来源与可执行判据；以及「若退化到 `M²`」时的如实报告口径。

1. 资源 / 包络**不是**方差依据，也**不是**判据依据，且**不能**由更多块或扩容替代非退化方差 / 协方差依据。

3. 若解析上界无法给出，或无法支持既有包络，可**另行申请一次独立预注册的包络测量方案**。该方案必须先明确对象、代码版本、硬件 / 环境、命令、指标口径、采样方式、停止条件、记录方式及其**结论适用范围**。

5. 「留到最后」应理解为：**在统计路线与足以计算资源规模的规格草案形成后，且在身份、seed、节点与清单冻结前**处理。
