### 5.2 机制核实（机制分解 + 机制判断）

**三条可直接核对的机制事实**：

1. **合法主动候选一直存在**：`8` 个节点全部 `can_raise=True`，`max_raise_to=970`。⇒ `N ≥ 5` 的 `0.00%` **不是**夹具或合法集造成的，是**策略层**结果。
2. **价值质量全为 `0`**：这些节点的 `score` 在 `103–313` 之间，而翻牌的价值阈值经惩罚与深度调整后为 `675` 以上，`value_quality = max(0, score − 阈值 + 120) = 0`。
3. **非价值进攻质量恰为一张只有 `3` 个条目的对手数表**：`bluff_quality = _SEAT_COUNT_FOR_U.get(contenders, 0)`，表为 `{1: 12, 2: 6, 3: 3}`。`contenders` 是**未弃牌的对手数**（不含焦点座位），故 `N=2/3/4` 对应 `1/2/3`，**`N ≥ 5` 落空 ⇒ 取 `0`**。

**机制判断**：当价值质量与非价值进攻质量**同时为 `0`** 时，主动候选的权重为 `0`，策略只能从「弃牌 / 跟注 / 过牌」中选择。§5.1 的读数形态（`N=2/3/4` 的主动率之比 `≈ 4 : 2 : 1`，与表值 `12 : 6 : 3` 一致）与该解释**相互印证**；`N ≥ 5` 恰好落在表外的取值为 `0` 这一预测也随之成立。

### 5.4 风格顺序与人格语义不一致（机制分解）

在 `flop-draw-n2-iqv3`（`contenders=1`，故三风格的**非价值进攻质量相同**，均为 `12`）上取 `normal` 手模式：

| 风格 | 主动权重 | 弃牌权重 | 跟注权重 | 过牌权重 | 主动率（机制分解） |
|---|---|---|---|---|---|
| `tight` | `10,800` | `55,770` | `0` | `20,000` | `12.48%` |
| `aggressive` | `16,800` | `30,515` | `0` | `20,000` | `24.96%` |
| `calling` | `7,200` | `19,880` | `5,400` | `20,000` | `13.72%` |

**读数方向的核对**：工件上同节点的主动率为 `tight 16.23% < calling 22.08% < aggressive 35.43%`（三手模式平均）。两者量级与排序一致；**`calling` 的主动量比 `tight` 低 `33%`，主动率却更高**——因为风格参数同时进入**分母**（`fold_percent` `130 / 85 / 70`、`call_percent` `90 / 110 / 150`）。

**机制判断**：风格在主动分支上只通过 `aggression_percent`（`90 / 140 / 60`）这一**全局倍率**进入，而在被动分支上通过 `fold_percent` / `call_percent` 与翻后跟注偏移进入；两个方向可以相互抵消甚至反号。⇒ 三档的主动率差异**不是由主动分支本身的一阶设计决定的**。

## 6. 候选改动 A：非价值进攻依据的「对手数表」在多人桌完全失效

### 6.1 可复现的目标反例与局面分类

| 项 | 内容 |
|---|---|
| 局面分类 | 翻牌，焦点座位**面对下注**、持有听牌（`draw > 0`）、`contenders ≥ 4` |
| 反例 | `flop-draw-n5-iqv3` … `flop-draw-n9-iqv3`：三档风格、三种手模式下主动份额**恒为 `0.00%`**（§5.1） |
| 复算方式 | 读 `<v8>/runs/stage-b/mixed-validation-stage-B.json` 的 `behavior.nodes`，按 `node_id` 聚合 `action_units` 的 `bet`/`raise`（与 `docs/phase6/57k` §7 的域二口径一致） |
| 范围 | 同类反例另见 `turn-combo-draw`(N≥5)、`missed-draw-river`(N≥5)、`one-side-all-in`(N≥5)（§5.3） |

### 6.2 当前规则为何产生该行为

`bluff_quality = _SEAT_COUNT_FOR_U.get(contenders, 0)`，表为 `{1: 12, 2: 6, 3: 3}`，`contenders` = 未弃牌对手数。该表在 `contenders ≥ 4` 时**没有条目**，直接返回 `0`。同时该节点的价值质量也为 `0`（`score` 远低于调整后的价值阈值）。两者相乘决定主动权重 ⇒ 主动候选权重为 `0`。

即：当前规则隐含的行为约定是「**面对 4 名及以上对手时，永远不存在任何非价值的进攻依据**」，与牌力、位置、听牌质量、底池规模均无关。

### 6.3 拟调整的策略机制

把「非价值进攻依据」从**只有 3 个条目的对手数常量表**改成**由公开特征定义的连续量**，至少包含：

1. **对手数**：单调递减但**不在 4 人处归零**（例如随人数衰减到一个小正数而非 `0`）；
2. **位置**：越靠后越有依据（当前该处只在翻前被使用，翻后完全未用）；
3. **牌面纹理与听牌质量**：`draw` 的强度分档（当前只做 `draw > 0` 的布尔判断）；
4. **底池与有效筹码**：与危险尺度保护一致，避免把大尺度用在无依据处。

**必须同时声明的边界**：这不是「把 `3` 改成 `8`」这类常量替换。判据是「该量是否随公开特征**连续且可解释地**变化」，而不是「取值是否让读数好看」。本项**不得**以跨过 `10` 个百分点为目标；若设计只能通过调大一个常量来生效，则应判定为**不满足本规格的设计要求**。

### 6.4 预期改善的行为

- 多人桌翻后面对下注时，策略**重新具备**按牌力与局面做半诈唬 / 保护性加注的能力；
- 域二中 `N ≥ 5` 的 `5` 个节点从「三档恒为 `0`」变为「三档可分化」，使该域的总体差不再被 `5` 个恒定零节点稀释；
- 对 L3 第 1 项（覆盖率）可能同时产生正向变化。

|---|---|
| 局面分类 | 翻牌面对下注、`contenders = 1`（`flop-draw-n2-iqv3`）；三风格的**非价值进攻质量相同**（均为 `12`） |
| 反例 | 工件读数：`tight 16.23%` / `calling 22.08%` / `aggressive 35.43%`；机制分解：`calling` 的主动权重比 `tight` **低 `33%`**，主动率却**更高**（§5.4） |
| 为什么是反例 | 三档风格的设计意图是 `aggressive` 最具进攻性、`calling` 最被动；但在「主动量的差异已被拉大」的场合，**主动率的排序被被动分支的参数反转**，说明风格差异不是由主动分支自身决定的 |
| 复算方式 | 读同一节点的 `action_units` 按风格聚合；机制分解用 4.2 的确定性内存计算 |

### 7.2 当前规则为何产生该行为

主动率 = 主动权重 ÷（主动 + 弃牌 + 跟注 + 过牌）。风格在**分子**只通过 `aggression_percent`（`90 / 140 / 60`）这一全局倍率进入；在**分母**通过 `fold_percent`（`130 / 85 / 70`）、`call_percent`（`90 / 110 / 150`）以及翻后跟注偏移进入。两个方向相互抵消，特定节点上可反号。

### 7.3 拟调整的策略机制

让风格在**主动分支的准入条件**上做一阶分化，而不是只缩放主动权重。可选方向（**均属待裁定，不在本文件内定**）：

1. 风格在「价值 / 半诈唬」门槛上有**各自的偏移量**（类似翻前跟注偏移的做法，但作用于主动分支）；
2. 风格在**危险尺度保护**的准入分数上有各自的门槛（当前为全局 `850` / `550`）；
3. 风格在**候选过滤**上保留各自的偏好（当前 `size_preferences` 只影响份额，不影响准入）。

**必须同时声明**：三项都必须写成**随公开局面变化的机制**，不得退化为「给 `tight` 加 `−X`、给 `aggressive` 加 `+X`」的常量平移；后者属被禁止的「为跨阈值调常量」。

### 7.4 预期改善的行为

- 三档风格在主动分支上的差异**由主动分支自身的准入决定**，不再被被动分支参数反转；
- 域二中 `N=2/3/4` 的 `max − min`（`19.20 / 10.92 / 5.96` pp）有望在**不依赖分母巧合**的前提下扩大；
- 人格在「面对下注」这一高价值局面上的可感知性提升。

## 8. 候选改动 C（**暂缓**）：L4 的「强牌 × 无人下注 × 后街兑现」

**本项按 `docs/59` §5.2 / §6 阶段 A 的要求列为暂缓**：它目前**不具备**「可复现的目标反例」，因此**不构成**一个可实施候选。

### 8.1 现有可引用的证据（读数）

从观测工件按「焦点座位在手内**未面对**下注/加注」筛出的行为读数：

| 牌力档 | 主动占比 | 其中翻牌 / 转牌 / 河牌 |
|---|---|---|
| `strong` | `30.94%` | `26.77%` / `35.50%` / `45.03%` |
| `medium` | `18.08%` | `24.90%` / `22.34%` / `23.56%` |
| `weak` | `9.16%` | `16.67%` / `12.67%` / `8.04%` |
| `None` | `3.58%` | 仅翻前 |

（同口径下「有面对」的主动占比为 `strong 12.93%` / `medium 9.62%` / `weak 4.42%`。）

### 8.2 证据缺口

1. 上述排序是**单调**的（`weak < medium < strong`），因此**不能**据此声称「强牌兑现系统性不足」；
2. `docs/phase6/57m` §5 给出的 L4 落点（「无面对下注」占负差 `70.06%`、`strong` 档以 `5.57%` 对数占 `30.14%`）是**净筹码口径**，与 §8.1 的**动作口径**之间**缺少可复现的因果链**；
3. 现有工件层**没有**「牌力 × 街道 × 是否面对下注 × 人数」的四维桶化行为明细，无法把某个具体节点/局面钉成反例。

### 8.3 升级为候选的前置条件

必须先按 `docs/59` §5.2 补上**只读 / 开发期**的分层诊断能力（例如在观测层记录焦点座位的牌力档与街道，并按上述四维桶化），且该能力**只读取行动者可见信息**、**不得**成为线上策略读取隐藏信息的通道。补齐之后，本项才可按下述六项要求重新提交。

## 9. 可行域与算术披露（**不承诺达标**）

在**冻结的域二定义**下（`8` 节点等权平均，其中 `N ≥ 5` 的 `5` 个节点当前三档恒为 `0`），判据要把「至少两对风格」的总体差推到 `≥10` pp，取决于两件事是否**同时**成立：

1. 候选 A 使 `N ≥ 5` 的节点获得**非零且可分化**的主动份额（从而不再提供恒 `0` 的恒定项）；
2. 候选 B 使三档在主动分支上的差异由**主动分支自身**决定。

**算术披露（仅作后果说明，不是设计目标）**：`N=2/3/4` 三个节点的现有 `max − min` 为 `19.20 / 10.92 / 5.96` pp，平均 `12.03` pp；若 `8` 个节点都具备相近的每节点差异，总体差将接近 `12` pp。按现有每节点数据，三对风格的节点平均差分别约为 `t-a 12.03` pp、`a-c 7.59` pp、`t-c 4.43` pp，即 `t-a` 已在 `10` pp 之上，而 `t-c` 需要显著扩大。

**必须声明**：以上只是**算术后果**，**不得**作为设计目标；`docs/59` §5.3 末段与 `docs/phase6/57k` §7 的纪律不变——**不得**以跨过阈值反推改动。
