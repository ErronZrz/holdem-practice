## 6. 诊断结论（证据面，不作质量裁定）

以下只陈述「证据指向什么」，**不构成**对任何判据的修改建议：

1. **L4 的配对单元是单手**，逐对 `bb_per_100` 为单手提纯（标准差 `7,365.40`，极值达 `±80,100`）。因此 L4 的块均值与区间由极少数大额底池主导。
2. **约三分之二的配对逐手同结果**（`64.26%`），且本轮**净值近乎完全对冲**：`−12,866` 仅为绝对差之和的约 `0.04%`（上一轮为 `15.7%` 残差，**形态不同但不可比较**）。
3. **负差同时表现为两种集中**：
   - **块级集中**：最差 `3 / 16` 块占全部负块合计的 `70.52%`；但**任何单块退出都不足以**把下界抬回 `−5` 以上（最好情形仍为 `−118.77`，去掉最差 `3` 块后仍为 `−58.18`）；
   - **族级集中**：`marginal-call-pressure-probe` 一族独占约 `75.77%` 的负侧合计，且在 `8` 个人数上**全为负**，并在 `5` 个人数上成为**最差族**——这正是 L4 绑定统计（逐人数取最差族）被判未满足的直接机制。
4. **格级分散**：`192` 个格子中 `115` 个为负；最大单格仅占负格合计的 `5.21%`，前 `12` 负格合计占 `35.47%` ⇒ **不存在单一主导格**（分母为负格合计，见 §5.7）。
5. **桶层面**：最大单一负桶是 **`strong` 牌力档**（`908` 对 / `−138,903`）；`≤50%` 尺度档单手均值差最负；`flop` 街为唯一显著为负的街道桶；`>100%` 尺度档与 `medium` 牌力档为**正**。
6. **符号不一致是普遍现象**：人数、风格（`calling` / `aggressive` 翻转）、对手族（仅 `marginal-call-pressure-probe` 无翻转）以及 `7 / 8` 个族的人数切片均出现翻转；`tight` 是唯一在 `8` 个人数上全负的风格。
7. **族集在 `N ≥ 6` 上实际只有 `7` 种行为**（§5.9），因此「`8` 族」上的任何聚合读数在 `N ≥ 6` 上并非 `8` 个独立行为。

**证据面的净判断**：本轮的 L4 未满足**有一个可指向的结构性来源**——`marginal-call-pressure-probe` 这一族（叠加「逐人数取最差族」的绑定统计）。**但**该来源**不是**可轻易修复的「格子」问题：同一族的负差在该族内部各人数、各风格上广泛分布，且单体量由极少数大额底池（`strong` 档、单手标准差 `7,365`）驱动。因此：

- 在既有冻结集合上，**能指向一族**，但**无法**把负差归因到该族内的少数具体机制格；
- 本诊断**不能**回答「换新身份或新样本集后 L4 是否会满足」——第八版与任何新身份的 L4 表现仍**在样本外**。

**不得**由本节推出「L4 判据有误」「应改判据」「应删该族」或「已证明是噪声」：本文件不重算判据、不重设区间、不重选估值块；判定与签收以 `docs/phase6/58l` / `58m` 为准，**未被触碰**。
