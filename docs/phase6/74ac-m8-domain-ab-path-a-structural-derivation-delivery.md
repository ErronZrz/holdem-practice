## 4. 块级对象与估计量（模板级，非读数）

### 4.1 节点级量（引用 AB-0，已锁定）

对 `n ∈ U_AB`（`74ab` §4.1）：

```text
域 A：  y_A(n) := q_candidate(i, n) − q_candidate(i′, n)     （§74ab §6.2；主判 marginalized）
域 B：  y_B(n) := Q_candidate(b*, n) − Q_baseline(b*, n)   （§74ab §5.5；主判 marginalized）
```

在 `74ab` 主判口径下，各节点 `y(n) ∈ [−1, 1]`（AB-0 节点支路）。**本交付不**代入任何 `q` 或 `Q` 的实测值。

### 4.2 层内均值与块级量（结构定义）

对块 `j`、主判层 `ℓ ∈ L*`：

```text
ȳ_{j,ℓ} := (1 / n_ℓ) · Σ_{n ∈ S_{j,ℓ}} y(n)
```

其中 `S_{j,ℓ} ⊆ P_ℓ` 为块 `j` 在层 `ℓ` 的节点样本（**设计层**对象；其随机性来源见 §5.2），`y(n)` 为 `y_A(n)` 或 `y_B(n)` 按 `domain` 取值。

块级统计量（W-1 单点权重 `v`，`74ab` §10）：

```text
X_j^{AB} := Σ_{ℓ ∈ L*} v_ℓ · ȳ_{j,ℓ} ，  Σ_ℓ v_ℓ = 1 ， v_ℓ ≥ 0
V_j^{AB} := Var(X_j^{AB})                              （单块理论方差，给定联合分布）
```

**登记**：`X_j^{AB}` 是**配对比较设计下**、在分布观测契约与 `74ab` 快照上的块级层加权均值；**不是**筹码 EV、**不是** exploitability，**不是**任何运行器已输出的确认量。

## 7. AB-0 支持界与层内方差骨架（静态）

### 7.1 逐节点与逐层界（已锁定，代数推出）

自 `74ab` §8.2：对每个 `ℓ`，`N_ℓ = P_ℓ` 上各节点 `[a_n,b_n] = [−1,1]` ⇒ `[a_ℓ,b_ℓ] = [−1,1]`，`R_ℓ := b_ℓ − a_ℓ = 2`。

**AB-0 在战役层**：随 `74ab` 版本 `1` 审查生效而**建立**（支持界由定义推出，**不**读样本）。

### 7.2 朴素块界 `M_AB(v)`

自 `74ab` §8.3：

```text
M_AB(v)² := ( Σ_{ℓ ∈ L*} v_ℓ · R_ℓ )² / 4
```

在 W-b 单点 `v`（§8）下：`R_ℓ ≡ 2` ⇒ `M_AB(v) = 1`（**恒等式**，非实测）。

### 7.3 层内方差（全枚举层 vs 将来抽样层）

**（A）本版全部层：`n_ℓ = M_ℓ`（§6.4）**

对固定块 `j`、层 `ℓ`，`T_AB` 规定 `S_{j,ℓ} = P_ℓ` 为 `P_ℓ` 上**唯一**的 `M_ℓ` 元子集。故

```text
ȳ_{j,ℓ} = (1 / M_ℓ) · Σ_{n ∈ P_ℓ} y(n)
```

在层抽样随机性下为**确定量**（给定各 `y(n)` 的分布则 `ȳ_{j,ℓ}` 的随机性仅来自节点级量本身，**无**层内子集抽样波动）⇒

```text
Var(ȳ_{j,ℓ}) = 0     （全枚举唯一子集；② 结构推论）
```

**特别地 `L-A-FL`**（`M_ℓ = 1`）：子集为单点 `{A-003}`，**不得**使用

```text
c_ℓ := (M_ℓ − n_ℓ) / (M_ℓ − 1)
```

该式在 `M_ℓ = 1` 时为 `0/0` **无定义**；方差为零的理由是**全集（此处为单点）均值确定**，而非 `c_ℓ = 0`。

**（B）将来 `L_s` 中、`M_ℓ > 1` 且 `n_ℓ < M_ℓ` 的层（本版无）**

在 AB-1′ 的随机抽样路径成立时，方差上界沿用 `74g` §5.3／`74i`：

```text
Var(ȳ_{j,ℓ}) ≤ c_ℓ · R_ℓ² / (4 n_ℓ) ，  c_ℓ := (M_ℓ − n_ℓ) / (M_ℓ − 1)   （仅 ℓ ∈ L_s ，M_ℓ > 1）
```

`c_ℓ` **不**用于本版 `n_ℓ = M_ℓ` 的全枚举层。

### 7.4 层间协方差（通用路线，不采用 AB-2z）

`74i` 通用形式对任意层间相关结构给出 Cauchy–Schwarz 交叉项界，**不**要求 AB-2z（层间零协方差）。在 AB-0、本版 AB-1′（规格层，§9.1）、W-1 单点 `v` 下：

```text
V_j^{AB} ≤ V_max^{AB}(v)     （见 §8；定义见 74i §5.3）
```

**不**采用 `V_max^{AB,0}(v)` 收紧路径。

### 8.1 W-1／W-b（已锁定）
