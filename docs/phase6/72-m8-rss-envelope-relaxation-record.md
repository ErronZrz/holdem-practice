## 4. 与冻结清单文本的差异（必须如实披露）

```text
阶段 A：wall/CPU 各不超过 120 秒，单进程 RSS ≤ 1073741824 字节
阶段 A+B：累计 wall/CPU 各不超过 1800 秒，RSS ≤ 1073741824 字节，保留文件 ≤ 104857600 字节，单 CPU 进程、不并行
```

- 该清单是**冻结产物**（`J2` 已落盘，冻结后**不得**按任何事后决定修改），因此**其文本保持原样**，`sha256` 仍为 `499258c9…`；
