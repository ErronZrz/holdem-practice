`73e` 已登记：在既定包络下，`R2 + V_max,N = M_N²` 这一保守路径的块数由解析式唯一确定，其可行性问题位于框架级，继续逐项填充剩余冻结项不能消除阻断，因此该路径不能作为当前 `73b` 的可冻结路线。
