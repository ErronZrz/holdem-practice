## 2. 分布观测

第九版的无输入健康读取为可用。第九版声明与现行支持声明一致。`125` 个节点都返回合并口径，定点单位总和失败数为 `0`。

与第八版逐节点比较候选单位：`24` 个节点不同，其余 `101` 个相同。不同的节点恰好是三类各 `8` 个：翻牌面对下注、顶对弱踢脚、转牌组合听牌。这与第九版只改「面对下注的听牌延续」和「无人下注的成牌兑现」相符，但节点差异本身不是质量结论。

## 3. 翻牌面对下注的三风格主动率

口径：主动动作是下注与加注；先把同一节点上各手模式的单位相加，再对节点等权平均。四个主种子上的逐节点单位完全相同，所以重复种子不改变份额。下表百分数四舍五入到两位；是否达到 `10` 个百分点由未四舍五入的差值决定。

| 风格 | 第八版主动率 | 第九版主动率 |
|---|---:|---:|
| 紧手 | 4.36% | 16.19% |
| 跟注 | 12.54% | 27.97% |
| 进攻 | 26.34% | 43.36% |

| 风格对 | 第八版差距（百分点） | 第九版差距（百分点） |
|---|---:|---:|
| 紧手 − 进攻 | −21.98 | −27.17 |
| 紧手 − 跟注 | −8.18 | −11.79 |
| 进攻 − 跟注 | 13.80 | 15.39 |
| 绝对值达到 10 的配对数 | 2 | 3 |

同一函数给出的翻前未开池进池率，第八版与第九版逐项相同：紧手 `35.93%`、进攻 `72.90%`、跟注 `90.78%`。三对差距的绝对值都大于 `10` 个百分点。第九版没有改动这条翻前读数。

这组数字说明：在**这套首配方的 8 个翻牌面对下注节点**上，第九版把三对主动率差距都推过了参照用的 `10` 个百分点，第八版还差紧手与跟注这一对。它**不是**对已公布历史域二读数的复算，**不是**独立验证通过。
