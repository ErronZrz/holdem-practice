## 3. 阻断一：域 C 的方差推导（修正后的条件性推导）

### 3.1 裁定要求

`74g` §4.4 以单一 `γ_0` 表示全部手的方差，隐含二阶平稳同方差；该前提未提出、未建立。庄位轮换、位置与状态构成可使 `Var(e_h)` 随 `h` 改变。须改为不引入平稳性的写法，且片段间零协方差须明确来自「不同片段全部手级随机量之间零协方差」。

### 3.2 对象（沿用 `74g` §4.1，`d_h` 仍未定义，见 §4.3）

```text
每手规范化值      e_h := 100 · d_h / BB
片段 f            块内手的子集，K_f := |f| ≥ 1
片段统计量        Δ_f = (1 / K_f) · Σ_{h ∈ f} e_h
块级量            X_j = Σ_f w_f · Δ_f ，  w_f ≥ 0 ， Σ_f w_f = 1
```

### 3.3 修正后的前提（全部未建立）

| 前提 | 内容 | 说明 |
|---|---|---|
| **C-1′** | 对块内每一手 `h`：`|e_h| ≤ E` | 由 Popoviciu 得逐手 `Var(e_h) ≤ (2E)² / 4 = E²`；**不要求**各手方差相同 |
| **C-2′** | 对块内任意两手 `h ≠ h'`：`Cov(e_h, e_{h'}) = 0` | 覆盖同一片段内与不同片段间的全部手对；其结构性来源见 §4，当前**未建立** |
| **F-0** | 块内各片段两两不相交 | 块模板性质；若片段重叠，则 `Cov(Δ_f, Δ_{f'})` 含 `Σ_{h ∈ f ∩ f'} Var(e_h)` 项，本节界不成立 |

**不引入**：二阶平稳性、同方差、条件零均值、任何手序过滤性质。

### 3.4 推导

```text
片段内（不使用平稳性）：
  Var(Δ_f) = (1 / K_f²) · [ Σ_{h ∈ f} Var(e_h) + Σ_{h ≠ h' ∈ f} Cov(e_h, e_{h'}) ]
  由 C-2′：   第二项 = 0
  由 C-1′：   Σ_{h ∈ f} Var(e_h) ≤ K_f · E²
  ⇒ Var(Δ_f) = (1 / K_f²) · Σ_{h ∈ f} Var(e_h) ≤ E² / K_f

片段间（f ≠ f'）：
  Cov(Δ_f, Δ_{f'}) = (1 / (K_f · K_{f'})) · Σ_{h ∈ f} Σ_{h' ∈ f'} Cov(e_h, e_{h'})
  由 F-0：    h 与 h' 恒为不同手
  由 C-2′：   每一项 = 0  ⇒  Cov(Δ_f, Δ_{f'}) = 0

块内：
  V_j = Var(X_j) = Σ_f w_f² · Var(Δ_f) ≤ E² · Σ_f w_f² / K_f
```

### 3.5 统一上界、适用权重类与非退化性

```text
对任意 w_f ≥ 0 、Σ_f w_f = 1：
  Σ_f w_f² / K_f ≤ (1 / K_min) · Σ_f w_f² ≤ 1 / K_min ，  K_min := min_f K_f
⇒ V_max^C := E² / K_min ，  V_j ≤ V_max^C
```

- **适用权重类**：全部非负、和为 `1` 的片段权重（`K_f` 与片段划分由块模板给定）。
- **对照对象（本记录内定义）**：由 C-1′，每个 `Δ_f` 与 `X_j` 均取值于 `[−E, E]`，故块级支持含于 `[−E, E]`，分布无关朴素界为 `M_C² := (2E)² / 4 = E²`。本记录的非退化比较只针对该 `M_C²`；`74g` §4.2 所称与 `73d` §2.1 `M_N` 的数值对应关系**未在本记录复核**，不作为本节依据。
- **非退化性（条件性）**：`V_max^C / M_C² = 1 / K_min`；当且仅当 `K_min ≥ 2` 时严格小于 `1`。`K_min = 1` 时本界即退化，须如实报告。
- **失效处置**：C-1′、C-2′、F-0 任一不成立 ⇒ 本节界不成立，回退 `M_C²` 并报告退化，或另行给出非退化界。

## 4. 阻断二：C-2 的构造来源（只登记要求与候选路径）

### 4.1 裁定要求（照录要点）

- 「块种子 ＋ 手号 → 摘要 → 每手种子」只能消除**推进状态**，不能建立**概率独立**：共同块种子的不同确定函数仍是同一随机变量的函数，静态检查无法把它转化为独立性证明。
- 须定义每手完整随机向量 `Z_h`，并结构性地给出不同 `h` 间独立或至少两两零协方差的来源。
- PRF / 摘要输出「近似独立」属于**显式模型假设**，转入待单独裁定的 **B 类**路径，不作为 A 类结构性依据。
- C-2b（推进流近似独立的建模理想化）**不得**作为 A 路径的可选实现形式，最多是未来 B 类申请的候选内容。
- `d_h` 的配对口径未定义，C-1、C-2 的随机对象不完整，因此不能进入 ③。

### 4.2 对 `74g` 的更正登记

1. `74g` §4.3 把 C-2a 的可执行判据写为「每手播种点的静态检查」。**更正**：该静态检查只能判定「无跨手推进状态」，**不能**判定手间独立或零协方差；在共同块种子下，它**不构成** C-2 的构造来源。
2. `74g` §4.3 把 C-2b 列为 A 路径的两条可选实现之一。**更正**：C-2b **移出** A 路径；若未来提出，只能作为 B 类显式模型申请的候选内容，按 `74f` §3.1 另行裁定。
3. 基于 PRF / 摘要函数「输出近似独立」的论证**移出** A 路径，归入 B 类候选，不自动获准。

### 4.3 待定义对象（设计裁定须写定，本记录不写定）

- **配对口径 `d_h`**：两臂在同一 deal、同一座位指派下的净筹码差；须精确写定「同一 deal」的含义（牌序或其等价随机部分如何在两臂间共享）、座位指派与庄位的确定方式、哪一臂为 `m_h` / `b_h`、每手重置口径，以及人数 `N` 下被测座位的定义。
- **每手完整随机向量 `Z_h`**：至少含
  - 同一 deal 两臂共享的随机部分（牌序或其生成量）；
  - 各臂的行动随机部分；
  - 各臂的手模式随机部分；
  - 其他任何影响 `d_h` 的随机量。
- **每手取值函数**：须写明 `e_h = g_h(Z_h)`，其中 `g_h` 只依赖本手随机向量与手号的确定量（如庄位），**不**依赖其他手的随机量或跨手状态。该性质本身需要构造来源（每手重置、策略无跨手状态、引擎无跨手推进随机状态）与可执行判据。

### 4.4 C-2′ 所需来源的登记

- **充分来源（登记，不选定）**：若 `e_h = g_h(Z_h)` 成立，且 `{Z_h}` 在不同 `h` 间**两两独立**，则 `Cov(e_h, e_{h'}) = 0`，即 C-2′ 成立。
- **补充登记**：若只得到 `Z_h` 各分量之间的两两**零协方差**而非两两独立，一般**推不出** `e_h` 的零协方差（`g_h` 为非线性函数）。因此设计裁定须说明：所给来源是两两独立，还是直接针对 `e_h` 的零协方差结构；后者须另给完整推导。
- **候选结构性来源（并列，不选定）**：
  1. 每手随机向量由相互独立的外生抽取直接给出（每手一组外生随机种子向量，互不派生于共同种子）；
  2. 明确、可证明的两两独立随机家族（须给出家族定义与两两独立的证明）。
- **不构成 A 类来源**：共同块种子的确定派生；单条推进流；PRF / 摘要「近似独立」。

### 4.5 当前状态

只读事实（裁定方与 `74g` §2 一致）：引擎构造时创建单个随机源，每手仅洗牌、不重播种；策略侧的手模式与行动随机量按手号 / 事件号派生。该事实支持「C-2 当前未建立」的登记，**不**支持手间独立。C-2′ 与 `e_h = g_h(Z_h)` 均**未建立**。

## 5. 阻断三：层间去重对抽样分布的影响（只登记要求与候选路径）

### 5.1 裁定要求（照录要点）

既有节点协议（`73b` 第 770–783 行，历史引用）按层优先序处理各层，低优先层跳过已被高优先层接受的节点并沿同一固定序列补足配额。因此，即使各层偏移量在输入端独立，去重后的 `S_{j,ℓ}`：

- 可能不再是该层总体上的均匀无放回样本；
- 可能与高优先层样本相关；
- 不能由「层驱动独立」直接推出层间协方差为零。

### 5.2 对 `74g` 的更正登记

1. `74g` §5.4 的 AB-2「各层抽样由相互独立的随机量驱动 ⇒ 层间协方差为 `0`」。**更正**：存在跨层去重 / 补足时，低优先层的接受集合是**高优先层偏移量与本层偏移量的联合函数**，输入端独立**不能**推出输出端独立或零协方差；AB-2 的原表述不足以支撑零协方差结论。
2. `74g` §5.2 AB-1 的可执行判据「逐点验证每个合格 `n_ℓ` 子集被抽到的次数相同」。**更正**：该判据只涉及**单层边缘分布**，即使通过也**不能**证明层间协方差为零；且在存在去重时，「该层合格总体」的含义须先写定。
3. `74g` §5.2 已登记：循环移位映射 ＋ 取前 `n_ℓ` 个**不保证**均匀无放回；本记录维持该登记。

## 6. 阻断四：A/B 对照对象的定义（修正后的条件性推导）

### 6.1 裁定要求

`74g` §5.5 只证明了相对 `R_max² / 4` 的收紧；该量未与块级 `X_j` 的整体取值范围对应，故「`n_ℓ ≥ 2` 即严格小于 `M²`」无完整定义支撑。须定义块级支持区间 `[A, B]` 与 `M_AB² = (B − A)² / 4`，证明 `V_max^{AB} < M_AB²`，补齐 `1 ≤ n_ℓ ≤ M_ℓ`、`M_ℓ > 1`，并单列 `n_ℓ = M_ℓ`。

### 6.2 对象与取值条件

```text
主判层集合        L*：进入主判量的层；要求其中每层 1 ≤ n_ℓ ≤ M_ℓ（n_ℓ = 0 的层不进入 L*）
层内取值          y ∈ [a_ℓ, b_ℓ] ，  R_ℓ := b_ℓ − a_ℓ ≥ 0
层内均值          ȳ_{j,ℓ} = (1 / n_ℓ) · Σ_{i ∈ S_{j,ℓ}} y_i
块级量            X_j = Σ_{ℓ ∈ L*} v_ℓ · ȳ_{j,ℓ} ，  v_ℓ ≥ 0 ， Σ_ℓ v_ℓ = 1
```

- `[a_ℓ, b_ℓ]` 须由规则或枚举取值域给出，**不**读取任何身份输出；本记录不冻结任何界值。
- 层分类（仅依模板量）：
  - **抽样层** `L_s := {ℓ ∈ L* : n_ℓ < M_ℓ}`，此时必有 `M_ℓ ≥ 2`；
  - **全体枚举层** `L_e := {ℓ ∈ L* : n_ℓ = M_ℓ}`：`S_{j,ℓ} = P_ℓ` 为确定集合，`ȳ_{j,ℓ}` 为常数，`Var(ȳ_{j,ℓ}) = 0`，且与任何量的协方差为 `0`；该情形**不使用**有限总体方差公式（`M_ℓ = 1` 时公式分母为零，必须按此单列）。

### 6.3 块级支持区间与对照对象

```text
A(v) := Σ_ℓ v_ℓ · a_ℓ ，  B(v) := Σ_ℓ v_ℓ · b_ℓ
⇒ 对任一实现，X_j ∈ [A(v), B(v)]
M_AB(v)² := (B(v) − A(v))² / 4 = (Σ_ℓ v_ℓ · R_ℓ)² / 4
```

- **定义地位**：`[A(v), B(v)]` 是由各层取值界导出的**块级包含区间**，`M_AB(v)²` 是在该区间上的分布无关朴素界。它是本记录为 A/B 主判量定义的非退化对照对象。
- **限定**：实际可达支持可能严格小于 `[A(v), B(v)]`（例如某层取极值的节点少于 `n_ℓ`）。本记录的「非退化」只相对 `M_AB(v)²` 陈述；若后续裁定要求以精确支持或既有登记的 `M` 为对照，须另行推导。本记录**不**作 `M_AB` 与 `73b` / `73d` 既有 `M` 的比较。
- `M_AB(v) = 0`（全部正权层 `R_ℓ = 0`）时 `X_j` 为常数，单列为平凡情形，不作非退化主张。

### 6.4 推导（在 AB-1′ 与 AB-2′ 下）

```text
层内（ℓ ∈ L_s，AB-1′ ＋ Popoviciu）：
  Var(ȳ_{j,ℓ}) = (σ_ℓ² / n_ℓ) · c_ℓ ，  c_ℓ := (M_ℓ − n_ℓ) / (M_ℓ − 1) ∈ (0, 1]（n_ℓ = 1 时为 1）
  σ_ℓ² ≤ R_ℓ² / 4
  ⇒ Var(ȳ_{j,ℓ}) ≤ c_ℓ · R_ℓ² / (4 n_ℓ)
层内（ℓ ∈ L_e）：
  Var(ȳ_{j,ℓ}) = 0
层间（AB-2′，零协方差情形）：
  V_j = Σ_{ℓ ∈ L_s} v_ℓ² · Var(ȳ_{j,ℓ}) ≤ Σ_{ℓ ∈ L_s} v_ℓ² · c_ℓ · R_ℓ² / (4 n_ℓ)
```

绝对统一上界（对全部非负、和为 `1` 的权重）：

```text
V_j ≤ max_{ℓ ∈ L_s} [ c_ℓ · R_ℓ² / (4 n_ℓ) ] · Σ_ℓ v_ℓ² ≤ V_max^{AB} := max_{ℓ ∈ L_s} [ c_ℓ · R_ℓ² / (4 n_ℓ) ]
（L_s 为空时 V_max^{AB} := 0）
```

相对对照对象的比较（对每一个权重向量 `v`）：

```text
记 n_s := min_{ℓ ∈ L_s} n_ℓ 。由 c_ℓ ≤ 1、n_ℓ ≥ n_s 及 v_ℓ R_ℓ ≥ 0（交叉项非负）：
  V_j ≤ (1 / n_s) · Σ_{ℓ} v_ℓ² R_ℓ² / 4 ≤ (1 / n_s) · (Σ_ℓ v_ℓ R_ℓ)² / 4 = M_AB(v)² / n_s
```

### 6.5 非退化条件（条件性）

- 若 `M_AB(v) > 0` 且 `L_s` 为空：`V_j = 0 < M_AB(v)²`。
- 若 `M_AB(v) > 0` 且 `n_s ≥ 2`：`V_j ≤ M_AB(v)² / n_s < M_AB(v)²`，收紧倍数不小于 `n_s`，且对全部非负、和为 `1` 的权重一致成立。
- 若 `n_s = 1`：本节**不**主张严格非退化（可能在特定权重下仍严格，但须另行推导）。
- 若 `M_AB(v) = 0`：平凡情形，见 §6.3。
- **失效处置**：AB-1′ 或 AB-2′ 不成立，或层间协方差无法以非退化方式给出 ⇒ 本节界不成立，回退 `M_AB(v)²` 并报告退化，或另行给出非退化界。
