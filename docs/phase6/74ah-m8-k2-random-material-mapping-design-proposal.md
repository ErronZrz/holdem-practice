## 2. 承接的约束与链（只读复述，非新裁定）

### 2.1 K-2 约束（`74k` §5）

```text
「其他座位共用随机材料」须定义为固定的、按座位与可能决策键索引的随机材料映射，
而非依赖某一条可变推进随机源的「相同初始 seed」。
两臂历史分叉时，不得把「相同初始 seed」表述为逐决策随机取值必然相同。
```

### 2.2 只读实现冲突（`74k` §7.1）

| 基线成员类型（**未选定**，见 §3） | 与 K-2 关系 |
|---|---|
| 混合策略类：行动随机量按 `(座位键, 手号, 事件数)` 主键固定派生 | 若 K-1 将来裁定为该类成员，K-2 **可能**由「注入该座位该手主键」满足；决策键候选常为 `(手号, 事件数)` 或含座位维 |
| 启发式类：构造时播种随机源，手内多决策**持续推进**（胜率与动作共用） | 若 K-1 将来裁定为该类成员，**仅**每手新建实例并注入**一个**种子 **不能**满足 K-2 |

默认策略登记仍为 `heuristic@1`（`74k` §10）；**本文不**据此预选 K-1。

## 4. 跨路径共用的裁定字段（并列备选，本文不选择）

下列字段在正式 K-2 裁定中**至少**须写定其一整套；不同 K2-P-* 对同一字段的可选答案不同。

### 4.1 决策键（decision key）

| 备选维度 | 说明 | 典型关联路径 |
|---|---|---|
| **D-evt** | `(hand_ordinal, event_index)`，`event_index` 为手内决策事件单调序号 | K2-P-i；混合策略对齐 |
| **D-seat-evt** | `(seat, hand_ordinal, event_index)` | 多非被测座并行决策 |
| **D-state-evt** | 在 D-evt 上增加**可机械复现**的公开状态摘要（如街次、底池档位哈希） | 分叉后同 `(hand, event_index)` 出现于不同信息集 |

### 4.2 历史分叉后「同键」规则

| 规则 ID | 内容摘要 | 后果 |
|---|---|---|
| **F-monotonic** | 手内 `event_index` 严格单调；**禁止**在不同公开状态下复用同一 `(hand, event_index)` | 键空间手内唯一 |
| **F-stateful** | 键含公开状态摘要；两臂在**相同**公开状态序列下索引相同材料 | 状态摘要须可审计、可复现 |
| **F-no-cross-arm** | 材料映射对两臂**同键同值**；分叉后若公开状态不同则键必不同 | 与 K-2「固定映射」一致 |
| **F-relax-ii** | **不**主张逐决策跨臂共享；仅手级／座级初始材料共享（K2-P-ii） | 须同步弱化 K-2 正文 |

## 5. K2-P-i：每决策新建实例并注入「座位 + 决策键」材料

### 5.1 路径摘要

- **不改**策略源码（相对 `74k` 候选 (i)）；通过**包外／运行层**供给协议，使每次决策（或每次策略实例生命周期）获得与决策键绑定的材料。
- 与 **P-a** 兼容：仍可为「每手每臂每座新建实例」，但实例寿命可缩短为**单决策**。

### 5.2 决策键（本路径下的待裁定写法，不选择）

| 写法 | 说明 |
|---|---|
| **Ki-D-evt** | `(hand_ordinal, event_index)` + 固定 `seat` 维用于 `non_probed` |
| **Ki-D-state-evt** | 在 Ki-D-evt 上增加 §4.2 **F-stateful** 要求的状态摘要 |
| **Ki-L3-bind** | 决策键与 L-3 用途标签一一对应（如 `non_probed_decision_{seat}_{k}`） |

### 5.3 历史分叉同键规则（本路径下的待裁定写法）

- 默认倾向 **F-monotonic** + **F-no-cross-arm**：两臂在相同公开决策位置使用 L-3 预生成的**同一**材料元组分量。
- 若公开状态分支导致「同一 event_index 不同含义」，须采用 **Ki-D-state-evt** 或提高 `event_index` 粒度；**禁止**静默复用键。

### 5.4 依赖

| 依赖 | 关系 |
|---|---|
| **K-1** | 须知基线成员类型：混合策略易对齐主键派生；启发式须**每决策**新实例 + 新材料，**不能**仅手级 seed |
| **K-3** | 手间 `Z_h` 独立不变；决策级材料须包含在**该手** `Z_h` 的生成义务内或由其确定派生 |
| **L-3** | 须扩展用途／键以承载决策级 `non_probed` 材料（可能增加 `74r` L-3 版本） |
| **K-4** | 高：供给协议与实例化口径变更 |
| **R-V1**（`74ag`） | 包外编排须能按裁定键注入；`verification` 不推进 |
| **R-K2 实现链** | `74k` §9 第 2 步；非本文件 |

### 5.5 架构边界与越界风险

- 在 `verification` 内实现决策循环 ⇒ 违反不可执行边界。
- 用「相同初始 seed」冒充 Ki ⇒ **违反 K-2**。
- 未扩展 L-3 却声称 Ki 已满足 ⇒ C-2′ 链形式不闭合。

### 5.6 身份影响（候选级）

- 策略**注册标识**可不变；**执行身份**／`code_identity` 须纳入：决策级材料生成、实例化频率、包外编排入口。
- 若基线为 `heuristic@1`，Ki 改变**随机消费路径**；须 K-4 审查，**不**由本文断定是否触发新参考版本。

### 5.7 失效／重核验影响（若将来采纳本路径）

| 事件 | 后果（`74ae` §9.1 口径） |
|---|---|

## 6. K2-P-ii：放弃逐决策跨臂共享，弱化 K-2 表述

### 6.1 路径摘要

- 只保证每手每非被测座（或每手全局）**初始**材料在双臂间共享；**不**主张分叉后逐决策取值相同。
- `74k` §7.1：C-2′ 方差界**不依赖**跨臂逐决策共享，只影响紧度。

### 6.2 决策键与同键规则（本路径）

| 写法 | 说明 |
|---|---|
| **Kii-D-hand-only** | 键为 `(seat, hand_ordinal)` 或每手单列 `non_probed_seed_seat_s` |
| **Kii-F-relax** | 采用 §4.2 **F-relax-ii**；K-2 正文须改为「不主张逐决策共享」 |

### 6.3 历史分叉

- 两臂行动序列分叉后，**允许**非被测座策略随机流分歧；须在运行记录中**显式登记**该弱化语义，避免与现行 K-2 条文（`74k` §5）逐字冲突。

### 6.4 依赖

| 依赖 | 关系 |
|---|---|
| **K-1** | 仍须单一基线成员；弱化的是**共享强度**，不是 O-a |
| **K-2 锁定修订** | **必须**新后缀修订 `74k` 承载的 K-2 表述或增补裁定限定（**不得**就地改 `74k`） |
| **L-3** | 可能仅需手级 `non_probed` 用途，决策级扩展压力较小 |
| **K-4** | 中：协议变更仍须审查 |
| **`74w` C-2′ 文本** | 须复核 §11.2 是否需说明「共享弱化不进入协方差证明」 |

### 6.5 架构边界与越界风险

- 未修订 K-2 正文而仅实现弱化 ⇒ 与 `74k` **形式冲突**，③ 形式核验风险。
- 将弱化误读为「可不生成 L-3 材料」⇒ 违反 R-a。

### 6.6 身份影响

- 可能低于 Ki（若仍每手新建实例）；但若改变预注册协议，仍须 K-4 审查。

### 6.7 失效／重核验影响

|---|---|

| 仅采纳 Kii 而未改文档 | `74af`「不通过」**持续** |

### 6.8 候选验收判据

## 7. K2-P-iii：策略从外部按决策键索引材料

### 7.1 路径摘要

- 修改 `strategy/`（至少基线成员实现），随机量从外部注入表／回调读取，键由 §4.1 裁定。

### 7.2 决策键与同键规则

- 可采用 **D-evt**、**D-state-evt** 或 **D-ext**；**F-stateful** + **F-no-cross-arm** 为常见组合（**不**选择）。

### 7.3 依赖

| 依赖 | 关系 |
|---|---|
| **K-1** | 须明确改动的注册策略／成员 |
| **L-3** | 外部表须与 L-3 生成物一致或可验证映射 |
| **K-4** | **高**：可能改变行动分布实现路径 ⇒ 身份与参考版本化**必审** |
| **`AGENTS.md`** | 默认**越界**；须显式 `strategy/` 改动授权 |

### 7.4 架构边界与越界风险

- `strategy` 直接依赖 `api/`／`llm/` ⇒ 禁止。
- 注入接口若绕过 `GameState` ⇒ 架构违反。
- 未审 K-4 即合并 ⇒ 评估口径争议。

### 7.5 身份影响
