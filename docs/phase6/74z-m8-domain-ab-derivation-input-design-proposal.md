## 9. `V_max^{AB}(v)` 与可选 AB-2z 收紧路径

> **本节性质**：下列公式来自 `74i` 的条件性推导，供候选对照；**本文件不作裁定**，**未**选用任一路线，**未**进入解算。

### 9.1 通用界（推荐候选，待后续裁定）

在 **AB-0**、**AB-1′** 与 **W-1** 均成立、且审查方**将来裁定**采用本候选时，对**已锁定**的 `v`：

```text
V_max^{AB}(v) := ( Σ_{ℓ ∈ L_s} v_ℓ · √c_ℓ · R_ℓ / (2 √n_ℓ) )²
M_AB(v)² := ( Σ_ℓ v_ℓ · R_ℓ )² / 4
```

- 层间协方差经 Cauchy–Schwarz 进入上式；在该候选下**不需要** AB-2z 作为前提（`74i` §5.3）。
- 非退化（条件性）：`M_AB(v) > 0` 且 `n_s := min_{ℓ∈L_s} n_ℓ ≥ 2` ⇒ `V_max^{AB}(v) ≤ M_AB(v)² / n_s < M_AB(v)²`（`74i` §5.4）；**当前无已裁定路线，不作解算主张**。
- `n_s = 1`：**不**主张严格非退化；`M_AB(v) = 0`：平凡情形。

### 9.2 收紧界 `V_max^{AB,0}(v)`（推荐候选，待后续裁定；须 AB-2z）

```text
AB-2z（未建立）：∀ ℓ ≠ ℓ′，Cov(ȳ_{j,ℓ}, ȳ_{j,ℓ'}) = 0
⇒ V_j ≤ V_max^{AB,0}(v) := Σ_{ℓ ∈ L_s} v_ℓ² · c_ℓ · R_ℓ² / (4 n_ℓ) ≤ V_max^{AB}(v)
```
