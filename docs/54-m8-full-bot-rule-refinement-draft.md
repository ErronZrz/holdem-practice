## 3. 根因定位（本次只读复算，落在公式与常量上）

### 3.1 R1：共享牌面的硬封顶与价格项失配

现状（`backend/app/strategy/mixed_features.py`）：

- 河牌当自身最佳牌型与公共五张完全同型时，基础分被硬封顶：`base = min(base, _SHARED_BOARD_CAP)`，`_SHARED_BOARD_CAP = 450`（`mixed_features.py:41`、`mixed_features.py:137-139`）。
- 该封顶**不看公共牌自身的牌型强弱**：公共是坚果顺子还是仅两对，一律压到 450。

现状（`backend/app/strategy/mixed_policy.py`）：

- 跟注阈值 `Tc = (310 若翻前否则 350) + 450*price/1000 + 25*r + depth`（`mixed_policy.py:183-185`），`depth` 深筹码为 `+25`（`mixed_policy.py:177-181`）。
- 被动质量 `F = max(0, Tc - S + 160) * fold_percent`、`C = max(0, S - Tc + 160) * call_percent`（`mixed_policy.py:188-189`）。

被冻结的 `shared-board` 节点牌面是 `Ah Kd Qc Js Th`（`backend/tests/mixed_bot_states.py:310-317`）。**规则层面可判定**：公共五张已是本轮最大顺子，且同花张数最多 2、公共无对子，因此任何两张底牌都无法超越它——该节点是**锁定平分**局面，不是「手牌弱」。

由公式可推（算术推算，非新样本）：

- 封顶后 `S ≤ 450 + 40(位置) + 35(松凶偏移) + 15(施压模式) = 540`；紧密型上限约 470。
- `Tc ≥ 350 + 25(深筹码) = 375`，带一次对手主动动作与常见 `price` 后约 500–600。
- 跟注要拿到正质量需 `S > Tc - 160`，因此**紧密型在这类节点上结构性地位于边界之下**；每多一名未弃牌对手再降 35（`mixed_policy.py:38`），使 C 直接归零。

方向与 R1 一致（紧密 95.9% > 松凶 82.7% / 跟注 82.8%）。值得单列的是：在锁定平分局面里，**弃牌得 0，跟注至少分回底池中的一份**，所以该节点上弃牌严格劣于跟注。这是规则层面的支配关系，不是新样本结论；它是否被对手实际利用仍需另行检验（`docs/53c` §5）。

### 3.2 R2：翻前价格项与深筹码项把门槛抬到基础分之上

翻前 `Tc` 由三块构成：基数 310、价格项 `450*price/1000`、深筹码 `+25`。翻前 `price = 1000*A/max(A, eligible_pot)`（`mixed_features.py:398-434`），在底池只有盲注的场景里，`A` 本身很小而 `price` 比值不低，价格项因此贡献上百点门槛（量级 +180 至 +300，确切值需在实施前只读复算确认）。

反向核对 `docs/53` §10.2 的翻前基础分：非对子最高约 622（AKs），普通牌型集中在 250–500；扣掉 `looseness`（紧密 −35）与人数惩罚 `35*(m-1)` 后，能越过 `Tc - 160` 的名字很少，这正是 VPIP 0.045 的结构性来源——**不是随机波动，而是阈值与基础分分布量纲不匹配**。旧启发式 arm 的 VPIP 0.243 说明该门槛明显高于本项目既有基线。

### 3.3 R3：退化节点把三档人格抹平

R3 的均值同时受两类节点支配：

- **主动候选为零或接近零的节点**：`_non_value_quality` 在翻前要求 `position≥0 且 base≥280`（`mixed_policy.py:246-248`），翻后要求 `draw>0 或 含 A/K`（`mixed_policy.py:249-250`）；不满足即 U=0，而 `V=max(0, S-Tv+120)` 在阈值未达时也为 0，于是主动质量整体归零（报告里 `no_active_candidate` 为 281/264/269 份即此）。
- **跟注质量归零的节点**：与 R2 同源（`S ≤ Tc - 160`），三档一致退化为「弃牌≈100%」，JS 距离在该节点上恰为 0。

即：松凶与跟注型的差异主要落在倍率（主动 140 对 60、跟注 110 对 150）与 `looseness`（+35 对 +10）上，一旦节点退化为二选一甚至单选，这些倍率**没有作用面**，均值因此被拉到 0.069。R1 / R2 / R3 在很大程度上是**同一个根因的不同投影**：评分上限与阈值失配，使分布塌缩为弃牌主导且风格不变。

## 4. 拟修改项（候选项，未裁定）

以下每项均须用户逐项裁定后才可实施；本文件不预设实施顺序。

### M1 共享牌面：区分「公共牌本身是坚果」与「公共牌本身很弱」

- 现状：不区分，一律封顶 450。
- 拟改：为「自身最佳牌型 == 公共最佳牌型」增加**锁定判定**——公共已是最大可能牌型（无同花可能、无更高牌型可能）时，封顶放宽或改用分池口径的价格；公共牌自身很弱时，保留甚至加强保守封顶。
- 边界：判定只读公共牌，不枚举对手底牌、不读未发牌、不新增 Monte Carlo。
- 备选实现：**(a)** 按公共牌型给分档封顶；**(b)** 锁定时把跟注阈值的价格项按在场未弃牌人数折减（分池下所需权益显著更低）；**(c)** 两者同时施加并用同一阈值常量统一表达。建议 **(b) 优先**：它直接修的是「价格口径把平分局面当普通跟注」这一失配，改动面最小且可被单点回归锁定；**(a)** 作为兜底另议。
- 可能损害：若判定过宽，会在「公共牌看似强、实际已被对手超越」的局面（如公共两对而对手成葫芦）变得过于粘手，因此判定条件必须只覆盖「任何底牌都无法超越」的情形。

### M2 翻前价格与深筹码项的口径

- 拟改：为翻前单独确定价格项权重与深筹码项是否施加（当前二者在仅盲注底池里把门槛抬到基础分之上）。
- 前提：**先由用户给出翻前进池率的目标带**（见 §5 决策 D2）；没有目标带就无法判断「修够了」还是「修过头」。
- 边界：不改 `_preflop_base` 的既有公式形态，不改 `heuristic.py` 任何常量；只动新策略自身的阈值口径。

### M3 风格分离

- 拟改方向：让风格差异作用在更多节点上（例如把被动/主动阈值本身按风格分档，而不是只调倍率），并优先修补 R3 中「三档都退化」的节点类别。
- 前提：同样需要用户先给出目标（见 §5 决策 D3）。`docs/53` §13.2 明确「不以追求更高动作熵为目标」，因此**不能**以「把 JS 距离调大」本身作为验收，而要以「三档在具体牌理上给出可解释的不同选择」为准。
- 边界：不引入新的随机分流维度以外的隐变量，不改变合法集与安全排除项。
