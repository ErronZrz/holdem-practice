## 2. 起点读数与可行区间

`docs/54g` 实测（对抗对照 4,224 手、同一四个主种子、按风格手数口径）：

| 档 | VPIP | 相对下限 0.12 | 相对上限 0.35 |
|---|---|---|---|
| 紧密 | 0.1080 | 差 0.0120 | 余 0.2420 |
| 松凶 | 0.2372 | ✓ | 余 0.1128 |
| 跟注 | 0.3281 | ✓ | 余 0.0219 |

两两差：紧–松 `0.1292`、松–跟 `0.0909`、紧–跟 `0.2201`。

**可行区间推导（本规格的关键约束）**：目标带要求"三档两两差 ≥0.05"。本次只动紧密型，松凶与跟注型按设计逐字不变，因此紧密型除下限 `0.12` 之外还受**上界**约束：

- 紧–松 ≥0.05 ⇒ 紧密 ≤ `0.2372 − 0.05 = 0.1872`
- 紧–跟 ≥0.05 ⇒ 紧密 ≤ `0.2781`（不构成约束）

**⇒ 紧密型的可行区间为 `[0.1200, 0.1872]`，中点 `0.1536`。** 低于下限或高于上界都算未命中；这使本次修订是一个**窄带落点问题**，而不是"越高越好"。

## 3. 只读估算：紧密型偏移 → VPIP 的弹性

估算只用**已披露在回执里的量级**，不重新发明模型：

**第一步：偏移在筛查模型中的响应**。`docs/54d` §4 给出筛查表，`docs/54e` §4 给出第三版的筛查落点 `0.178 / 0.363 / 0.492`（紧 / 松 / 跟）。两处之差可拆出偏移通道：

| 通道 | 筛查量级 |
|---|---|
| 人数惩罚 35→30（紧密型，无偏移） | `0.153 → 0.178`，即 `+0.025` |
| 松凶（偏移 35） | `0.246 → 0.363`，扣掉人数惩罚通道后约 `+0.092` ⇒ 每点 `≈0.0026` |
| 跟注（偏移 110） | `0.208 → 0.492`，扣掉人数惩罚通道后约 `+0.259` ⇒ 每点 `≈0.0024` |

两个风格给出的每点响应接近，取 `≈0.0025`（筛查口径）。

**第二步：折算到实测口径**。同一运行里"实测 / 筛查"的比例为：紧密 `0.1080/0.178 = 0.607`、松凶 `0.2372/0.363 = 0.653`、跟注 `0.3281/0.492 = 0.667`。取紧密型自身最保守的 `0.607`。

**⇒ 实测口径弹性约为 `0.0025 × 0.607 ≈ 0.0015` VPIP / 每点偏移。**

**估算的假设与不确定性（必须如实标注）**：以上把"人数惩罚通道"近似为与风格无关的绝对增量、并假定偏移通道按同一比例折算。两处近似都可能带来数十个百分点的偏差，因此把弹性区间记为 `0.0010 – 0.0021`（中心 `0.0015`，约 ±35%）。

## 4. 建议取值与预期落点

**建议：`preflop_call_bonus.tight = 30`**（紧密型），松凶仍 35、跟注仍 110，其余参数逐字不变。

| 项 | 值 |
|---|---|
| 预期落点（中心弹性 0.0015） | `0.1080 + 30 × 0.0015 ≈ 0.1530` |
| 预期落点（弹性区间） | `0.138 – 0.171` |
| 可行区间 | `[0.1200, 0.1872]` |
| 判定 | 中心值与整个弹性区间都落在可行区间内 |

选 30 而不是更小的值，是因为可行区间上界只有 `0.1872`：落点太靠近下限时，估算偏差会直接导致"未命中下限"；取中点可在两个方向都留出余量。

**若实测越界时的处置方向（不是承诺）**：低于 `0.12` 则向上调偏移；高于 `0.1872` 则向下调。**每次重跑都是开发证据**，不得当作独立质量验证。

## 5. 拟修改项（候选项，未裁定）

### `@4` 的唯一改动

在第三版口径基础上**只改一项**：紧密型的翻前跟注偏移由 `0` 改为 `30`。第三版的分池口径、翻前价格项权重（150）、翻前每对手惩罚（30）、松凶与跟注型的偏移（35 / 110）以及全部翻后口径**逐字不变**。

边界：
- 不改翻前基础分公式形态（M2-3 连张倒置仍按既有裁定不动）；
- 不动 `heuristic.py`、不动翻后价格口径；
- 偏移仍**只进入被动分支**，因此不会凭空产生加注，跟注型 PFR 仍应贴近 0、松凶 PFR 与主动率仍应最高。
