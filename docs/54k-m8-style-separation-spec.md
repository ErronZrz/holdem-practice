## 2. 问题与实测起点

`docs/53` 把风格间可分辨性列为后续重点，`docs/54j` 的实测给出三对风格的平均 JS 距离（125 节点口径）：

| 风格对 | 平均 JS | 最大 JS | 恒等节点数 | 非恒等子集均值 |
|---|---|---|---|---|
| 紧密–松凶 | 0.2136 | 0.4406 | 26 / 125 | 0.2696 |
| 紧密–跟注 | 0.2444 | 0.5809 | 27 / 125 | 0.3117 |
| **松凶–跟注** | **0.1102** | 0.2914 | **31 / 125** | **0.1465** |

**松凶–跟注型在均值、非恒等子集均值、最大距离三项上都最弱**，且恒等节点最多。该读数在 `@3` 与 `@4` 之间**逐字未变**（`0.1102`），说明翻前偏移细化完全没有触及它。

## 3. 只读诊断：距离集中在哪里

对 125 个冻结节点逐个复算（只读，不写文件）：

| 类别 | 节点数 | 松凶–跟注 平均 JS |
|---|---|---|
| short-stack-call | 7 | 0.0000 |
| one-side-all-in | 7 | 0.0091 |
| missed-draw-river | 8 | 0.0196 |
| shared-board | 8 | 0.0268 |
| free-check | 8 | 0.0288 |
| flop-draw | 8 | 0.0322 |
| overpair-on-high-board | 8 | 0.0412 |
| sizes-merged | 8 | 0.0472 |
| top-pair-weak-kicker | 8 | 0.0996 |
| incomplete-raise | 7 | 0.1064 |
| turn-combo-draw | 8 | 0.1891 |
| hu-blind-position | 8 | 0.2090 |
| facing-first-raise | 8 | 0.2166 |
| unopened-open | 8 | 0.2243 |
| open-after-limp | 8 | 0.2248 |
| facing-reraise | 8 | 0.2609 |

**结构成因（机制层）**：

1. **31 个节点上两档分布逐位恒等**，分布在这些类别里：`short-stack-call` 7、`free-check` 5、`flop-draw` 5、`one-side-all-in` 5、`missed-draw-river` 5、`incomplete-raise` 3、`overpair-on-high-board` 1。这些节点的候选数为 2 / 4 / 5 个不等，恒等的原因不是"只有一个候选"，而是**质量被单一分支吃满**（该分支拿到全部单位、其余候选为 0 单位），因而风格参数无处发力。
2. **被动分支主导是普遍形态**。逐点核对若干低距离节点（单点读数，非聚合）：`overpair-on-high-board` 2 人为 跟注 0.803 / 弃牌 0.197，主动候选为 0 单位；`missed-draw-river` 2 人为 弃牌 0.955 / 主动合计 0.045；`free-check` 2 人为 过牌 0.923 / 主动 0.077。对照高距离节点 `facing-first-raise` 2 人为 跟注 0.762 / 主动 0.238。**风格差异主要活在主动质量里，而很多节点的主动质量接近 0。**
3. 现有风格参数的差异集中在主动通道（`aggression_percent` 140 vs 60、`size_preferences` 不同），被动通道的差异只有 `fold_percent` / `call_percent` 两个倍率；在主动质量为 0 的节点上，两档只剩"弃牌与跟注的比例"，而该比例由评分与阈值之差决定，风格的直接杠杆很弱。

**⇒ 结论：要让松凶–跟注型分开，最直接的作用面是"被动分支"（跟注/弃牌、过牌/下注的选择比例），而不是继续加大主动倍率。**

## 4. 只读估算：两条通道的响应

估算方法：在只读脚本中按现有实现重算权重向量，并加入**假想的**按风格偏移旋钮（被动通道的翻后评分偏移、主动通道的价值门槛偏移）。**保真度核对**：在偏移取零时，重算结果与既有分布的逐位一致率为 `1125 / 1125`（125 节点 × 3 风格 × 3 手模式），基线三对 JS 也与实测逐字一致——因此重算路径可信；但**加入偏移后的读数仍是估算**，因为该旋钮在当前代码中并不存在。

| 候选（假想旋钮） | 紧–松 | 紧–跟 | **松–跟** | 动作熵 紧/松/跟 | 无主动候选 紧/松/跟 |
|---|---|---|---|---|---|
| 基线（`@4` 实测） | 0.2136 | 0.2444 | **0.1102** | 0.510 / 0.527 / 0.376 | 278 / 263 / 267 |
| **被动通道：跟注型 +80** | 0.2136 | 0.3001 | **0.1619** | 0.510 / 0.527 / 0.320 | 278 / 263 / 267 |
| 被动通道：松凶 −40、跟注 +140 | 0.1844 | 0.3367 | **0.2295** | 0.510 / 0.546 / 0.287 | 278 / 263 / 267 |
| 主动通道：松凶 −60、跟注 +80 | 0.2320 | 0.2544 | 0.1531 | 0.510 / 0.592 / 0.342 | 278 / 235 / 287 |
| 主动通道：松凶 −100、跟注 +140 | 0.2473 | 0.2607 | 0.1817 | 0.510 / 0.639 / 0.327 | 278 / 213 / 295 |

三列必须一起看的三点：

1. **被动通道是"定点"的**：它不改变无主动候选的计数，只把跟注型的弃牌质量移向跟注，因此直接作用于上面诊断出的"被动分支主导"节点。
2. **主动通道会顺带抬高松凶型的动作熵**（0.527 → 0.592 / 0.639）。按 `docs/53` §13.2，**动作熵不是目标**，这一点只能是副作用，不得当成成绩。
3. **两种通道都会降低跟注型的动作熵**（0.376 → 0.320 / 0.287）。这与"跟注型不主动加注"的语义一致，但确实**削弱了该风格自身的动作多样性**——这是与"三维不可预测性优先"之间必须由用户权衡的取舍，本文件不预设结论。

**未估算的通道**：尺度通道（放大 `size_preferences` 差异，让同一动作的金额分布更不同）。本文件不给出它的读数，避免把未测的猜测写进规格。

## 5. 拟修改项（候选项，未裁定）

### M3-1 被动通道的按风格翻后偏移（推荐优先评估）

为每种风格引入**只作用于翻后被动分支**的评分偏移（新参数，类似既有翻前跟注偏移的做法），松凶取负、跟注取正、紧密取 0 或小正值。

边界：
- **只作用于翻后**：翻前一分不动，因此 `docs/54j` 已实测达标的目标带不受影响（由回归锁定）。
- 仍**只进入被动分支**：不凭空产生加注，跟注型 PFR 仍应贴近 0。
- 不读取对手底牌、不引入新的随机维度。

### M3-2 主动通道的按风格价值门槛偏移

为每种风格引入价值门槛偏移（松凶取负 → 更薄的价值下注；跟注取正 → 更少加注）。

边界：会同时抬高松凶的动作熵与主动质量，属于"更激进"的改动，需与 `docs/53` §13.2"不以拉高动作熵为目标"一并权衡。

### M3-3 尺度通道（未估算）

放大三档的尺度偏好差异。**本文件不给读数**；若进入实施，必须先补一次只读估算。

### M3-4 结构恒等节点不可改善（记账）

31 个节点上两档分布逐位恒等，任何**按风格标量**的机制都改不动它们（质量被单一分支吃满）。因此"松凶–跟注"可达到的上限不是 1，且**任何目标都必须写明按什么口径判定**（见 §6）。

### 6.1 选参扫描（只读估算，按 T1 口径）

通道取 §5 的 M3-1（被动通道），且**只动跟注型、只作用于翻后**：松凶与紧密的翻后被动偏移取 0，因此这两对的距离按构造不变。

| 跟注型翻后偏移 | 紧–松 | 紧–跟 | 松–跟 | 最小对 | T1（≥0.15） | 跟注型动作熵 | 无主动候选 |

| 0（`@4` 基线） | 0.2136 | 0.2444 | 0.1102 | 0.1102 | 否 | 0.376 | 267 |

| **+100** | **0.2136** | **0.3132** | **0.1765** | **0.1765** | **是（余 0.0265）** | **0.303** | **267** |
| +120 | 0.2136 | 0.3258 | 0.1907 | 0.1907 | 是（余 0.0407） | 0.292 | 267 |
| +140 | 0.2136 | 0.3367 | 0.2024 | 0.2024 | 是（余 0.0524） | 0.287 | 267 |
| +200 | 0.2136 | 0.3659 | 0.2334 | 0.2334 | 是（余 0.0834） | 0.283 | 267 |

读数要点：

1. **紧–松 始终为 0.2136**：只动跟注型，这对按构造不变，T1 对它的要求自动满足。
2. **门槛在 +40 与 +80 之间越过**：+80 是满足 T1 的最小扫描点。
3. **跟注型动作熵单调下降**，到 +120 之后基本进入平台（0.292 → 0.287 → 0.283）。按 `docs/53` §13.2，熵不是目标；这里的下降是**副作用**，也是不建议取更大偏移的理由。
4. **无主动候选计数三档全部不变**：该通道不触碰主动候选，因此不会改变"无主动候选"的既有读数。
5. **估算的可复现性边界**：上述数字来自 §4 的只读重算路径（在偏移为零时与正式分布逐位一致）。**若实施严格按同一数学落地**（偏移只进入翻后被动分支、不进 `_score`、不夹紧分数），则这些冻结节点读数可以被**逐位复现**；**若实现方式不同，它们就只是估算**。

**建议取值：跟注型翻后被动偏移 = `+100`。** 理由：满足 T1 且留出约 18% 的余量，避免因实现细节差异恰好落在门槛之下；同时不把跟注型动作熵压到平台（`+140` 之后收益递减、熵损失更多）。次选为 `+80`（最小改动、余量仅 8%）与 `+140`（余量 52%、熵损失更大）。
