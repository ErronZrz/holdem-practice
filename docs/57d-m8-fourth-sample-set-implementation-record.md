## 6. 两处比较口径错误的如实更正

| 项 | 现象 | 更正 |
|---|---|---|
| 空牌面空洞匹配 | 首次比对报出「同类别同人数的牌面相同 `54` 处」，一度像是碰撞 | `54` 恰为**翻前类别覆盖的节点数**——这些节点的公共牌都是空元组，相等是**空洞匹配**。严格口径（只比较非空牌面）下碰撞为 `0` |
| 座位取错 | 首次比对用 `hole_cards[0]`（`0` 号座）当作主题底牌 | 主题牌面落在**行动座位**上，应取回放后的当前行动座位；更正后行动座位底牌碰撞为 `0` |

两处都是**比较口径错误**，不涉及任何实现缺陷；以本节更正为准。这两个错误**也促使**回归里把行动座位解析与「牌面 + 底牌 + 行动线」组合比对写成显式断言，避免同类错误再出现。
